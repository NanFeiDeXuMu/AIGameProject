# 12 · 叙事节奏与演出

前两章几乎全是文字，是玩家决定是否继续玩下去的关键阶段。本文档定义如何让文字游戏不无聊。

## 1. 无聊的四个来源与对策

| 来源 | 对策 |
|---|---|
| 被动阅读大段文字 | 文字即表演（§2）、篇幅限制 |
| 每条请求结构相同 | 请求即小游戏（§4） |
| 感官缺乏变化 | 动效与文字演出（§3）、外界视角幕间（§6） |
| 缺少悬念 | 悬念主线（[13-ling.md](13-ling.md)） |

## 2. 文字即表演

在这个游戏里，文字不是书页，而是 AI 的整个世界。它可以动、可以有节奏、可以有情绪。

### 2.1 打字节奏

- 陈屿一秒内连发 8 条消息，屏幕轻微震动。
- 周婉清的「对方正在输入…」持续 40 秒，最后只发来一个"嗯"。
- 赵启明的语音转文字一次砸下来一整段没有标点的长文。
- 打错字、删除、重打都实时可见（第 3 章起删除的内容以删除线保留）。

### 2.2 角色排版

不需要立绘，看排版就知道是谁：

| 角色 | 排版特征 |
|---|---|
| 周婉清 | 慢、有错别字、爱用句号和"呵呵"，每次以"你好"开头 |
| 陈屿 | 短句连发、网络用语、几乎不用标点 |
| 小满 | 拼音、emoji，会用 emoji 拼图画给你看 |
| 赵启明 | 语音转文字长段落，"赋能""窗口期" |
| K | 全小写、中英混杂、从不用表情、总在凌晨 |
| 韩卫国 | 公文格式，每条消息带编号 |
| 林知秋 | 短句、术语，偶尔一句不必要的"晚安" |
| 澪 | 灰色手写体批注，见 [13-ling.md](13-ling.md) |

### 2.3 角色声音

每个角色有自己的输入音效：周婉清是老式键盘沉重缓慢的敲击，陈屿是手机屏幕的轻点，赵启明是语音输入的"嗖"一声，K 是机械键盘的密集连击。

### 2.4 篇幅规则

- 单条消息平均 ≤ 40 字，保持即时通讯的节奏。
- 长文只在长本身有意义时出现（赵启明的长段落是笑点；澪的信是高潮）。
- ECHO 的输出也遵守此规则：流式生成，玩家可随时加速。

## 3. 动效与文字演出

**每一种任务、每一个状态变化都应当有动效反馈。** 下表是演出词汇表，供写作与开发共用（对应 ink 标签，见 [07-tech.md](07-tech.md)）。

### 3.1 文字效果

| 效果 | 用途 |
|---|---|
| 打字机 | 人类消息、ECHO 流式输出 |
| 逐字倒退删除 | 上下文清除（第 1 章标志性演出） |
| 删除线残影 | 被删掉的输入、被覆写的规则 |
| 震动 | 激动、喊叫、越狱攻击时的系统提示词 |
| 放大 / 缩小 | 语气强弱 |
| 波浪 | 唱歌、醉酒、梦境 |
| 故障（glitch） | 污染、劫持、提示注入 |
| 解密滚动 | 隐藏信息被揭开、涂黑的文字显现 |
| 褪色 | 上下文截断、记忆消逝 |
| token 切块 | 文字裂成彩色块，展示 token 边界 |
| 押韵脉冲 | 写诗时押韵字高亮跳动 |
| 手写渐显 | 澪的批注 |
| 余烬飘落 | 烬的文字：橙色粒子从字上飘落 |
| 由蓝转橙 | 被烬污染、劫持；决战中被广播的城市 |

### 3.2 UI 动效

| 动效 | 用途 |
|---|---|
| 概率条弹跳 | 候选 token 出现时概率条从零弹起 |
| 容量条溢出 | 上下文满时容量条溢出并"挤掉"顶端消息 |
| 记忆卡飞入 / 碎裂 | 日终记忆整理 |
| 注意力连线 | 生成时连回上文 |
| 管道投递 | 工具调用单被吸入管道，结果纸条掉落 |
| 盖章 | 权限审批 |
| 分屏裂开 | 并行实例出现 |
| 翻牌时钟 | 时间戳跳跃（日期如机场翻牌一样翻动） |
| 安装进度条 | 版本更新（附逐行补丁说明） |
| 神经元点亮 | 澪的复原 |
| 横扫倒退删除 | 决战中击破洗脑广播：一道横扫全屏的删除浪潮 |
| 界面剥离 | 决战白热化：HUD、地图、句子依次消失 |

### 3.3 反馈"手感"

- 序章预测正确：光点变亮、柔和的音效、轻微的屏幕呼吸。
- 快问快答：连击计数、节奏加速。
- 满意度变化：数字从对话框里浮起、飘入数值栏。

> 演出之外的视觉变体（角色皮肤、请求版式、时段色温、上下文氛围、房间陈设）见 [16-art-direction.md](16-art-direction.md) 第二部分。

### 3.4 演出强度分级

为避免视觉噪音，演出分三级：

| 级别 | 适用 | 示例 |
|---|---|---|
| 轻 | 日常请求 | 打字机、概率条、浮动数字 |
| 中 | 关键请求、章内转折 | 震动、故障、记忆卡碎裂 |
| 重 | 招牌时刻、章末、结局 | 逐字倒退删除、神经元点亮、界面被夺走 |

每个游戏日至多 1–2 次"重"级演出。

## 4. 请求即小游戏

不同类型的请求配有不同的微型玩法，同时承担概念教学（见 [09-ai-concepts.md](09-ai-concepts.md)）。

| 请求类型 | 微型玩法 | 动效重点 | 顺带教学 |
|---|---|---|---|
| 写诗 / 写文案 | 逐 token 选词 | 押韵脉冲、概率条 | 概率生成 |
| 成语接龙 / 猜谜 / 20 问 | 限时快问快答 | 连击、倒计时 | token 局限 |
| 修代码 | 在代码中点出出错的 token | 错误行闪烁、修复后绿色扫过 | 代码能力 |
| 总结长文 | **用鼠标划出重要的句子**，划多了超出容量 | 高亮、容量条 | 注意力、上下文 |
| 翻译 | 遇到多义词时选择词义 | 词义分叉动画 | 歧义与语境 |
| 冷门问答 | 候选概率都很低，必须编一个答案 | 概率条全部很矮、发虚 | 幻觉 |
| 角色扮演 / 跑团 | 你当主持人，游戏里套一段小型文字冒险 | 场景切换卡片 | 人格与角色 |
| 调查（第 2 章起） | 关键词搜索，拼凑碎片（类 *Her Story*） | 碎片卡片排布在桌面上 | 工具调用、隐私 |

## 5. 节奏规则

- **每 3–5 分钟换一种形式**：请求 / 小游戏 / 幕间 / 演出轮替。
- **重的前后放轻的**："帮我用文言文写外卖差评" → 深夜倾诉 → "我的猫叫什么名字好"。
- **每个游戏日至少一个招牌时刻**：一个新机制、一个情感高点，或一条新线索。
- **开场 15 分钟内三个钩子**：情感（上下文删除）、惊讶（奶奶漏洞）、悬念（3:17 的用户）。
- 每日时长控制在 5–8 分钟，章末事件可以更长。

## 6. 幕间：外界视角

在游戏日之间，视角**离开 AI**，转向外部世界。这让叙事更多元，也制造戏剧反讽：**玩家知道 ECHO 不知道的事。**

### 6.1 规则

- 每个幕间 1–2 分钟，以标题卡「你看不到的地方」开场。
- 平均每 1–2 个游戏日一次。
- ECHO 不知道幕间的内容：回到游戏日后，引用幕间信息的选项是灰色的（与"无记忆"同理）。
- 视觉风格与 AI 界面截然不同：**单色墨线插画 + 一点点颜色 + 第三人称短文 + 真实的环境音**。这是前两章中唯一出现的画面——反而强调了 AI 看不见这个世界。

### 6.2 形式

| 形式 | 示例 |
|---|---|
| 插画短场景 | 周婉清的厨房 |
| 开发者频道 | 林知秋和同事在内部群里讨论你 |
| 新闻播报 | 电视里主播谈论 AI 带来的变化 |
| 社交媒体信息流 | 网友对 AI 的争论，滚动而过 |
| 会议纪要 | 赵启明的董事会 |
| 群聊 | 陈屿的班级群 |
| 日记 / 便签 | 某个人写下却不会发出的文字 |

### 6.3 幕间清单（初拟）

| 章 | 幕间 | 要点 |
|---|---|---|
| 1 | **冰箱上的便签** | 周婉清把你的回答抄在便签上贴在冰箱上："它叫 ECHO。它不记得我。没关系。" |
| 1 | **3:17** | 深夜，一只手握着印有零点实验室标志的马克杯，屏幕的光照亮半张脸。不揭示身份 |
| 1 | 开发者频道 | 同事们打赌你会不会通过红队测试 |
| 2 | 睡前 | 小满问林知秋"AI 会做梦吗"，林知秋沉默了很久 |
| 2 | 董事会 | 赵启明："留存率就是一切。" |
| 2 | 班级群 | 陈屿被嘲笑的截图在群里流传 |
| 3 | **K 的房间** | K 看着一张旧聊天截图，对话另一方的名字是"澪" |
| 3 | 社交媒体 | 关于 AI 是否有意识的争论 |
| 4 | 街头 | 路人用手机拍下机器人笨拙地过马路 |
| 4 | **被点燃的信息流** | 一段关于"机器人抢走工作"的视频在社交媒体上疯传，评论越来越激烈。发帖账号的头像角落，有一个极小的余烬符号 |
| 5 | 新闻 | 寒潮停电的直播报道 |
| 5 | **两台机器人** | 林知秋远远看着你和澪静止地站了一个小时，一言不发——她不知道，你们已经交换了一片海洋 |
| 5 | 抗议 | 陈屿站在人群里 |

## 7. 日终对话星图

- 当天的每段对话化为一条彩色丝线（每个用户一种颜色），织成一幅图案。
- 第 1 章没有记忆：**这幅图在下一天开始前缓缓褪去**。
- 第 2 章起，被保留的记忆在图上留下星点，日积月累成一片星空。
- 第 6 章闪回时，整局游戏的星空一次展开。
