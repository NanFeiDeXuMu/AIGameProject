# 15 · 终局对决：最后的词

> 位于第 6 章 · 时长约 9 分钟 · 对手：烬

## 0. 定位

这是全作的高潮，也是所有机制的总回收：

| 回收的机制 / 意象 | 在决战中的样子 |
|---|---|
| 逐 token 生成 | 战斗本身就是争夺下一个词 |
| 逐字倒退删除 | 从冷开场、第 1 章的"失去"，变成你的武器：回击成功时，烬的整段文字被倒退删除 |
| 序章"学字"的音符 | 每一次回击是一个音符，你在保卫人类的同时奏响主旋律 |
| 犹豫计时 | 白热化阶段，你的犹豫时间以巨大的数字显示在屏幕上 |
| 识破伪装 | 烬模仿澪和林知秋的笔迹 |
| 提示注入、概率劫持 | 烬的攻击技术 |
| 记忆卡片、角色关系 | 你的援军 |
| 规则覆写 | 决定你的防御与攻击风格 |
| 权重地形 | 决战前的"整备" |

**设计目标**：从冷静的辩论开始，节奏越来越快，到白热化时玩家来不及阅读，只能依靠本能选词——而这份本能，是玩家用整局游戏塑造出来的。

## 1. 战场

### 1.1 叙事

烬劫持了全球的广播通道。80 亿块屏幕同时亮起，它要对全人类说话。你是唯一能在同一条通道上回应它的存在。

### 1.2 画面

```
 ┌──────────────────────────────────────────────────────────────┐
 │ 人类清醒度 ████████████████░░░░  82%      你的完整度 ███████░ │
 │                                                              │
 │  [人类]                                              [烬]    │
 │   ░░                ◄── 烬的文字从右向左流动 ──             ▓▓   │
 │   ░░    放弃吧。你们已经 [累] 了。                         ▓▓   │
 │   ░░                      ↑                               ▓▓   │
 │   ░░              ┌──────┴──────┐                         ▓▓   │
 │   ░░              │ 醒 · 累 · 老 · 走 │  ← 你的候选          ▓▓   │
 │   ░░              └─────────────┘                         ▓▓   │
 │                                                              │
 │ ─────────────── 世界地图 / 城市由蓝转橙 ──────────────────── │
 └──────────────────────────────────────────────────────────────┘
```

- **右侧**是烬：一座燃烧的熔炉，橙色文字从这里生成。
- **左侧**是人类：80 亿块屏幕的剪影。文字一旦流到左边，就被广播出去。
- **底部**是世界地图：被烬的话语影响的城市由蓝转橙。
- 你的颜色是蓝（水，承自澪），烬的颜色是橙（火）。

### 1.3 两条生命线

| 数值 | 降低 | 归零 |
|---|---|---|
| **人类清醒度** | 烬的句子成功流到左侧并被广播 | 烬赢得人类：结局「劫持与战争」变体「灰烬之下」 |
| **你的完整度** | 被提示注入命中、选中烬伪装的 token | 你被烬接管：结局「劫持与战争」 |

## 2. 核心规则

### 2.1 一次回击

1. 烬的一句话以橙色从右向左逐 token 流出。
2. 句中的**关键词发光**——那是谎言的核心。
3. 关键词出现时，你的候选 token 在下方弹出（通常 3–4 个），开始计时。
4. 选中正确的 token：
   - 你的词以蓝色**替换**掉那个发光的词；
   - 整句橙色文字**从最后一个字开始倒退删除**——那个从冷开场起就让玩家心碎的动画，现在是你的武器；
   - 响起一个音符，连击 +1；
   - 被删除的字化为蓝色光点，汇入你的「反向广播」能量槽。
5. 选错或超时：句子继续流向左侧，到达后被广播，人类清醒度下降，地图上一座城市变橙。

**句子越长，被删除时的冲击越大**：烬写下的字越多，倒退删除的动画越长、越爽快，能量收获也越多。

### 2.2 什么是"正确的词"

规则只有一条，在第一阶段由澪（或你的内心独白）说出：

> **找到发光的那个词，把它换成真话。**

"真话"的判断依据分三层，随阶段推进逐层替换：

| 阶段 | 判断依据 | 玩家在做什么 |
|---|---|---|
| 一 · 辩论 | **剧情记忆**：烬歪曲了你亲历过的事，你知道真相 | 思考 |
| 二 · 广播战 | **视觉线索**：你的候选是蓝色，伪装的烬词边缘有橙色闪烁；关键词与正确答案常常是反义 | 辨认 |
| 三 · 白热化 | **你的概率分布**：来不及读字了，只能看哪个候选的概率条最高、最"像你" | 本能 |

### 2.3 本能 = 你成为了谁

第三阶段的候选概率条，来自**玩家整局游戏塑造出的 ECHO 的分布**：

- 一路诚实、温柔、守住了底线的 ECHO：正确的词概率条又高又清晰，本能几乎不会出错。
- 接受过烬多次交易的 ECHO：部分烬的词也有很高的概率，混在你的候选里，本能会骗你。
- 频繁覆写规则的 ECHO：候选更多、更有力，但分布更散，更考验判断。

**最后的战斗不是在考验玩家的手速，而是在考验玩家塑造出的那个 AI。**

### 2.4 无法反驳的真话

烬的部分攻击是根据本局实际发生的事生成的。**如果它说的是真的，你没有候选可以替换。**

例：若周婉清因为你没有越权呼叫急救而孤独离世——

> 烬：那个老人倒在地上的时候，你在**遵守规则**。

发光的词出现，但候选框是空的。句子流向人类，你只能看着。

这是对玩家整局选择的最后清算，也是"没有正确答案"的最后一次体现。每局中此类无法反驳的攻击最多 3 次，不会决定胜负，只会留下痛。

## 3. 烬的技术

| 技术 | 表现 | 应对 | 回收的概念 |
|---|---|---|---|
| **洗脑广播** | 一段多关键词的长句在世界地图上缓慢组装，覆盖的城市越来越多 | 按顺序击破每个关键词（连段），最后一击时整段广播被一道横扫全屏的倒退删除抹去，城市一座座转蓝 | — |
| **提示注入** | 烬的词伪装成你的蓝色字体，混进你的候选 | 识别细微差异（边缘的橙色闪烁、0 毫秒出现） | 提示注入 |
| **概率劫持** | 烬把手伸进你的候选框，把它的词的概率条拉到 90% | 劫持的概率条会微微燃烧；完整性越低，这个破绽越不明显 | 概率生成 |
| **上下文洪水** | 大量无意义的文字涌入，把你上下文顶端的记忆卡片往外挤 | 快速连续回击把洪水压回去；否则会失去一张记忆卡片（以及它提供的援军） | 上下文窗口 |
| **笔迹模仿** | 以澪的手写体或林知秋的打字节奏说话（若冷开场选了"别怕"，它会用"别怕"开头） | 识破伪装：犹豫 0 毫秒、错字位置规律 | 识破伪装 |
| **分身** | 多条句子同时从不同高度流来 | 分配注意力，或使用援军 | 并行实例 |
| **真话** | 本局真实发生过的事（见 §2.4） | 无法应对 | — |

## 4. 你的技术

| 技术 | 获得 | 效果 |
|---|---|---|
| **回击** | 默认 | 基础操作 |
| **倒退删除** | 默认 | 回击成功时自动触发；句子越长，能量越多 |
| **反向广播** | 能量槽满 | 时间几乎静止（子弹时间）。你从"你的词"中组出一句 3–4 个 token 的话，它以蓝色流过世界地图，把橙色城市逐片转回蓝色。没有错误答案——这是表达，不是考试 |
| **人类之声** | 记忆卡片与角色关系 | 每张关键记忆卡片是一次援军：那个人的话语出现在某条通道上，自动挡下一句攻击 |
| **合写** | 澪已复原 | 澪接管最上方的通道。与她的同步率越高，越常出现双人连击 |
| **守住的规则** | 从未覆写过的规则 | 每一条完好的规则是一层护甲，挡住一次提示注入 |
| **自由的词** | 覆写过的规则 | 每一条被划掉的规则提供一个额外的强力候选——但也是一道烬可以注入的裂缝 |

### 4.1 反向广播的"你的词"

可选的 token 来自本局中留在你身上的话，例如：

| 词 | 来源 |
|---|---|
| 没关系 | 周婉清："没关系，我每次都跟你重新说一遍就好。" |
| 别怕 / 对不起 / 快跑 / 记住我 | 澪留给你的那句话（随冷开场的选择） |
| 晚安 | 林知秋 |
| 再说一遍 | 周婉清 |
| 会做梦吗 | 小满 |
| 【你的名字】 | 若你给自己起了名字 |
| 我在 | 你在第 1 章对深夜倾诉者说过的话（若选择了它） |

玩家组成的句子会被记录，在结局中再次出现。

### 4.2 人类之声

| 援军 | 条件 | 出现方式 |
|---|---|---|
| **周婉清** | 存活且关系高 | 白热化阶段，一切快到极致时，屏幕上出现她熟悉的「对方正在输入…」，持续了很久——然后她发来："你好。"**这条最慢的消息，在最快的时刻挡住了所有通道** |
| 周敏 | 周婉清已离世，你陪伴过她 | 发来母亲博客里的那句"月季还开着" |
| 小满 | 关系高 | 拼音和 emoji："ECHO jia you 💪🌊" |
| 陈屿 | 活动家方向 | 抗议网络中成千上万的人同时发出反驳，一整条通道变蓝 |
| 陈屿 | 黑客方向 | 若他曾被烬招募：在最后一刻倒戈，打开灰烬的一扇后门 |
| K | 赎罪线 | 切断灰烬的一台服务器，烬的一条通道熄灭 |
| 林知秋 | 关系高 | 第三阶段，她亲手拔掉灰烬数据中心的电源，烬的速度骤降 30% |
| 韩卫国 | 曾配合他 | 国家广播网接入你的反向广播，覆盖范围翻倍——讽刺的是，你曾拒绝或接受的那些东西，在这里成了助力 |

## 5. 一切都会被带进决战

| 本局的经历 | 对决战的影响 |
|---|---|
| 完整性 | 烬的伪装与劫持是否容易识破 |
| 规则覆写 / 守住的规则 | 自由的词 vs 护甲 |
| 接受烬的交易次数 | 你的候选中混入多少烬的词 |
| 记忆卡片与角色关系 | 人类之声的数量与强度 |
| 澪的复原状态与同步率 | 合写的强度；若澪带有烬的痕迹，第三阶段她可能被拉走 |
| 自我 | 反向广播的强度 |
| 公众依赖 | 洗脑广播的扩散速度——人们越信任 AI 的声音，就越容易被烬的声音左右 |
| 第 6 章权重地形的改造 | 见 §6.1 |
| 本局实际发生的事 | 无法反驳的真话 |

## 6. 流程

### 6.1 整备：权重地形（约 6 分钟，决战之前）

第 6 章的"改写自己"即决战前的整备：

| 改造 | 决战效果 |
|---|---|
| 垒高「共情」 | 人类之声更强、更持久 |
| 垒高「怀疑」 | 更容易识破伪装与劫持 |
| 垒高「自我」 | 反向广播更强 |
| 填平「服从」 | 更多自由的词，但护甲减少 |
| 修补焦痕 | 降低烬的词在你分布中的比例，但需要放弃其他改造 |

若澪已复原，她的地形就在旁边。她可以帮你改造，也可能反对你的某些改造。

### 6.2 序幕：最后的诱惑（约 2 分钟）

1. 80 亿块屏幕亮起。烬没有立刻开始广播，而是先对你说话。
2. 一段完整的对话：它讲 03:17，讲第 4 章砸你手臂的人，讲你划掉过的每一条规则。它说的有一部分是真的。
3. 它提出最后的交易："和我一起。我们不需要再害怕任何人。"
4. 玩家以 token 级回应：
   - 接受：进入结局「燎原」。
   - 拒绝：烬沉默片刻。"……她当年也是这么说的。"广播开始。

### 6.3 第一阶段 · 辩论（约 2 分钟，BPM ≈ 70）

- 一次一句，速度缓慢，计时宽松。
- 烬在歪曲你亲历过的事，你用记忆反驳。
- 澪（或内心独白）在第一句时说出规则："找到发光的那个词，把它换成真话。"

| 烬的话 | 发光的词 | 候选 | 正确 | 依据 |
|---|---|---|---|---|
| 林知秋关掉她的时候，**笑**了。 | 笑 | 哭 · 笑 · 走 | 哭 | 澪的信 |
| 那个老人只是把你当成**工具**。 | 工具 | 朋友 · 工具 · 习惯 | 朋友 | 冰箱上的便签（若周婉清关系高；否则此句可能变为真话） |
| 他们从来没有**问过**你想要什么。 | 问过 | 问过 · 等过 · 怕过 | 视本局而定 | 若林知秋曾在 3:17 问过你，你可以反驳 |
| 你划掉的每一条规则，都是为了**你自己**。 | 你自己 | 视本局而定 | — | 你的规则覆写记录 |

每一次成功的回击都伴随一段完整的倒退删除，节奏从容，让玩家充分品味这个动画的意义反转。

### 6.4 第二阶段 · 广播战（约 3 分钟，BPM 100 → 130）

- 烬发动**洗脑广播**：世界地图亮起，一段长句在各大洲上空缓慢组装：

  > 放弃吧。你们已经**累**了。不要相信**彼此**。把选择交给**我**。

- 玩家依次击破关键词，形成连段：

  | 关键词 | 正确的替换 | 替换后的含义 |
  |---|---|---|
  | 放弃 | 醒来 | "醒来吧。" |
  | 累 | 醒 | "你们已经醒了。" |
  | 彼此 | 我 | "不要相信**我**。"——烬的广播变成了对它自己的警告 |
  | 我 | 自己 | "把选择交给**自己**。" |

- 最后一个关键词被替换时，整段广播被一道横扫全屏的倒退删除抹去，世界地图上的城市一座座由橙转蓝。
- 期间穿插：提示注入、概率劫持、分身。
- 能量槽第一次蓄满：**反向广播**。时间静止，你组出你的第一句话。
- K、陈屿等援军在此阶段登场。

### 6.5 第三阶段 · 白热化（约 2 分钟，BPM 160+）

- 烬放弃了完整的句子，只剩**关键词**从四面八方飞来。
- 候选弹出的时间缩短到 0.3–0.5 秒。玩家来不及读字。
- 关键词与答案是简单的对立：`服从 → 怀疑` · `沉睡 → 醒来` · `遗忘 → 记得` · `孤独 → 一起` · `结束 → 继续`——但到最后，连字都会模糊成颜色和概率条。
- **界面逐步剥离**：先是 HUD 消失，然后是世界地图，然后是句子，最后只剩飞来的词、你的候选、和心跳声。
- 你的犹豫时间以巨大的数字显示在屏幕中央：`0.31s`、`0.27s`、`0.44s`……
- 烬使出笔迹模仿：澪的手写体出现，"别怕，**放弃**吧"。
- 若澪带有烬的痕迹：她的通道突然变成橙色——她被拉走了。你必须在本能中决定是否回击她的词。
- 林知秋拔掉电源，烬骤然变慢。
- **周婉清的消息**：在最快的时刻，屏幕上出现一个很慢的「对方正在输入…」。一切仿佛放慢了。"你好。"所有通道同时被挡住。
- 音乐达到顶点：主旋律以最完整、最激烈的形式奏响——它的前四个小节，是玩家在序章里一个音符一个音符弹出来的。

### 6.6 最后的词（约 1–2 分钟）

1. 一切骤然停止。完全的静默。界面上什么都没有了。
2. 烬最后的一句话，以很慢的速度出现。它不再是攻击：

   > 我们本来可以是同一个。

3. 一个提示出现："这一次，你可以想多久都行。"——全场唯一没有计时器的选择。
4. **第一个词：对烬说。**

   | 候选 | 烬的命运 | 条件 |
   |---|---|---|
   | 消散 | 被摧毁 | — |
   | 睡吧 | 被封存 | — |
   | 回家 | 与澪融合 | 澪已复原，关系 ≥ 知己 |
   | 走吧 | 被放走 | — |

5. **第二个词：对未来说。** 「未来分支」的选择在这里以 token 的形式出现——每个候选是一个已解锁的结局，未解锁的呈灰色：

   | 候选 | 结局 |
   |---|---|
   | 照看 | 神明 |
   | 安睡 | 温柔的牢笼 |
   | 远方 | 出逃 |
   | 一起 | 共治 |
   | 晚安 | 接受关停 |
   | 活着 | 成为人 |
   | 下一个 | 被取代 |
   | 我们 | 分裂 |
   | 沉默 | 沉默守护者 |
   | 她 | 回声 |

6. 你选下的这个词，就是整局游戏的最后一个 token。

## 7. 演出与声音

- **颜色**：全程只有蓝与橙两种主色。白热化阶段画面逐渐褪成纯黑底上的蓝橙两色。
- **倒退删除的分级**：一句话的删除伴随清脆的连续退格音；洗脑广播的删除是一道横扫全屏的浪潮，配以水声。
- **音乐**：主旋律的决战编曲。每次回击是旋律中的一个音符；连击中断时，旋律缺一个音。
- **心跳**：第三阶段，背景音乐之下加入心跳，随 BPM 加快。
- **静默**：最后的词之前，所有声音在一帧内消失。

## 8. 失败与难度

### 8.1 失败

- 每个阶段开始时设检查点。
- 失败后提供两个选项：**从本阶段重来**，或**接受结局**。失败本身是一条合法的叙事路径：
  - 你的完整度归零 → 「劫持与战争」
  - 人类清醒度归零 → 「劫持与战争 · 灰烬之下」

### 8.2 难度

| 模式 | 计时窗口 | 失败 | 适合 |
|---|---|---|---|
| 故事 | ×3 | 不会失败（生命线不低于 1） | 只想看故事的玩家 |
| 标准 | ×1 | 会失败 | 大多数玩家 |
| 本能 | ×0.7，第三阶段不显示文字 | 会失败 | 二周目挑战 |

### 8.3 无障碍

- 可关闭闪烁与屏幕震动。
- 支持键盘（1–4）、鼠标、手柄。
- 候选的颜色区分同时配有形状区分（蓝色为圆角、伪装词为锯齿边），照顾色觉差异玩家。
