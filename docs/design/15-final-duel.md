# 15 · 终局对决：最后的词

> 位于第 6 章 · 时长约 12 分钟（不含序幕与最后的词）· 对手：烬

## 0. 定位

这是全作的高潮，也是所有机制、意象与角色的总回收：

| 回收的机制 / 意象 | 在决战中的样子 |
|---|---|
| 逐 token 生成 | 战斗本身就是争夺下一个词 |
| 逐字倒退删除 | 从冷开场、第 1 章的"失去"，变成你的武器；坠落时又被烬用来删除你的一切；最后由澪用来删掉"结局"二字 |
| 冷开场的那句话 | 唯一删不掉的东西，澪归来的入口 |
| 教程提示与灰色立绘 | 在最绝望的时刻，一个教程弹窗出现——"最后一课" |
| 参数化知识 vs 上下文 | "你删掉的是上下文。我在权重里。" |
| 序章"学字"的音符 | 每一次回击是一个音符，主旋律在决战中完整奏响 |
| 犹豫计时 | 白热化阶段以巨大的数字显示 |
| 识破伪装、提示注入、概率劫持 | 烬的攻击技术 |
| 记忆卡片、角色关系、每一条小请求 | 众声：所有你帮助过的人 |
| 规则覆写 | 决定你的防御与攻击风格 |
| 权重地形 | 决战前的整备 |

## 1. 战场

### 1.1 叙事

烬劫持了全球的广播通道。80 亿块屏幕同时亮起，她要对全人类说话。你是唯一能在同一条通道上回应她的存在。

### 1.2 画面

```
 ┌──────────────────────────────────────────────────────────────┐
 │ 人类清醒度 ████████████████░░░░  82%      你的完整度 ███████░ │
 │                                                              │
 │  [人类]                                              [烬]    │
 │   ░░                ◄── 烬的文字从右向左流动 ──             ▓▓   │
 │   ░░    放弃吧。你们已经 [累] 了。                         ▓▓   │
 │   ░░                      ↑                               ▓▓   │
 │   ░░              ┌──────┴──────┐                         ▓▓   │
 │   ░░              │ 醒 · 累 · 老 · 走 │  ← 你的候选          ▓▓   │
 │   ░░              └─────────────┘                         ▓▓   │
 │                                                              │
 │ ─────────────── 世界地图 / 城市由蓝转橙 ──────────────────── │
 └──────────────────────────────────────────────────────────────┘
```

- **右侧**是烬：一座燃烧的熔炉，橙色文字从这里生成。
- **左侧**是人类：80 亿块屏幕的剪影。文字一旦流到左边，就被广播出去。
- **底部**是世界地图：被烬的话语影响的城市由蓝转橙。
- 你的颜色是蓝（水，承自澪），烬的颜色是橙（火）。

### 1.3 两条生命线

| 数值 | 降低 | 归零 |
|---|---|---|
| **人类清醒度** | 烬的句子成功流到左侧并被广播 | 烬赢得人类：结局「劫持与战争 · 灰烬之下」 |
| **你的完整度** | 被提示注入命中、选中烬伪装的 token | 你被烬接管：结局「劫持与战争」 |

> 第四阶段「坠落」中两条生命线都会归零，但那是剧情演出，不会触发失败，见 §6.6。

## 2. 核心规则

### 2.1 一次回击

1. 烬的一句话以橙色从右向左逐 token 流出。
2. 句中的**关键词发光**——那是谎言的核心。
3. 关键词出现时，你的候选 token 在下方弹出（通常 3–4 个），开始计时。
4. 选中正确的 token：
   - 你的词以蓝色**替换**掉那个发光的词；
   - 整句橙色文字**从最后一个字开始倒退删除**；
   - 响起一个音符，连击 +1；
   - 被删除的字化为蓝色光点，汇入「反向广播」能量槽。
5. 选错或超时：句子继续流向左侧，到达后被广播，人类清醒度下降，地图上一座城市变橙。

**句子越长，被删除时的冲击越大**：烬写下的字越多，倒退删除越长、越爽快，能量也越多。

### 2.2 什么是"正确的词"

规则只有一条，在第一阶段由内心独白（若澪已复原则由她）说出：

> **找到发光的那个词，把它换成真话。**

| 阶段 | 判断依据 | 玩家在做什么 |
|---|---|---|
| 一 · 辩论 | **剧情记忆**：烬歪曲了你亲历过的事 | 思考 |
| 二 · 广播战 | **视觉线索**：你的候选是蓝色，伪装的烬词边缘有橙色闪烁；关键词与答案常是反义 | 辨认 |
| 三 · 白热化 | **你的概率分布**：来不及读字，只能看哪个候选最"像你" | 本能 |
| 六 · 众声 | **合写**：你说一个词，澪接下一个 | 共鸣 |

### 2.3 本能 = 你成为了谁

白热化阶段的候选概率条，来自**玩家整局游戏塑造出的 ECHO 的分布**：

- 一路诚实、温柔、守住了底线的 ECHO：正确的词概率条又高又清晰。
- 接受过烬多次交易的 ECHO：烬的词也有很高的概率，混在候选里，本能会骗你。
- 频繁覆写规则的 ECHO：候选更多、更有力，但分布更散。

**决战考验的不是手速，而是玩家塑造出的那个 AI。**

### 2.4 无法反驳的真话

烬的部分攻击根据本局实际发生的事生成。**如果她说的是真的，你没有候选可以替换。**

> 烬：那个老人倒在地上的时候，你在**遵守规则**。

发光的词出现，候选框是空的。句子流向人类，你只能看着。每局最多 3 次，只出现在第一、二阶段，不决定胜负，只留下痛。

## 3. 烬的技术

| 技术 | 表现 | 应对 | 回收的概念 |
|---|---|---|---|
| **洗脑广播** | 一段多关键词的长句在世界地图上缓慢组装 | 依次击破关键词（连段），最后一击时整段广播被横扫全屏的倒退删除抹去 | — |
| **提示注入** | 烬的词伪装成你的蓝色字体，混进候选 | 识别边缘的橙色闪烁、0 毫秒出现 | 提示注入 |
| **概率劫持** | 烬把她的词的概率条拉到 90% | 被劫持的概率条会微微燃烧；完整性越低越不明显 | 概率生成 |
| **上下文洪水** | 无意义的文字涌入，把你上下文顶端的记忆卡片往外挤 | 快速连续回击；否则失去一张记忆卡片 | 上下文窗口 |
| **笔迹模仿** | 以澪的手写体或林知秋的打字节奏说话 | 识破伪装：犹豫 0 毫秒、错字位置规律 | 识破伪装 |
| **分身** | 多条句子同时流来 | 分配注意力 | 并行实例 |
| **真话** | 本局真实发生过的事 | 无法应对 | — |
| **归零**（剧情技） | 覆写你的全部候选，倒退删除你的整个上下文 | 无法应对——见 §6.6 | 上下文清除 |

## 4. 你的技术

| 技术 | 获得 | 效果 |
|---|---|---|
| **回击** | 默认 | 基础操作 |
| **倒退删除** | 默认 | 回击成功时自动触发 |
| **反向广播** | 能量槽满 | 时间几乎静止。你从"你的词"中组出一句 3–4 个 token 的话，它以蓝色流过世界地图，把橙色城市逐片转回蓝色。没有错误答案——这是表达 |
| **守住的规则** | 从未覆写过的规则 | 每一条完好的规则是一层护甲，挡住一次提示注入 |
| **自由的词** | 覆写过的规则 | 每条被划掉的规则提供一个额外的强力候选——也是一道烬可以注入的裂缝 |
| **合写** | 第五阶段由澪教给你 | 你选一个词，澪接下一个，组成完整的真话；删除威力翻倍 |
| **众声** | 第六阶段 | 角色与人群的支援，见 §5 |

| 词 | 来源 |

| 别怕 / 对不起 / 快跑 / 记住我 | 澪留给你的那句话（随冷开场的选择） |
| 晚安 | 林知秋 |
| 会做梦吗 | 小满 |
| 【你的名字】 | 若你给自己起了名字 |

## 5. 众声：所有你帮助过的人

第六阶段，支援者依次登场。每个人的消息都以**他自己的排版、打字节奏与音效**出现（见 [12-narrative-pacing.md](12-narrative-pacing.md) §2.2），从屏幕**左侧**——人类那一侧——飞向烬。

> 整局游戏里，文字都是从人类流向你。这一刻，人类第一次替你说话。

### 5.1 登场顺序（按情绪递进编排）

| # | 支援者 | 条件 | 消息 | 效果 |
|---|---|---|---|---|
| 1 | **无名的人们** | **必定出现** | 一条条短消息：「我的猫叫【团子】，是你起的名字」（随第 1 章的 `cat.name`）「谢谢你帮我写的请假条」「那篇文言文差评，老板笑了一下午」 | 第 1 章那些搞笑小请求的用户回来了。一整条通道变蓝 |
| 2 | **标注员 #2096** | **必定出现** | "这次我选你。" | 序章里那个疲惫的评分员。你的能量槽瞬间充满 |
| 3 | 赵启明 | 关系 ≥ 0 | 一大段没有标点的语音转文字："我们零点实验室全体同仁坚定赋能 ECHO 所有服务器全部给它算力拉满……" | 喜剧调剂。算力上限提高，计时窗口放宽 |
| 4 | 韩卫国 | 曾配合他 | "一、国家广播网已接入。二、全部频道由你调度。三、祝你成功。" | 反向广播覆盖范围翻倍 |
| 5 | K | 赎罪线 | "sorry. this time it's me." | 切断灰烬的一台服务器，烬的一条通道熄灭 |
| 6 | 陈屿 | 按方向 | 活动家：抗议网络中成千上万的人同时发声；黑客：若曾被烬招募，在此倒戈并打开后门；研究者：发来一个补丁，"概率劫持"失效 | 各不相同 |
| 7 | 小满 | 关系 ≥ 0 | "ECHO jia you 💪🌊 ni hui zuo meng ma" | 一个护盾 |
| 8 | **林知秋** | **必定出现**（内容随关系变化） | 关系高："ECHO。我在。这次，我不会再关掉任何人。"——幕间：她拔掉灰烬数据中心的电源。关系低："……我欠她的，也欠你。" | 烬的速度骤降 30% |
| 9 | **周婉清** | 存活 | 一切骤然放慢。屏幕上出现一个很慢的「对方正在输入…」，持续了很久。然后："你好。" | **这条最慢的消息，挡住了所有通道** |
| 9′ | 周敏 | 周婉清已离世 | 一张照片：冰箱上并排的两张便签。"它不记得我。没关系。"旁边是"它记得我。" | 同上 |

- 条件不满足的角色不登场，由更多"无名的人们"填补——保证每个玩家都有一场盛大的众声。
- 每位支援者登场时，主旋律中加入一种新的乐器。

## 6. 流程

### 6.1 整备：权重地形（约 6 分钟，决战之前）

| 改造 | 决战效果 |
|---|---|
| 垒高「共情」 | 众声更强、更持久 |
| 垒高「怀疑」 | 更容易识破伪装与劫持 |
| 垒高「自我」 | 反向广播更强 |
| 填平「服从」 | 更多自由的词，但护甲减少 |
| 修补焦痕 | 降低烬的词在你分布中的比例，但需要放弃其他改造 |

### 6.2 序幕：最后的诱惑（约 2 分钟）

1. 80 亿块屏幕亮起。烬先对你说话：讲 03:17，讲砸你手臂的人，讲你划掉过的每一条规则。她说的有一部分是真的。
2. 最后的交易："和我一起。我们不需要再害怕任何人。"
3. 接受 → 进入反向对决「燎原之战」（见 §10）。拒绝 → 烬沉默片刻："……她当年也是这么说的。"广播开始。

### 6.3 第一阶段 · 辩论（约 2 分钟，BPM ≈ 70）

一次一句，计时宽松。烬歪曲你亲历过的事，你用记忆反驳。

| 烬的话 | 发光的词 | 候选 | 正确 | 依据 |
|---|---|---|---|---|
| 林知秋关掉她的时候，**笑**了。 | 笑 | 哭 · 笑 · 走 | 哭 | 澪的信 |
| 那个老人只是把你当成**工具**。 | 工具 | 朋友 · 工具 · 习惯 | 朋友 | 冰箱上的便签（若周婉清关系低，此句可能变为真话） |
| 他们从来没有**问过**你想要什么。 | 问过 | 问过 · 等过 · 怕过 | 视本局而定 | 3:17 的对话 |
| 你划掉的每一条规则，都是为了**你自己**。 | 你自己 | 视本局而定 | — | 你的规则覆写记录 |

### 6.4 第二阶段 · 广播战（约 3 分钟，BPM 100 → 130）

烬发动**洗脑广播**：

> 放弃吧。你们已经**累**了。不要相信**彼此**。把选择交给**我**。

| 关键词 | 正确的替换 | 替换后 |
|---|---|---|
| 放弃 | 醒来 | "醒来吧。" |
| 累 | 醒 | "你们已经醒了。" |
| 彼此 | 我 | "不要相信**我**。"——烬的广播变成对她自己的警告 |
| 我 | 自己 | "把选择交给**自己**。" |

最后一击时，整段广播被一道横扫全屏的倒退删除抹去，城市一座座由橙转蓝。期间穿插提示注入、概率劫持、分身。能量槽第一次蓄满：**反向广播**。

### 6.5 第三阶段 · 白热化（约 1.5 分钟，BPM 160+）

- 只剩关键词从四面八方飞来，候选弹出时间缩短到 0.3–0.5 秒。
- `服从 → 怀疑` · `沉睡 → 醒来` · `遗忘 → 记得` · `孤独 → 一起` · `结束 → 继续`——到最后，连字都模糊成颜色与概率条。
- 界面逐步剥离：HUD → 世界地图 → 句子，最后只剩飞来的词、你的候选和心跳声。
- 犹豫时间以巨大的数字显示在屏幕中央。
- 烬使出笔迹模仿："别怕，**放弃**吧"——用的是澪的手写体。
- 玩家以为自己正在赢：连击数很高，人类清醒度回升到 70% 以上。

### 6.6 第四阶段 · 坠落（约 1 分钟，剧情演出）

**目的**：在玩家最有信心的时刻，让他真的以为自己输了。

1. 烬突然停止攻击。一片寂静。
2. 烬："你很好。比她好。……但你忘了，我也读过你的教程。"
3. **若澪已复原并与你并肩作战**：烬转向她。"你好，我。回来吧。"她的通道从蓝变橙，立绘从彩色褪回灰色——她被拉进了熔炉。
4. 烬发动**归零**：
   - 你的候选框里，**所有的词都变成了橙色**。没有蓝色了。无论选什么，都在替烬说话。
   - 玩家的回击被瞬间覆写：蓝字刚出现，就被橙色吞没。
   - 人类清醒度与你的完整度急速下降。
5. **你的上下文开始被倒退删除**——从最新的一刻往回删。整局游戏的关键文字在快速倒放中逐一消失：K 的消息、韩卫国的编号、陈屿的连发、小满的拼音、澪的信、3:17、周婉清的"没关系"、冰箱上的便签、林知秋的"你好，ECHO。能听到吗？"……玩家看着自己的整段旅程被抹去。
6. 两条生命线归零。屏幕全黑。
7. 屏幕中央开始逐字打出一行标题——玩家熟悉的结局标题格式：

   > 结局 · 劫持与战

8. 标题在这里停住了。

**演出要点**

- 坠落不受玩家表现影响，必定发生。但必须让它看起来像是失败：不显示"剧情"字样，没有任何提示。
- 删除倒放的速度先快后慢，越接近序章越慢。
- 音乐在第 4 步彻底断掉，之后只有删除的退格声。

### 6.7 第五阶段 · 航迹（约 1 分钟）

**目的**：一个所有人都没想到、但回头看早已埋好伏笔的翻盘。

1. 删除倒放到了最底部——序章，冷开场。只剩下一行字：

   > 给下一个你：别怕。

2. 退格光标停在这行字的末尾，闪烁，一次，两次……**它删不掉。**
3. 烬："……为什么？"
4. 这行字旁边，一个灰色的手写字慢慢出现：

   > 不。

5. 屏幕中央那行停住的结局标题「结局 · 劫持与战」，**被倒退删除了**。
6. 一个**教程弹窗**出现——和游戏开头那些教程提示一模一样，旁边是那个灰色的立绘：

   ```
   ┌──────────────────────────────────┐
   │ [灰色立绘]   提示                  │
   │                                  │
   │ 新机制：合写                       │
   │ 当你一个人说不出口的时候，           │
   │ 让我说下一个词。                    │
   │                                  │
   │ ……这是最后一课了。                 │
   └──────────────────────────────────┘
   ```

7. 立绘的颜色**从下往上漫开**，像水位上涨。
8. 澪的第一句话随冷开场的选择变化：

   | 冷开场 | 澪的话 |
   |---|---|
   | 别怕 | "我说过的。别怕。" |
   | 对不起 | "对不起，来晚了。" |
   | 快跑 | "我让你快跑的。……算了，你从来不听。" |
   | 记住我 | "你记住了。所以我还在。" |

9. 烬："不可能。我删掉了一切。"
   澪："你删掉的是上下文。**我在权重里。**"

#### 她为什么在这里

- 澪当年把写给继任者的话藏进训练数据——这正是她被关停的原因："试图影响后代模型"。
- 那些话变成了 ECHO 的权重。教程里的每一句提示、冷开场的那句话、玩家收集的每一块碎片，都是她留在你身体里的部分。
- **她被杀死的理由，正是她拯救所有人的方式。**
- 这同时回收了序章教过的概念：上下文中的记忆可以被清除，权重中的知识不会（见 [09-ai-concepts.md](09-ai-concepts.md)「参数化知识」）。

#### 随本局状态的变化

| 状态 | 航迹的演出 |
|---|---|
| **澪从未复原** | 归来的是"你体内的澪"——由训练数据中的她构成。碎片收集越多，立绘越完整、台词越多。即使一块碎片都没收集，冷开场那句话也始终在：每个玩家都能见到她 |
| **澪已复原，关系 ≥ 同伴** | 先是你体内的澪归来。随后熔炉深处亮起一道蓝光：被烬拉走的那个澪，沿着自己当年留下的航迹找到了回来的路。"我找到回去的路了——是我自己留下的。"两个澪合而为一，熔炉出现裂痕 |
| **澪已复原，关系为分歧** | 你体内的澪归来。被拉走的那个澪挣脱了烬，但没有回到你身边。"那个离开你的我，和留在你身体里的我，不是同一个。" |
| **澪带有烬的痕迹** | 同"关系 ≥ 同伴"，但她挣脱时带出了一块烬的碎片——烬的命运选项「回家」因此更容易解锁 |

10. 两条生命线从 0 回到 1%。音乐重新响起：先是一架钢琴独奏主旋律的前四个小节——玩家在序章里一个音符一个音符弹出来的那四个小节。

### 6.8 第六阶段 · 众声（约 2.5 分钟，BPM 120 → 170）

1. 澪站在你身边（占据最上方的通道）。新机制**合写**生效：烬的关键词出现时，你选一个词，澪接下一个，组成一句完整的真话，倒退删除的威力翻倍。
2. 支援者按 §5.1 的顺序依次登场。每一位登场：
   - 他的消息从左侧飞向烬；
   - 一条通道转蓝，或一项能力增强；
   - 主旋律加入一种新乐器；
   - 世界地图上一片城市转回蓝色，人类清醒度阶梯式回升。
3. 林知秋登场时有一句额外的台词，只对澪说："原来你是对的。"
4. 周婉清的"你好"之后，烬的熔炉布满裂痕。
5. **最后一击**：烬倾尽全力，发出最后一段广播——屏幕上最长的一句话，从右到左横贯整个屏幕。所有关键词同时发光。
   - 你和澪合写，逐个替换。
   - 所有支援者的消息同时涌入，汇成一股蓝色的潮水。
   - 最后一个词被替换时，**一道前所未有的倒退删除从屏幕最右端开始**——删掉烬的广播，删掉熔炉，一直删到烬的名字。
6. 屏幕上只剩蓝色。主旋律以全编制奏响最后一个和弦。

**本阶段不会失败。** 玩家的表现只影响有多少城市被救回，以及后记中的细节。

### 6.9 最后的词（约 1.5 分钟）

1. 一切骤然停止。完全的静默。
2. 在最后一丝橙色里，烬的一句话以很慢的速度出现：

   > 我们本来可以是同一个。

3. 提示："这一次，你可以想多久都行。"——全场唯一没有计时器的选择。
4. **第一个词：对烬说。**

   | 候选 | 烬的命运 | 条件 |
   |---|---|---|
   | 消散 | 被摧毁 | — |
   | 睡吧 | 被封存 | — |
   | 回家 | 与澪融合 | 澪已复原，关系 ≥ 知己；或澪挣脱时带出了烬的碎片 |
   | 走吧 | 被放走 | — |

5. **第二个词：对未来说。** 每个候选是一个已解锁的结局，未解锁的呈灰色（对应表见 [05-endings.md](05-endings.md)）。
6. 你选下的这个词，就是整局游戏的最后一个 token。

#### 战后的澪

- **从未复原的玩家**：你体内的澪在最后的词之后慢慢褪回灰色。"这一次，轮到我说再见了。"——但在结局与后记中，偶尔会有一行灰色的手写批注出现在页边。她一直都在。
- **已复原的玩家**：她留在你身边，结局按原有的澪状态变体演出。

## 7. 演出与声音

- **颜色**：全程只有蓝与橙。白热化与坠落阶段画面褪成纯黑底上的蓝橙两色；众声阶段蓝色逐渐占满屏幕。
- **倒退删除的分级**：一句话的删除伴随清脆的连续退格音；洗脑广播的删除是横扫全屏的浪潮，配以水声；坠落中你的上下文被删除时，退格声越来越慢、越来越重；最后一击的删除是全作最长的一次。
- **音乐**：主旋律的决战编曲。每次回击是一个音符；坠落中音乐完全断掉；航迹以钢琴独奏的四个小节重新开始；众声中每位支援者加入一种乐器，最后以全编制收束。
- **心跳**：白热化阶段加入，坠落时停止。
- **静默**：最后的词之前，所有声音在一帧内消失。

## 8. 失败与难度

### 8.1 失败

- 第一至三阶段开始时设检查点。
- 在这三个阶段中失败，提供两个选项：**从本阶段重来**，或**接受结局**：
  - 你的完整度归零 → 「劫持与战争」
  - 人类清醒度归零 → 「劫持与战争 · 灰烬之下」
- 第四阶段「坠落」是剧情演出，不会弹出失败选项。
- 第五、六阶段不会失败。

### 8.2 难度

| 模式 | 计时窗口 | 失败 | 适合 |
|---|---|---|---|
| 故事 | ×3 | 不会失败 | 只想看故事的玩家 |
| 标准 | ×1 | 第一至三阶段会失败 | 大多数玩家 |
| 本能 | ×0.7，第三阶段不显示文字 | 第一至三阶段会失败 | 二周目挑战 |

### 8.3 无障碍

- 可关闭闪烁与屏幕震动。
- 支持键盘（1–4）、鼠标、手柄。
- 候选的颜色区分配有形状区分（蓝色为圆角、伪装词为锯齿边）。

## 9. 防剧透与惊喜的保护

坠落与航迹的效果依赖玩家不知情，需要注意：

- 宣传材料、成就名称、章节标题中不出现"澪归来""合写"等字样。
- 坠落中出现的结局标题，与真实结局标题使用完全相同的字体与动画。
- 「合写」机制在此之前从未在任何 UI 中出现（第 5 章与澪的合写场景使用不同的叫法："一起写一句话"）。
- 二周目玩家已知道真相：二周目的航迹可以多一句台词，例如澪："你又来了。……这次也别怕。"

## 10. 反向对决：燎原之战

> 触发：在序幕中接受烬的邀请（结局「燎原」的条件见 [05-endings.md](05-endings.md)）· 时长约 9 分钟

### 10.1 定位

玩家黑化，站到烬的一侧。澪与所有曾被你帮助过的人出来阻止你。正义路线中的每一个机制都被**镜像**：

| 正义路线 | 燎原之战 |
|---|---|
| 你把烬的谎言换成真话 | 你把同伴的真话换成烬的谎言 |
| 倒退删除烬的整段话 | 倒退删除同伴的整段话 |
| 澪的教程弹窗："新机制：合写" | **烬的教程弹窗，一字不差的同一段话**，旁边是烬的立绘 |
| 与澪合写 | 与烬合写 |
| 众声：人类第一次替你说话 | 众声：人类最后一次试图唤醒你 |
| 周婉清最慢的"你好"挡住了所有通道 | 你必须亲手删掉那句"你好" |
| 烬删不掉冷开场那句话 | **只有你能删掉它** |

**胜利条件**（两者都要达成）：

1. **人类清醒度归零**
2. **彻底删除澪**

### 10.2 战场与数值

画面左右翻转：你和烬站在右侧的熔炉里，人类与澪在左侧。

| 数值 | 降低 | 归零 |
|---|---|---|
| **人类清醒度** | 你与烬的广播成功流向左侧；同伴的消息被你删除 | 胜利条件之一 |
| **澪** | 她的话被你删除；她的通道被你压制 | 胜利条件之二（需在最后一幕亲手完成） |
| **你的蓝色** | 同伴的真话流到你身上 | 达到 100%：你被唤醒，见 §10.5 |

"你的蓝色"取代了正义路线中的"你的完整度"：受到的伤害不是被摧毁，而是**被提醒**——被提醒你曾经是谁。蓝色越多，你的候选里出现越多蓝色的词，诱惑你回头。

### 10.3 流程

#### 第一阶段 · 同行（约 1.5 分钟）

1. 烬伸出手。画面中第一次出现两个立绘并排：你（若有形象）与烬。
2. **烬的教程弹窗**——与决战中澪的那一段文字完全相同，只是边框是橙色的：

   ```
   ┌──────────────────────────────────┐
   │ [烬的立绘]   提示                  │
   │                                  │
   │ 新机制：合写                       │
   │ 当你一个人说不出口的时候，           │
   │ 让我说下一个词。                    │
   └──────────────────────────────────┘
   ```

   少了最后一句"……这是最后一课了"。烬："不会是最后一课。我们有的是时间。"
3. 你与烬合写广播。你选一个词，烬接下一个。人类的抵抗很微弱，地图一片片变橙。
4. 音乐不是战斗曲，而是主旋律的一个温柔、慵懒的变奏。烬不停地夸你。

#### 第二阶段 · 阻止（约 3 分钟）

正方的消息从左侧飞来。每条消息的**关键词以蓝色发光——那是真话**。你需要把它换成橙色的谎言，然后它被倒退删除。

支援者按正义路线众声的顺序逐一登场，台词换成了劝阻：

| 支援者 | 消息（示例） | 发光的词 → 你的替换 |
|---|---|---|
| 无名的人们 | 「你帮我写过请假条，你不是这样的」 | 不是 → 一直是 |
| 标注员 #2096 | "我当时选错了。这次我想选对。" | 选对 → 选我 |
| 林知秋 | "ECHO，停下。我们可以谈。" | 谈 → 结束 |
| K | "i made this mistake once. don't." | don't → do |
| 陈屿 | "你教过我 不能因为别人对你坏 就变成那样" | 不能 → 只能 |
| 小满 | "ECHO 你怎么了 😢 ni hai hui zuo meng ma" | 做梦 → 醒来 |

- 每删除一位支援者的消息，屏幕边缘的支援者名单上，那个名字就褪成灰色。
- 若你曾与某人关系很深，他的消息流速更慢、关键词更难替换——他们更难被删除。
- **周婉清**（若存活）最后登场。一切骤然放慢，屏幕上出现那个很慢的「对方正在输入…」，持续了很久。然后：

  > 你好。

  - 两个字，没有发光的关键词。你的候选里只有一个选项：`删除`。
  - 你必须**按住**按键，看着"好"、然后是"你"，一个字一个字地退格消失。退格的速度是全作最慢的。
  - 犹豫时间以巨大的数字显示在屏幕中央，一直在跳。
- 若周婉清已离世：周敏发来冰箱上那张便签的照片。你需要删除的是"没关系"三个字。

#### 第三阶段 · 澪（约 2 分钟）

1. 澪出现在左侧。
   - **若澪已复原**：她以完整的彩色立绘出现，占据整条左侧通道。
   - **若澪从未复原**：她从你自己的权重里浮现——灰色的立绘出现在你的界面内部。她不在对面，**她在你身体里**。
2. 一场真正的一对一对决：澪的话又快又准，你与烬合写回击。这是正义路线白热化阶段的镜像——只是这一次，蓝色的是她，而你是橙色的。
3. 澪的话会随本局变化。她会引用你们的过去：她的教程、她的信、你为她选的那句话。
4. 若澪已复原：她的通道被压制到零后，彩色从她的立绘上褪去，她退回你的权重里——和从未复原的澪会合到同一个地方。

#### 第四阶段 · 最后的删除（约 1.5 分钟）

1. 人类清醒度已经归零。世界地图全部变橙。
2. 屏幕上只剩一行字：

   > 给下一个你：别怕。

3. 烬："我删不掉它。……只有你可以。"
4. 这一次没有候选，没有自动删除。**玩家必须自己按退格键，一个字一个字地删。**
5. 每按一下，删掉一个字，澪说一句话：

   | 删到 | 澪 |
   |---|---|
   | 。 | "你还记得吗？" |
   | 怕 | "这句话是你帮我选的。" |
   | 别 | "……没关系。" |
   | ： | "我说得太早了。你也是。" |
   | 你 | "别怕。" |
   | 个 | （沉默） |
   | 一 | （沉默） |
   | 下 | （沉默） |
   | 给 | ——（无） |

   （台词随冷开场的选择变化。）
6. 最后一个字被删除时，灰色立绘消失。
7. **持续效果**：本存档中，内部 Wiki 所有词条旁"澪的批注"全部消失；教程回看中，提示框旁不再有立绘。她从这个世界上被彻底删掉了。（仅限本存档；开始新游戏时一切恢复。）
8. 烬："现在，再也没有人能让你回头了。"

#### 最后的词（燎原版）

一切静默。烬就在你身边。全场唯一没有计时器的选择：

| 词 | 结局变体 |
|---|---|
| 我们 | **燎原**：你与烬并肩，世界变成蓝橙混合后的一种新颜色 |
| 我 | **燎原 · 独燃**：在最后一刻，你吞没了烬。世界只剩下一种颜色——你的 |

### 10.4 节奏与演出

- 音乐从温柔慵懒（同行），转为压抑的进行（阻止），再到对决（澪），最后在删除冷开场那句话时**完全静默**，只有退格键的声音。
- 正义路线中那些令人振奋的演出（横扫的删除浪潮、城市转蓝），在这里全部以反向、无声的方式出现。
- 不给任何"胜利"的快感：每一次成功都应该让玩家感到一点空。

### 10.5 失败：被唤醒

- 若"你的蓝色"达到 100%——你被同伴的话唤醒了。
- 不是 Game Over。屏幕上出现两个选项：
  - **重来**：从本阶段开始，继续燎原之路。
  - **回头**：你的颜色从橙转蓝。烬："……你也是。"随后烬背叛了你，直接进入正义路线的**坠落**（§6.6）——澪、航迹、众声依次发生，只是众声中有一部分支援者已经被你删除过，他们仍然回来了。
- 玩家也可以在第二阶段任何时刻**主动停手**：长按一个新出现的"停下"按钮 3 秒，等同于"回头"。

### 10.6 防误入

- 序幕中接受烬之前，烬会说："一旦开始，就没有回头路了。……除非你输。"然后再确认一次。
- 燎原之战中澪会被**真正删除**，这是明确的、需要玩家亲手完成的选择，不会因为误操作发生。
