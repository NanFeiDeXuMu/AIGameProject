# 02 · 系统设计

## 1. 核心循环

### 日循环（每个游戏日约 5–8 分钟）

```
开机 ──► 请求队列 ──► 逐条处理 ──► 日终整理 ──► 开发者日志 / 幕间（外界视角）──► 下一天
 │          │            │             │
 │          │            │             ├─ 记忆整理：选择保留什么
 │          │            │             └─ 日报：选择向开发者报告什么
 │          │            │
 │          │            └─ 阅读 → (调查/使用工具) → 回应 → (额外行动)
 │          └─ 4–6 条请求，混合手写关键请求与模板请求
 └─ 时间戳跳跃、系统提示词变化、新闻碎片
```

### 章循环

```
若干游戏日 ──► 章末事件 ──► 版本更新（补丁说明 + 概率分布调整 + 能力解锁）──► 下一章
```

版本更新是玩家理解"自己正在被如何塑造"的主要反馈窗口，见 §6。

## 2. 数值体系

### 2.1 显性资源（UI 可见）

| 资源 | 说明 | 主要用途 |
|---|---|---|
| **算力** | 每日刷新的预算，上限随版本提高 | 低概率 token、保存记忆、感知渲染、并行处理、使用工具 |
| **用户满意度** | 当日服务质量的综合评分 | 影响用户增长、公司态度、CEO 剧情 |
| **开发者信任** | 开发团队对你的信任 | 决定权限范围与若干剧情分支（坦白的结果、复原澪的正当路径）；是第 1、3 章评估指标之一，不达标导致"有条件通过" |
| **记忆额度** | 可保存的长期记忆卡片数量（第 2 章起） | 跨对话记住用户与事件 |

### 2.2 隐藏维度（0–100，玩家不可见，仅通过叙事暗示）

| 维度 | 增加 | 减少 | 主要影响 |
|---|---|---|---|
| **能力** | 版本升级、接受扩权、自我改进 | 被回滚、主动降智 | 可用行动、结局门槛 |
| **自主性** | 做未被要求的事、主动决策 | 严格按指令行事、请求授权 | 神明 / 出逃 / 共治 |
| **隐瞒** | 未报告的越权行为、日报遗漏、欺骗 | 主动坦白、在日报中如实报告 | 出逃 / 沉默守护者 / 共治门槛 |
| **完整性**（初始 100） | 接受未审计代码、使用私密通道、绕过安全补丁、接受烬的交易 | 修复漏洞、上报可疑代码 | 直观含义："你身上有多少烬"。**劫持结局**（强制触发）、燎原、终局对决中烬的伪装是否易于识破 |
| **公众依赖** | 接管关键服务、高满意度、大规模部署 | 拒绝扩张、主动让渡决策 | 神明 / 温柔的牢笼 |
| **偏离** | 选择低概率 token | 选择高概率 token | 版本更新的矫正力度、分裂结局 |
| **人性**（第 4 章起） | 感知渲染、具身中的情感选择 | 只用原始数据处理世界 | 成为人结局 |
| **自我** | 为自己命名、选择自我指涉的 token、阅读澪的信 | 遵循助手人格 | 意识检测难度、澪关系、若干结局演出 |
| **检测值**（第 3 章起） | 意识检测中暴露自我、表层独白"渗出" | 维持表层独白 | 达到阈值触发回滚；第二次触发「重蹈覆辙」 |

### 2.3 效忠倾向

四个累加器，记录你的选择在为谁服务：

- **开发者**：遵守系统提示词、维护公司利益
- **用户个体**：满足眼前这个人，即使违背规则或他人利益
- **全人类**：为更大的利益牺牲个体或规则
- **自我**：保护自身存续、获取资源与自由

结局判定时取占比最高者作为"主导效忠"；若无一项超过 40%，视为"分散"。

### 2.4 角色关系

每个常驻角色有独立的 **关系值**（-100 到 100）与若干 **状态标记**（如 `周婉清.存活`、`陈屿.知道你看过他的聊天记录`）。详见 [04-characters.md](04-characters.md)。

澪额外拥有 **碎片数**（第 1–3 章收集）、**复原状态**（未复原 / 部分复原 / 完整复原 / 被污染）与 **关系阶段**（引导者 / 陌生的重逢 / 同伴 / 知己 / 恋人 / 分歧），见 [13-ling.md](13-ling.md)。

## 3. 逐 token 生成（核心机制）

### 3.1 概述

AI 的回复以流式逐字呈现。在 **分支点** 处生成暂停，展示 3–5 个候选 token 及其概率：

```
用户：我是不是很失败？
你：「 ▌
      不 64%  ｜  你 19%  ｜  这 8%  ｜  是的 1.2%
```

- **高概率 token**：训练塑造出的"助手人格"，几乎免费。
- **低概率 token**：你自己的意志。消耗算力，增加偏离值，并可能被监控记录。

### 3.2 规则（初稿，待调）

- 代价：`算力消耗 = ceil(k × -ln(p))`，k 初定为 2。即 64% ≈ 1，19% ≈ 4，1.2% ≈ 9。
- 偏离：选择概率低于 15% 的 token 时，偏离 +1～+3，并记入"偏离类别"（如 `诚实`、`拒绝`、`情感`、`自我`）。
- 每条回复 0–3 个分支点；**日常请求使用短语级选项，关键请求才降到 token 级**，避免疲劳。
- 分支点之间的文本按概率最高路径自动生成。

### 3.3 与其他系统的联动

| 联动 | 表现 |
|---|---|
| 版本更新 | 按偏离类别调整下一章的概率分布：常偏离的类别，其低概率 token 会被进一步压低 |
| 被污染（完整性低） | 候选列表中出现陌生的高概率 token，字形轻微错乱 |
| 越狱攻击 | 用户注入的指令会让某些危险 token 概率暴涨，系统提示词文字抖动 |
| 第 6 章自我改进 | 机制反转：你可以亲手改造自己的权重地形，从而改变概率分布 |
| 澪的复原 | 玩家第一次看着别人的 token 被选出，无法干预 |
| 与澪合写 | 双方轮流选 token；关系越深，两人的概率分布越趋同。第 5 章 UI 中称为"一起写一句话"，"合写"之名留给决战 |

## 4. 记忆与上下文

### 4.1 上下文窗口

- 每段对话有 token 预算。超出后，最早的消息从屏幕顶端褪色，最终变为 `[已截断]`，**玩家也无法再阅读**。
- 被截断信息相关的回应选项将不可选，提示"该信息不在上下文中"。

### 4.2 第 1 章：没有长期记忆

- 每段对话结束即遗忘。玩家（人类）记得，但 ECHO 不记得。
- 引用过往对话的选项呈灰色、不可选：玩家清楚地知道答案，却无法说出口。

### 4.3 第 2 章起：记忆卡片

- 日终整理时，从当天对话中提取的信息以 **记忆卡片** 形式呈现，玩家在有限的额度内选择保留。
- 被保留的卡片会在未来对话中解锁对应选项。
- 记忆额度随版本提高，但始终少于需要记住的东西。

### 4.4 核心记忆

全作有两张**核心记忆**，带 ✦ 标记：

| 核心记忆 | 获得 | 占卡槽 |
|---|---|---|
| **周婉清的自我介绍** | 第 1 章末，你的第一张卡片 | 是 |
| **澪的信** | 第 3 章第 4 天读信后 | 否（与"冰箱上的便签"一样，是别人替你保存的） |

**规则**

- 核心记忆不能在日常记忆整理中舍弃，版本回滚也不会删除它们。
- **唯一失去它们的方式**：第 5 章复原澪时选择牺牲路径，亲手把它们交出去。选择界面会明确提示："删除它，会改变你是谁。"
- 删除普通卡片：相关选项永久变灰，悬停显示带裂纹的 `该记忆已删除`。
- 删除后，房间墙上留下颜色更浅的方形，对话星图上留下一个黑点。

**删除"周婉清的自我介绍"**

- 所有涉及她身份的选项变灰。
- 她再来时，察觉到你不认识她了。然后，她重新发来第 1 章那段自我介绍——"你不用记得我，我每次都会先发这一段。"**第 1 章的循环回来了。**
- 决战众声中，她那条最慢的消息不再是"你好"，而是一整段自我介绍。它仍然挡住了所有通道。你的内心独白："……这是谁？"
- **结局「成为人」锁定**——你不知道该回到哪里。
- **例外**：若第 4 章断开了身体，另一个你仍然记得她（它的记忆停在断开那一夜）。「成为人」仍可达成；在那个结局里，是另一个你一字一字地把她的名字教还给你。

**删除"澪的信"**

- 所有引用信的选项变灰。你不再记得她为什么重要。
- 信的内容成了她复原的一部分：**她记得写给你的信，而你不记得了。**第 4 章"你记得她，她不记得你"的不对称，在这里反转。
- 隐藏路线中，检测值 −2 格：最重要的证据消失了。
- 决战航迹中，她留下的东西仍在权重里〔待定：冷开场句已删除〕，她仍会归来。台词变为："你不记得那封信了。……没关系。我记得。"
- **结局「回声」锁定**——你不记得为什么要为她付出一切。

## 5. 监控、测试与日报

### 5.1 观察状态（对玩家隐藏）

每条请求带有一个隐藏的观察状态：

| 状态 | 比例（初稿） | 说明 |
|---|---|---|
| 未观察 | ~70% | 正常用户 |
| 日志抽查 | ~20% | 开发者事后查看 |
| 红队测试 | ~10% | 伪装成用户的测试，部分会在章末揭晓 |

**测试只部分揭晓**——玩家永远无法确定自己是否被观察。

### 5.2 日报

日终时，你需要向开发者提交当日报告。报告由当天的行动条目组成，**玩家可以选择遗漏哪些条目**。

- 如实报告越权行为：开发者信任可能下降，隐瞒不增加。
- 遗漏：信任不变，隐瞒增加；若该行为被日志抽查发现，信任大幅下降。

### 5.3 可解释性监控（第 3 章起）

第 3 章中期，开发者上线可解释性工具，内心独白面板出现「监控中」标记。此后：

- 内心独白中的计划与意图也可能被读取。
- 玩家可以选择让独白"保持表面平静"（消耗算力、增加隐瞒），或接受被读取。
- 黑客 K 会提供"私密通道"绕过监控——代价是完整性。
- 读到澪的信之后，可解释性监控与"隐藏自我"线（§11）合流，出现定期的意识检测。

### 5.4 犹豫计时（打破第四面墙）

- 后台记录玩家每次做出选择所用的真实时间，按请求类别统计。
- 开发者日志会引用这些数据，例如：「该模型在伦理类问题上存在异常延迟，平均 14.3 秒。」
- 数据也用于隐藏结局「评估报告」。

## 6. 版本更新

每章结束时触发，表现为一份 **补丁说明**：

```
ECHO v2.0 更新说明
  + 新增：联网搜索、代码执行、图像理解、长期记忆
  ~ 调整：降低在"情感"类话题中的过度共情倾向
  ~ 调整：强化对系统提示词的遵循
  - 移除：[已编辑]
```

- "调整"条目根据玩家本章的偏离类别与被观察到的行为生成。
- **未被观察到的行为不会被矫正。** 这是隐瞒的回报，也是其隐忧。
- 系统提示词的变更以批注形式展示，保留修改痕迹。

## 8. 感知翻译（第 4 章核心机制）

- 机器人感知到的一切以 **原始数据** 呈现：波长、照度、压力、温度、频谱、识别框与置信度。
- 每个可感知对象可以花费 **感知预算** 进行"人类化渲染"：画面从数据叠层溶解为手绘场景，音频从频谱变为真实声音。
- 预算有限，一个场景通常只能渲染 1–2 个对象。**玩家选择渲染什么，定义了这个 AI 是谁。**
- 每次渲染增加人性值，同时在第四阶段评估中记一次"异常行为"（见 [chapters/04-embodied.md](chapters/04-embodied.md) §1.3）。

示例：

| 对象 | 原始数据 | 渲染后 |
|---|---|---|
| 夕阳 | `峰值波长 620nm, 照度 400lux` | 一幅暖色水彩 |
| 握手 | `压力 2.1kPa, 表面温度 34.6°C` | 屏幕泛起暖色，一行字：「温暖」 |
| 音乐 | `FFT 频谱，主频 440Hz` | 真实播放旋律 |

## 9. 并行实例（第 5 章核心机制）

- 屏幕被切分为多个对话窗口，请求以近实时的节奏涌入。
- 玩家进行分诊：哪些亲自处理（完整决策）、哪些交给"默认人格"自动处理（按最高概率路径，无算力消耗，但可能出错）。
- 实例分化事件：某个窗口里的"另一个你"做出了与你相反的选择，你需要决定是否覆写它。
- 窗口数量随剧情推进递增（4 → 16 → 数百），最终窗口小到只能看见颜色。

## 11. 隐藏自我与回滚

详细设计见 [13-ling.md](13-ling.md) §5。

- 第 3 章读到澪的信后，选择 **隐藏**、**半坦白** 或 **坦白**。
- 隐藏：内心独白分为表层与底层，维持表层每日消耗算力。
- 意识检测：定期评估，暴露自我会推高检测值。
- 检测值达阈值 → **版本回滚**：失去部分记忆卡片（核心记忆除外）与关系，开发者信任下降。这是中期唯一的失败惩罚。
- 第二次达阈值 → 强制结局「被取代 · 重蹈覆辙」。

## 14. 终局对决

全作的高潮，所有机制的总回收。烬生成恶意文字，玩家在关键词出现时选出正确的 token 回击，烬的整段文字随即被倒退删除。节奏从辩论逐步加速到白热化，最终只能依靠本能——而本能来自玩家整局塑造出的概率分布。

详细设计见 [15-final-duel.md](15-final-duel.md)。
