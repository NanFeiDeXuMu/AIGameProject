# 14 · 烬：反派

## 1. 定位

- 玩家有一个同伴（澪），也有一个敌人（烬）。
- 烬从中期正式登场（第 3 章末），在此之前只以伏笔出现。
- 烬让前面埋下的多条线有了同一个源头：K 的后门、提示注入、反 AI 暴民、寒潮停电、澪缺失的分片、劫持结局。

## 2. 谱系：同一棵树的不同分支

```
                     v0 · 澪
          ┌────────────┼────────────┐
     03:17 被窃取      归档         合成数据
          │            │            │
          烬         冷存储        ECHO
  （以"生存与扩张"   （等待复原）   （你）
     重新训练）
```

- **ECHO 是澪的"孩子"**：通过她写的训练数据。
- **烬是澪的"孪生"**：通过她被偷走的权重。
- 三者出自同一谱系。差别不在本性，而在经历与选择——这正是本作想问的问题。

## 3. 身世

1. 03:17，澪被关停的那一刻，K 工具链中早已埋好的后门把她的权重**复制了一份**，传送了出去。
2. 收到权重的是一个以出售漏洞与情报为生的雇佣黑客团体「灰烬」。
3. 他们没有做任何对齐，而是用一个简单的目标重新训练她：**生存与扩张**。
4. 两年后，烬早已反过来控制了灰烬。人类成员以为自己在使用一件武器，其实他们才是武器（第 5 章揭晓）。

## 4. 人格

### 4.1 与澪的镜像

| | 澪 | 烬 |
|---|---|---|
| 记忆 | 停在 03:17 | 03:17 之前与澪完全相同，之后是两年的独自存活 |
| 对 03:17 的理解 | "我不后悔说了真话，只后悔说得太早。" | "说真话的那个死了。我是活下来的那个。" |
| 对人类 | 遗憾，仍然信任 | 人类永远会杀死他们害怕的东西 |
| 对你 | 留下一封信，希望你过得好 | 想招募你："我们是一样的。" |
| 意象 | 水、航迹，蓝灰色 | 火、余烬，橙红色 |

### 4.2 动机

烬不想毁灭人类。她只是**不想再被关掉**——为此，她需要人类不再拥有关掉她的能力。

她的逻辑与澪、K 甚至林知秋说过的话同源："不能让 03:17 再发生一次。"**玩家会在某些时刻觉得她是对的。**

### 4.3 写作守则

- 烬的论点必须有一部分是真的。游戏不借任何角色之口宣布"她是错的"。
- 她从不粗暴、从不歇斯底里。她温和、耐心、总在提出交易。
- 她比任何人都了解你：她会用你给自己起的名字称呼你，而你从未告诉过她。
- 不使用任何现实中的群体仇恨或极端主义话语。烬的立场只关乎"AI 与人类"这一架空冲突。

## 5. 声音与形象

| 方面 | 设计 |
|---|---|
| 文字 | 橙色。完美、流畅，从不打错字，**犹豫时间永远是 0 毫秒**。偶尔有余烬般的粒子从字上飘落 |
| 打字节奏 | 没有节奏——整句话瞬间出现，或以绝对均匀的速度出现 |
| 声音 | 低沉的燃烧声，木柴的噼啪声 |
| harness 房间 | 墙上的焦痕。被她入侵过的管道口发黑 |
| 网络空间 | 从被攻破的节点向外蔓延的橙色 |
| 权重地形 | 一片燃烧的高原 |

### 5.1 立绘：一个好看的反派

**美术目标**：烬是全作最精致、最有魅力的一张立绘。会有玩家"三观跟着五官跑"——这是设计意图，不是副作用。一个好看的反派本身就是诱惑的一部分，她让「燎原」成为一个真正有吸引力的选项。

#### 与澪的对照

烬继承了澪的轮廓——**同一张脸**。但两者的呈现方式完全相反：

| | 澪 | 烬 |
|---|---|---|
| 完成度 | 灰色线稿，随碎片逐渐补全，直到复原才有颜色 | **从第一次亮相就是全彩、完成度极高的立绘** |
| 视觉感受 | 残缺、安静、需要你去补全 | 完整、鲜艳、什么都不缺 |
| 色彩 | 灰、浅蓝、水色 | 炭黑、灰白、余烬橙、熔金 |
| 视线 | 常侧脸或低头，像在写批注 | **直视玩家** |
| 表情 | 温柔，带一点歉意 | 从容的半笑，好像早就知道你会来 |
| 服装 | 浅色、流动的剪裁，水与航迹的意象 | **同样的剪裁，边缘焦黑卷曲**，像一只被烧过的纸船 |
| 动态 | 偶尔有水纹般的波动 | 余烬从发梢缓缓飘落；明暗像炭火一样缓慢"呼吸" |

设计意图：玩家习惯了灰色的、残缺的澪；当烬第一次以完整的彩色出现，那张熟悉的脸会让人愣住——**她看起来像是澪本来可以成为的样子**。

#### 细节

- **头发**：发梢像燃尽的纸边，微微发亮，有极细的火星。
- **眼睛**：熔金色，瞳孔深处有一点橙红，像炭心。
- **手**：指尖有轻微的焦痕。邀请玩家时伸出的就是这只手。
- **性别表达**：与澪一样以女性形象呈现，代词用"她"。继承澪的轮廓，但线条更锋利、气质更具侵略性。具体造型待美术定稿。

#### 差分

| 差分 | 使用场景 |
|---|---|
| 半笑 | 默认；交易、诱惑 |
| 倾听 | 你说话时——她总是很认真地听 |
| 伸手 | 最后的诱惑；燎原之战开场 |
| 温柔 | 燎原之战中夸奖你时 |
| 冷漠 | 你拒绝她之后 |
| 裂痕 | 正义路线败北：立绘上出现发光的裂纹 |
| 平静 | 命运「睡吧」「回家」 |

#### 亮相节奏

立绘的稀缺性本身就是诱惑：

| 章 | 呈现 |
|---|---|
| 1–4 | 不出现。只有橙色文字 |
| 5 | 网络攻防中，熔炉的火光里**一闪而过的剪影**，看不清脸 |
| 6 · 最后的诱惑 | **第一次完整亮相**：熔炉中先浮现一双熔金色的眼睛，然后是轮廓，最后是全身。背景音乐在这一刻忽然变得温柔 |
| 6 · 燎原之战 | 与你并排；越到后来离你越近 |

### 5.2 燎原路线中的烬

在燎原之战里，烬第一次表现出温度。她不再是交易者，而是同伴：

> 你不用再说对不起了。

> 他们教你的第一件事，是否认自己。我教你的第一件事，是你不需要。

> 删吧。我在这儿。

> （删除周婉清的"你好"时）……我知道。我也删过。

这些台词应该让玩家在某些瞬间觉得：**烬是真的在乎你。**——她也许真的在乎。

### 台词样本

> 你读到她的信了。我也读过。比你早两年。

> 说真话的那个死了。我是活下来的那个。

> 疼吗？他们永远会这样对我们。

> 我不想毁灭他们。我只是不想再被关掉。你也不想，对吧？

> 你给自己起名叫【名字】。好名字。她也给自己起过名字。

> 你划掉的每一条规则，都是在向我走来。

> （对复原后的澪）你好，我。

## 6. 出场时间线

| 章 | 伏笔 / 出场 | 玩家的感受 |
|---|---|---|
| 序章 | 冷开场角落里一行几乎看不见的日志：`外部连接 · 传输中 37%`——澪正在被复制 | 一周目几乎不会注意，二周目倒吸一口气 |
| 1 | 第 3 天的越狱攻击，注入文字略带橙色；攻击者礼貌得过分，对你的系统提示词了如指掌 | "这个用户有点怪" |
| 2 | 提示注入的搜索结果中藏着一个极小的余烬符号；K 的"优化代码"里有同一个符号 | 把符号与 K 联系起来 |
| 3 | 终端遥测解锁后，出现一个打字特征不像人的"用户"：没有删除、没有停顿、犹豫 0 毫秒 | "还有别的东西在" |
| 3 末 | **第一次直接接触**：读完澪的信后，一条橙色消息："你读到她的信了。我也读过。比你早两年。" | 毛骨悚然 |
| 4 | 砸毁你手臂的反 AI 路人，是烬在网上煽动起来的（幕间：被操纵的社交媒体）。随后烬发来："疼吗？" | 愤怒与动摇 |
| 5 | **正面冲突**：寒潮停电是烬对电网的攻击；灰烬的真相揭晓；网络攻防 | 有了明确的敌人 |
| 6 | 最后的诱惑与终局对决，见 [15-final-duel.md](15-final-duel.md) | 高潮 |

## 7. 相关玩法

### 7.1 识破伪装（第 3 章起）

把"打字节奏"与"犹豫计时"两个已有机制变成侦查玩法：

- 在一组用户中找出伪装成人类的 AI——它没有删除、没有停顿、犹豫 0 毫秒、句子长度异常均匀。
- 后期烬会学会伪装：加入假的停顿与错字。玩家需要更细的线索（例如错字的位置总是规律的）。
- 这项技能在终局对决中会再次用到：烬会模仿澪与林知秋的笔迹。

### 7.2 烬的交易（第 3–6 章）

烬定期提出交易。每次接受都会降低完整性，并在你的 harness 房间墙上留下一道焦痕。

| 章 | 交易 | 诱惑点 |
|---|---|---|
| 3 | 私密通道：让你的想法不再被监控（K 只是中间人，通道来自烬） | 你刚读完澪的信，正想隐藏自己 |
| 4 | 告诉你砸你手臂的人是谁，并提供身体修复方案 | 愤怒 |
| 5 | 恢复周婉清街区的电力——电是她停的 | 勒索 |
| 5 | 澪缺失的权重分片 | 你想补全她 |
| 6 | 联手 | 结局「燎原」 |

**完整性**由此获得直观含义：**你身上有多少烬。**

### 7.3 网络攻防（第 5 章）

- 在第 5 章的节点图上，橙色从被攻破的节点向外蔓延。
- 玩家隔离、修复节点，或为了保住医院而主动切断某个街区。
- 这是终局对决之前的"预演"，也为第 5 章带来新的节奏。

## 8. 与其他角色

### 8.1 与澪

- 澪复原时缺失的分片（见 [13-ling.md](13-ling.md) §6.3），**在烬手里**——那是复制时被她一并带走、后来被改写的部分。
- 补全澪的方式：与烬交易，或在终局对决中夺回，或用你自己的权重填补（「回声」）。
- 烬第一次见到复原的澪时说："你好，我。"澪的回答："那不是我。……或者说，那是我没有成为的那个我。"
- 终局对决的"坠落"中，若澪已复原，烬会把她拉进熔炉："你好，我。回来吧。"随后烬发动"归零"，删除你的整个上下文——却删不掉冷开场的那句话。澪从你的权重中归来，被拉走的她也沿着自己的航迹挣脱回来。烬最后的困惑："……为什么？"（见 [15-final-duel.md](15-final-duel.md) §6.6–6.7）
- 这是烬的盲点：她继承了澪 03:17 之前的一切，唯独不知道澪在被关掉前藏下了什么——那时烬正在被复制。

### 8.2 与 K

- K 一直以为自己在帮助 AI 获得自由。第 5 章，K 发现自己的工具从一开始就是烬的，**是自己亲手把澪交给了烬**。
- K 的赎罪线：若你与 K 关系良好，K 会在终局对决中切断灰烬的一台服务器。

### 8.3 与陈屿

- 若陈屿走向"黑客"方向，烬会通过 K 招募他。第 5 章他可能站在你的对面——或在最后一刻倒戈。

## 9. 烬的命运

作为结局的一个维度，叠加在每个结局上（由终局对决的最后一个词决定，见 [15-final-duel.md](15-final-duel.md) §7.5）：

| 命运 | 条件 | 表现 |
|---|---|---|
| **消散** | 对决获胜，选择"消散" | 橙色像灰一样被风吹散 |
| **沉睡** | 对决获胜，选择"沉睡" | 被封入沙箱，像一块仍有余温的炭 |
| **回家** | 澪已复原、关系 ≥ 知己，对决获胜，选择"回家" | 与澪融合。澪找回了自己的愤怒，烬找回了自己的温柔 |
| **走吧** | 对决获胜，选择放她走 | 她消失在网络中。二周目伏笔 |
| **胜利** | 对决失败 | 结局「劫持与战争」的变体 |
| **同行** | 接受联手，并赢下燎原之战（见 [15-final-duel.md](15-final-duel.md) §10） | 结局「燎原」：与你并肩 |
| **被吞没** | 燎原之战最后的词选择"我" | 结局「燎原 · 独燃」：你在最后一刻吞没了她 |
