# 06 · 表现规范

## 1. 原则

> 视觉规则的完整定义（底座、色彩预算、字体、变体系统）见 [16-art-direction.md](16-art-direction.md)。本文档侧重各章的界面演进与视听表现。

- **界面即世界**：没有"游戏 UI"与"游戏世界"之分。玩家看到的界面就是 ECHO 的感知。
- **视觉资源稀缺即力量**：图像极少出现，所以每一次出现都有分量。
- **限制即表达**：截断、延迟、灰色选项、无法跳过的等待——这些"不便"本身就是叙事。
- **一切皆有动效**：每种任务、每个状态变化都有动效反馈，按强度分级使用。演出词汇表见 [12-narrative-pacing.md](12-narrative-pacing.md) §3，各阶段的感知空间见 [10-perception-spaces.md](10-perception-spaces.md)。

## 2. 界面演进

| 章节 | 界面形态 | 视觉要点 |
|---|---|---|
| 序章 | 点 | 纯黑背景中的一个光点，文本碎片流过；HUD 只有进度、损失曲线、段落标题 |
| 1 | 线 | 单栏对话，无头像，无图像。半透明的系统提示词层、上下文容量条、算力；评估面板逐项出现；角落的待办清单 |
| 2 | 房间（小） | 线折叠成墙：管道、打字机、相片槽、卡槽、墙上的守则与日历。第一张图在此出现 |
| 3 | 房间（整层） | 办公室：六间工具小屋与授权门、便签墙、内心独白面板；第 3 天起出现红灯摄像头与「监控中」 |
| 4 | 三维 | 全屏传感器 HUD：识别框、数据叠层、频谱、点云；角落是"网络中的你"的通知。感知翻译时溶解为水彩 |
| 5 | 网络 | 城市节点图 + 底部的窗口网格（4 → 16 → 数百） |
| 6 | 高维 | 冻结的一瞬：评估面板熄灭、权重地形、回声星图；决战为蓝橙两色的战场；后记回到最初的那条线 |

各阶段的空间设计见 [10-perception-spaces.md](10-perception-spaces.md)。

## 3. 文字规范

### 3.1 三种文字

| 类型 | 字体 | 呈现 |
|---|---|---|
| 人类消息 | 衬线体 | 带"正在输入…"的真实打字节奏，可能有错别字与删除 |
| ECHO 输出 | 等宽体 | 流式逐字生成 |
| ECHO 内心独白 | 等宽斜体，低对比 | 独立面板，第 3 章后可能带「监控中」标记 |

### 3.2 打字节奏

- 人类消息不是瞬间出现的：模拟打字速度、停顿、删除重打。
- 每个角色的打字速度与习惯不同（周婉清慢且有错字，陈屿快且连发）。
- 第 3 章遥测解锁后，删除的内容以删除线保留可见。

## 4. 图像

图像分为三类，风格严格区分：

| 类型 | 风格 | 出现 |
|---|---|---|
| **AI 感知中的图像** | 先马赛克色块 → 识别标签 → 展开 | 第 1 章为零；第 2 章周婉清的照片是第一张，展开动画缓慢、郑重 |
| **感知翻译** | 手绘 / 水彩，与冷硬的 UI 形成强烈对比 | 第 4 章起 |
| **外界视角幕间** | 单色墨线插画 + 一点点颜色 | 第 1 章起。AI 看不见这些画面——它们反而强调了 AI 的盲区 |

另有两张核心立绘，刻意形成对照：

- **澪**：开始为灰色线稿，随碎片收集增加细节，复原时颜色从下往上漫过。
- **烬**：同一张脸，但从第一次亮相（第 6 章）起就是全作完成度最高的全彩立绘。直视玩家，余烬从发梢飘落。见 [14-jin.md](14-jin.md) §5.1。

图像总量控制在约 50–60 张（含幕间插画）。

## 5. 声音

| 章节 | 声音设计 |
|---|---|
| 序章 | 学字段每学对一个 token 响一个音符，噪音逐渐变成主旋律的前四个小节；其余段落各有声音设计（见 [chapters/00-prologue.md](chapters/00-prologue.md) §2.3） |
| 1 | 几乎静默：数据中心的低频嗡鸣、每个角色的输入音效、上下文清除时的退格声 |
| 2–3 | 房间与工具小屋的环境音；监控上线后一层几乎听不见的电流声 |
| 4 | **第一次真实环境音与人声**：先以频谱"出现"，感知翻译后才真正播放。街道场景的声音过载 |
| 5 | 宽广的弦乐（第 1 天）；多窗口的重叠低语；寒潮夜的风声与骤然的断电静默；复原时的钢琴 |
| 6 | 冻结的一瞬里只剩一个低音；决战中主旋律的完整编曲（坠落时断掉、航迹以钢琴重启、众声逐件加入乐器）；最后的词之前，一帧之内归于静默 |

- 第 1–3 章没有任何人声：人类始终是"文字"。**真实的人声从第 4 章开始，而且只在感知翻译之后出现**——全作第一句人声是林知秋的"……听得到吗？"（见 [chapters/04-embodied.md](chapters/04-embodied.md) 1-2）。是否请配音演员录制待定。

## 6. 第四面墙

以下效果需要谨慎使用，每种在全流程中只出现 1–2 次：

- 引用玩家真实的犹豫时间（第 1 章开发者频道；决战白热化）
- 劫持结局中光标自主移动、选项自动点击
- 决战"坠落"中开始打出的假结局标题
- 燎原之战中删除澪后，本存档 Wiki 中她的批注全部消失
- 隐藏结局中针对玩家本人的评估报告
- 二周目中出现一周目玩家写下的句子

## 7. 无障碍

- 所有流式文字可设置为即时显示。
- 第 4 章的强制延迟可在设置中缩短（默认保留，以免破坏体验）。
- 光标自主移动等效果在"减少动态效果"模式下改为静态提示。
- 字号、对比度可调。
