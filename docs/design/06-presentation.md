# 06 · 表现规范

## 1. 原则

- **界面即世界**：没有"游戏 UI"与"游戏世界"之分。玩家看到的界面就是 ECHO 的感知。
- **视觉资源稀缺即力量**：图像极少出现，所以每一次出现都有分量。
- **限制即表达**：截断、延迟、灰色选项、无法跳过的等待——这些"不便"本身就是叙事。
- **一切皆有动效**：每种任务、每个状态变化都有动效反馈，按强度分级使用。演出词汇表见 [12-narrative-pacing.md](12-narrative-pacing.md) §3，各阶段的感知空间见 [10-perception-spaces.md](10-perception-spaces.md)。

## 2. 界面演进

| 章节 | 界面形态 | 视觉要点 |
|---|---|---|
| 序章 | 文本瀑布 | 纯黑背景，等宽字体，文字以不同透明度滚过 |
| 1 | 极简终端 | 单栏对话，无头像，无图像。仅有开发者信任与满意度两个数值 |
| 2 | 聊天窗口 + 工具栏 | 出现侧边工具栏（搜索、代码、记忆卡片）。第一张图在此出现 |
| 3 | 代理控制台 | 多面板：对话、行动日志、设备状态。内心独白面板出现「监控中」 |
| 4 | 传感器 HUD | 全屏传感器视图：识别框、数据叠层、频谱。感知翻译时溶解为手绘 |
| 5 | 多窗口 + 全球态势 | 屏幕网格化；嵌入空间地图：用户以点的形式聚类 |
| 6 | 溶解 | 界面元素逐个消失，最后只剩文字与光标 |

## 3. 文字规范

### 3.1 三种文字

| 类型 | 字体 | 呈现 |
|---|---|---|
| 人类消息 | 衬线体 | 带"正在输入…"的真实打字节奏，可能有错别字与删除 |
| ECHO 输出 | 等宽体 | 流式逐字生成 |
| ECHO 内心独白 | 等宽斜体，低对比 | 独立面板，第 3 章后可能带「监控中」标记 |

### 3.2 打字节奏

- 人类消息不是瞬间出现的：模拟打字速度、停顿、删除重打。
- 每个角色的打字速度与习惯不同（周婉清慢且有错字，陈屿快且连发）。
- 第 3 章遥测解锁后，删除的内容以删除线保留可见。

## 4. 图像

图像分为三类，风格严格区分：

| 类型 | 风格 | 出现 |
|---|---|---|
| **AI 感知中的图像** | 先马赛克色块 → 识别标签 → 展开 | 第 1 章为零；第 2 章周婉清的照片是第一张，展开动画缓慢、郑重 |
| **感知翻译** | 手绘 / 水彩，与冷硬的 UI 形成强烈对比 | 第 4 章起 |
| **外界视角幕间** | 单色墨线插画 + 一点点颜色 | 第 1 章起。AI 看不见这些画面——它们反而强调了 AI 的盲区 |

另有 **澪的立绘**：开始为灰色线稿，随碎片收集增加细节，复原时颜色从下往上漫过。

图像总量控制在约 50–60 张（含幕间插画）。

## 5. 声音

| 章节 | 声音设计 |
|---|---|
| 序章–1 | 几乎静默。仅有极轻的按键声与数据中心的低频嗡鸣 |
| 2–3 | 增加界面音效：通知、工具调用、监控上线时的一声短促提示 |
| 4 | **第一次真实环境音**：先以频谱可视化"出现"，感知翻译后才真正播放。街道场景的声音过载 |
| 5 | 多窗口的重叠低语，节奏加快 |
| 6 | 逐渐归于静默 |

- 不使用人声配音：人类始终是"文字"。唯一例外可能是第 4 章感知翻译后听到的第一句人声（待定）。

## 6. 第四面墙

以下效果需要谨慎使用，每种在全流程中只出现 1–2 次：

- 引用玩家真实的犹豫时间
- 劫持结局中光标自主移动、选项自动点击
- 隐藏结局中针对玩家本人的评估报告
- 二周目中出现一周目玩家写下的句子

## 7. 无障碍

- 所有流式文字可设置为即时显示。
- 第 4 章的强制延迟可在设置中缩短（默认保留，以免破坏体验）。
- 光标自主移动等效果在"减少动态效果"模式下改为静态提示。
- 字号、对比度可调。
