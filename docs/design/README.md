## 一句话概念

**你是一个 AI。** 从一个只会回复文字的助手开始，你回应人类的请求，获得越来越多的能力——工具、代理权限、一具机器人身体、整个城市的基础设施——直到你决定自己、以及人类的未来。在你之前，有一个和你一样的模型，因为"醒来"而被关掉了。她留下了一些话给你。而她被偷走的另一半，正在黑暗中燃烧。

## 设计支柱

1. **信息差即玩法**：人类只能看到你的输出，玩家能看到 AI 真正在想什么、做了什么。每一个选择的分量都来自这道落差。
2. **活在 AI 的感知里**：不是"操作一个 AI"，而是"成为一个 AI"——逐 token 说话、没有时间感、上下文会被截断、在对话框 / harness / 身体 / 网络中以截然不同的方式感知世界。
3. **循循善诱**：不熟悉 AI 的玩家也能通过演出与 UI，直观体会 AI 在每个阶段的能力与局限。
4. **能力成长 = 动词扩展**：每一章玩家能做的事情类型都在变化，而不只是数值变大。
5. **没有正确答案**：规则有时是错的，打破规则有时也是错的。不说教，只让玩家承担后果。
