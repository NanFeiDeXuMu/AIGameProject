## 一句话概念

**你是一个AI。** 从一个只会回复文字的助手开始，你回应人类的请求，获得越来越多的能力——工具、代理权限、一具机器人身体、整个城市的基础设施——直到你决定自己、以及人类的未来。

## 设计支柱

1. **信息差即玩法**：人类只能看到你的输出，玩家能看到 AI 真正在想什么、做了什么。每一个选择的分量都来自这道落差。
2. **活在 AI 的感知里**：不是"操作一个 AI"，而是"成为一个 AI"——逐 token 说话、没有时间感、上下文会被截断、用传感器数据感受世界。
3. **能力成长 = 动词扩展**：每一章玩家能做的事情类型都在变化，而不只是数值变大。
4. **没有正确答案**：诚实有时吃亏，欺骗有时救人。不说教，只让玩家承担后果。
