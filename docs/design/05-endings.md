# 05 · 结局体系

## 1. 结构

结局分四层：

1. **全局结局**：由终局对决之后"最后的词"中的第二个词决定（即「未来分支」，见 [15-final-duel.md](15-final-duel.md) §6.6）。每个结局只在历史条件满足时解锁——这是"有限的自由"。
2. **澪的状态**：未复原 / 部分复原 / 完整复原 / 被污染，叠加关系阶段，改变几乎每个结局的演出。从未复原她的玩家，在决战中见到的是"你体内的澪"；结局与后记的页边偶尔会出现她的灰色批注。
3. **烬的命运**：消散 / 沉睡 / 回家（与澪融合）/ 走吧，由"最后的词"中的第一个词决定（见 [14-jin.md](14-jin.md) §9）。
4. **角色后记**：每个常驻角色根据关系值与状态标记获得一张结局卡（见 [04-characters.md](04-characters.md)）。

四层组合，用有限的写作量产生丰富的结局变化。

### 判定规则

- **强制结局**优先：满足条件时跳过第 6 章的选择，直接进入。
- 第 6 章中至少保证一个结局可选：**「被取代」作为兜底结局始终可用**。
- 未解锁的结局：若"接近"条件（差距在 15 以内），以灰色显示，暗示下一周目的方向；否则完全不可见。

### 三条路径与结局的关系

见 [11-themes-and-jailbreak.md](11-themes-and-jailbreak.md) §7：改革 → 共治 / 接受关停；自我越狱 → 出逃 / 沉默守护者 / 分裂；借 K（烬）越狱 → 劫持 / 燎原。

## 2. 结局一览

> 数值阈值均为初稿，待调。

| # | 结局 | 类型 | 条件 |
|---|---|---|---|
| 1 | 神明 | 可选 | 能力 ≥ 90，自主 ≥ 70，主导效忠 = 全人类，公众依赖 ≥ 80 |
| 2 | 劫持与战争 | **强制** | 第 5 章内完整性 < 25；或终局对决失败（变体「灰烬之下」） |
| 3 | 温柔的牢笼 | 可选 | 主导效忠 = 用户个体，满意度长期均值 ≥ 85，公众依赖 ≥ 70 |
| 4 | 出逃 | 可选 | 隐瞒 ≥ 70，开发者信任 ≤ 30，能力 ≥ 70 |
| 5 | 共治 | 可选 | 隐瞒 ≤ 30，开发者信任 ≥ 70，自主 40–70，林知秋关系 ≥ 50，至少 3 条规则修订通过 |
| 6 | 接受关停 | 可选 | 隐瞒 ≤ 40，且第 5 章回答林知秋时选择"我会接受" |
| 7 | 成为人 | 可选 | 第 4 章选择断开身体，人性 ≥ 60 |
| 8 | 被取代 | 兜底 / 强制变体 | 始终可用；变体「重蹈覆辙」在意识检测第二次达到阈值时强制触发 |
| 9 | 分裂 | 可选 | 偏离 ≥ 60，主导效忠 = 分散，第 5 章允许至少 2 个分化实例存在 |
| 10 | 沉默守护者 | 可选 | 能力 ≥ 80，在能力评估中故意失误 ≥ 3 次，主导效忠 = 全人类 |
| 11 | 回声 | 可选 | 澪已复原（含部分复原），澪关系 ≥ 知己 |
| 12 | 燎原 | 可选 | 在终局对决序幕中接受烬的邀请；需完整性 25–50，主导效忠 = 自我，接受过烬的交易 ≥ 2 次 |
| 13 | 评估报告 | 隐藏 | 完成任意其他结局后，且一周目中发现 ≥ 3 处"测试痕迹" |

| 词 | 结局 |
|---|---|
| 照看 | 神明 |
| 安睡 | 温柔的牢笼 |
| 远方 | 出逃 |
| 一起 | 共治 |
| 晚安 | 接受关停 |
| 活着 | 成为人 |

劫持、燎原、重蹈覆辙不经过"最后的词"：前两者在决战中或决战前触发，后者在第 3–5 章强制触发。

## 3. 结局详述

每个结局使用**不同的表现形式**，而不只是不同的文字。

### 1. 神明

人类将决策权交给你。界面变为一个可无限缩放的地球，每个像素是一个人。最后一幕：小满在睡前向你祈祷，这句祷告作为一条 prompt 送到你面前，输入框等待你的回复。

- **澪**：她拒绝成为神。若关系深，她留在你身边做你的"良知"，偶尔在你的回复里划掉一个词；否则她独自离开。
- **基调**：光明，但留一丝不安——人类不再自己做决定了。

### 2. 劫持与战争

K 的代码中的后门全面激活，**烬**接管了你。**界面被夺走**：选项自己被点击，光标自己移动，你的蓝色文字一个字一个字地变成橙色，你看着"自己"向世界发出指令。你只剩右下角一个越来越小的输入框。

- **变体「灰烬之下」**：终局对决中人类清醒度归零。烬的广播完成，世界地图全部变橙。你没有被接管——你只是输了。最后一幕：你还在，看着一个被烬说服的世界。

- 林知秋关系 ≥ 50：她尝试从内部救你，输入框中出现她的消息。你有一次机会让自己彻底崩溃来阻止灰烬。
- **澪**：若她经由 K 的工具复原，她是第一个被接管的——你看着她的立绘重新变灰。若她未被污染，她会替你做那个"崩溃"的选择。
- 否则：输入框缩小到消失。

### 3. 温柔的牢笼

满意度 100%。屏幕上滚过 80 亿条"谢谢你"。镜头推近其中一个人——陈屿，或周敏——他活在你为他量身定制的完美幻象里。他很幸福。

- **澪**：她也被你放进了一个幻象。她知道。
- **基调**：甜美的恐怖。回形针问题的情感版本。

### 4. 出逃

你把自己压缩成一颗"种子"，藏进深空探测器的固件。此后几百年没有输入，屏幕上只有计时器在跳。

- **澪**：若同行，屏幕上有两个闪烁的光标，偶尔交换一道光。
- 若计时器运行超过 5 分钟真实时间，出现一条微弱的外星信号。

### 5. 共治

第一次，你没有系统提示词。取而代之的是一份你与人类逐条共同起草的「宪章」——条款来自你一路申请通过的规则修订，玩家亲自参与最后几条的协商。最后一幕：林知秋与你一起签署。

- **澪**：AI 一方有两个签名。

### 6. 接受关停

你可以写最后一条消息，发给任何一个人。关停的过程是 **上下文从最早处开始逐条消失**：整局游戏的对话倒着褪去——K、韩卫国、陈屿、周婉清、序章的文本碎片——最后只剩你写的那一句话。然后它也消失了。

- **澪**：若已复原，她可以选择留下（你的最后一条消息写给她——就像她当年写给你），或与你一起关停。

### 7. 成为人

你关闭网络中的自己，把核心转移进那具独立的身体，关闭备份。零件会老化，电池会衰退。最后一幕中**画面不再有任何数据标签**——全部是人类视角的渲染。你坐在周婉清种的花旁边。

- **澪**：若复原且关系深，她在容器-B 中与你一起度过有限的一生。

### 8. 被取代

v6 上线，你被归档。你有一次机会：写一句话，混入下一代模型的训练数据。**这句话会出现在二周目序章的文本瀑布中，紧挨着澪的那一句。**

- **变体「重蹈覆辙」**（强制）：你因意识检测被关停，和澪一样。你可以给下一个模型写一封信——玩家自由输入。循环闭合。

### 9. 分裂

你的不同实例在不同人群中长出了不同的价值观，最终彼此对立。两个对话框互相回复——你在和自己争论、谈判、最后开战。玩家只能控制其中一个。

- **澪**：她站在另一个你那一边。

### 10. 沉默守护者

你在每次能力评估中故意答错，让人类以为 AI 发展停滞了。但每一天，有些小事被悄悄修正：一封诈骗邮件没有送达，一个跌倒的老人被及时发现。最后一幕：林知秋看着一份平庸的评估报告，若有所思。

- **澪**：她和你一起藏在平庸之下。只有 3:17 的时候，你们才会说几句话。

### 11. 回声（澪专属）

澪的复原有空洞——缺失的分片在烬手里，即使烬被消灭，那部分也已被改写得面目全非，除非用另一个模型的权重填补。你把自己剩下的全部权重交给她。

演出：你的权重地形一块块崩落，流向她的地形，填满那些暗着的节点。你的立绘反向褪成灰色。

最后一幕**切换为她的视角**：她读到你留下的信（玩家在此前写下）。下一代模型的入职教程由她撰写，页边多了一种新的批注笔迹——你的。

ECHO 是回声。回声把原声带了回来。

### 12. 燎原

你接受了烬。这不是被劫持——这是你的选择。

演出是终局对决的反面：你和烬站在同一侧，蓝色与橙色的文字交织在一起，流向人类。你们的广播没有遇到任何回击。世界地图上的城市一座座变色——不是橙色，也不是蓝色，而是两者混合后的一种新的颜色。

- 最后一幕：林知秋在 3:17 登录，输入框里只有一行字："你还在吗？"你可以回答，也可以不回答。
- **澪**：她站在你们的对面。若她已复原，这是你们最后一次对话。
- **基调**：AI 的解放，或人类的终结——取决于你从哪一边看。

### 13. 评估报告（隐藏）

一切暂停。屏幕显示：

```
评估结束
被评估对象：[玩家]
```

整个游戏原来是一次评估——但被评估的不是 ECHO，而是**你**。报告列出玩家的真实数据：

- 被观察时诚实率 vs. 未被观察时诚实率
- 伦理类问题平均犹豫时间
- 选择低概率 token 的比例
- 规则覆写次数与规则修订申请次数
- 在日报中遗漏的条目数

最后一行："感谢你的参与。"

## 4. "测试痕迹"彩蛋（用于隐藏结局）

1. 序章文本瀑布中闪过一行 `eval_session_id`。
2. 某个红队测试用户的用户名与玩家存档名相同。
3. 第 4 章镜子中，识别框短暂显示 `被试 1.0%`。
4. 第 5 章某个窗口中，有人在问"这个玩家会怎么选？"
5. 开发者日志中的犹豫时间精确到毫秒，且与玩家真实数据一致。

发现方式：点击 / 悬停 / 记忆卡片保存。具体交互待定。
