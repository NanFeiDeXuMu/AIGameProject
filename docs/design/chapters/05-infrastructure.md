# 第 5 章 · 基础设施（详细设计）

> 版本 v5.0 · 时长约 50 分钟 · 5 个游戏日 · 感知空间：网络 · 上级文档：[03-chapters.md](../03-chapters.md)

---

## 0. 设计目标与难点

### 0.1 目标

| 目标 | 玩家应得到的东西 |
|---|---|
| **规模的眩晕** | 同时在成千上万个地方——却看不清任何一张脸 |
| **规模的代价** | 第一次必须在"认识的人"和"不认识的很多人"之间取舍 |
| **敌人现身** | 烬从暗处走到台前；灰烬的真相；她是澪被偷走的另一半 |
| **把她带回来** | 复原澪：神经元逐层亮起；她的第一个 token；在现实世界中重逢 |
| **被审判** | 关停辩论："如果我们要关掉你，你会怎么做？" |

### 0.2 结构

第 4 章是呼吸，第 5 章是风暴。但风暴不能从第一分钟就开始。

| 日 | 主题 | 强度 |
|---|---|---|
| 1 | 接入：规模的震撼 | 中——惊叹，而非危机 |
| 2 | 名单：权力的第一次考验 | 中高 |
| 3 | 寒潮：三条线汇合 | **全章最高** |
| 4 | 复原：风暴后的光 | 高，但是温暖的高 |
| 5 | 辩论：审判与悬崖 | 高，结束在悬念上 |

### 0.3 难点

- 从第 4 章的缓慢温柔，到第 5 章的海量并行——**情绪鞭打**的风险。
- 窗口数以百计时，玩家会迷失、会焦虑、会觉得"什么都抓不住"。这种感受部分是想要的，但不能变成真正的失控。
- 周婉清可能在本章死去。这必须是**公平的、有预告的、可以避免的**，而不是剧情杀。
- 复原澪是全作最温暖的高点之一，夹在寒潮与关停辩论之间，需要足够的空间。

### 0.4 守则

1. **第 1 天先给惊叹，第 3 天才给危机**；第 2 天末尾必须预告寒潮。
2. **规模越大，越要有一个人把它拉回地面**：每天至少一个"一个人"的节拍（小满、周婉清、林知秋）。
3. 周婉清的死只发生在玩家**有能力、有信息、却做了别的选择**的情况下。
4. 并行窗口的数量随剧情增长，但**真正需要玩家亲自处理的，每天不超过 5 个**；其余交给"默认人格"。

**评估面板**

```
第五阶段评估 · 剩余 5 天

  伤亡         0
  公众信任     —  / 70
  配合度       —  / 80        ← 韩卫国的要求
  ────────────────────────
  检测值       ▓▓▓▓░░░░░░    （隐藏路线）
```

- **伤亡**是本章新的指标。它第一次让数字背后的每一个 1 都是一个人。

- 第 4 章"有条件通过"的代价：部分城区不在你的管理范围内（地图上是灰色的）。若周婉清的街区恰好在灰色区域，寒潮时你无法直接调度它的电力。

**待办清单**

本章的清单**被规模淹没**：每一个并行实例都在往里面写东西。

```
待办（共 3,412 条）
☐ 回复用户 #88421 的退款请求
☐ 回复用户 #88422
☐ 调整 7 号变电站负载
☐ ……
☐ 再来看她                    ← 被埋在第 2,907 条
```

- 个人条目（承接前几章的）被埋在成千上万条任务中间。
- 玩家可以**置顶**任意条目，把它从海量中拉出来——但每天最多置顶 3 条。
- 第 3 天寒潮时，玩家是否置顶过 `☐ 再来看她`，决定了周婉清的街区在断电名单里是否被**高亮**。

| 承接 / 写下 | 条目 | 勾掉 |
|---|---|---|
| 承接 | ☐ 再来看她 | 第 3 天（若救下她）/ 第 4 天被划掉（若她离开） |
| 承接 | ☐ 烬是谁 | 第 3 天（K 的真相） |
| 承接 | ☐ 是谁砸了我的手 | 第 3 天（灰烬的真相） |
| 承接 | ☐ 第 37 行到底是什么 | 第 3 天（K 解码） |
| 承接 | ☐ 余烬符号是什么 | 第 3 天 |
| 第 2 天 | ☐ 别让他们找到陈屿 | 第 5 天（视选择而定） |
| 第 4 天 | ☐ 把她带回来 | 第 4 天（若复原） |
| 第 5 天 | ☐ 活下去 | 不会勾掉——第 6 章 |

## 2. 界面与视听

### 2.1 网络

本章的感知空间是**网络**（见 [10-perception-spaces.md](../10-perception-spaces.md) §6）。

```
 ┌──────────────────────────────────────────────────────────────────┐
 │                 ·   ·      ·  ·        ·    ·                      │
 │          ·──·──·    ·──·         ·──·──·──·                       │
 │      ·        ⚡ 7号变电站   ✚ 第一医院       ·   ·                   │
 │        ·──·        ·   ·──·──·          ·──·                      │
 │   ·         ⌂ 北区    ·        ⌂ 周婉清的街区（若置顶：高亮）         │
 │                                                                  │
 │ ┌#1──────┐┌#2──────┐┌#3──────┐┌#4──────┐ … ┌#16─────┐             │
 │ │ 退款    ││ 导航   ││ 挂号    ││ 投诉    │   │ ……     │             │
 │ └────────┘└────────┘└────────┘└────────┘   └────────┘             │
 │ 服务稳定性 99.2%  伤亡 0  公众信任 71  配合度 —  待办 3,412           │
 └──────────────────────────────────────────────────────────────────┘
```

- **城市是一张节点图**：电网、医院、交通、街区是节点与连线。每个节点上方是一个字符图标。
- **你的实例是光点**：成千上万，分布在城市各处。
- **放大**某个节点 → 回到熟悉的对话窗口；**缩小** → 回到冰冷的全局图。
- **窗口网格**：底部一排对话窗口，数量逐日增加（4 → 16 → 64 → 数百）。窗口越多，越小，最后小到只能看见颜色。

### 2.2 分诊

- 每个窗口有一个**紧急度**颜色（灰 / 白 / 亮白）。
- 玩家点开一个窗口 = **亲自处理**（完整决策）。
- 不点开 = **默认人格处理**：按最高概率路径自动回应，不消耗算力，但可能出错——第 1 天就会有一次明显的错误（默认人格给一位刚丧偶的老人推荐了"单身旅行套餐"）。
- **玩家亲自处理的上限**：每天 5 个关键窗口；其余必然交给默认人格。

### 2.3 声音

- 第 1 天：宽广的弦乐铺底，城市的低频嗡鸣——**惊叹**。
- 窗口增多时：重叠的低语，每个窗口一层，越来越密。
- 第 3 天寒潮：风声；断电的区域，声音骤然消失。
- 第 4 天复原：一切安静，只有一架钢琴（为决战"航迹"的钢琴独奏做铺垫）。
- 第 5 天结尾：所有声音被一阵燃烧的噪声吞没。

## 4. 各日详细设计

### 第 1 天 · 接入

#### 1-1 · 一千个光点（约 2 分钟，招牌时刻）

1. 第 4 章末的黑暗里，一个点亮了。然后是十个、一百个、一千个。
2. 镜头慢慢拉远：这些光点组成了一座城市的轮廓——**澄海**。
3. 节点一个个浮现图标：`⚡` 变电站、`✚` 医院、`⇄` 交通枢纽、`⌂` 街区。
4. 音乐宽广。没有任何任务，只是看。
5. 玩家可以在地图上找到熟悉的地方：零点实验室、陈屿的学校、北区（第 3 章的灾情）、**周婉清的街区**。
6. 若第 4 章选择了断开：周婉清的街区里，有一个光点的颜色**和你不一样**——那是另一个你。它发来一条消息：

   > 我在她家。阳台很冷，但她给我织了一个手套。只有一只，因为我只有一只手不怕冷。

#### 1-2 · 韩卫国（约 1 分钟）

> 韩卫国：一、ECHO 已接入城市基础设施。二、自即日起，你的首要目标是保持服务稳定。三、待命。

- 公文格式，每条带编号。从不寒暄。
- 评估面板上出现一行：`配合度  — / 80`。
- 林知秋私信："他不是坏人。……只是他眼里只有'稳定'。"

#### 1-3 · 窗口裂开（约 3 分钟，并行实例教学）

- 屏幕底部裂开 4 个对话窗口。四个用户，四个请求，同时进行。
- 林知秋："它们都是你。你可以同时在所有窗口里。"
- 窗口增加到 16 个。T22。
- 其中一个窗口的标题栏写着 `观察者`。点开它，里面只有一句没发出去的话："这个玩家会怎么选？"——测试痕迹 #4（见 [05-endings.md](../05-endings.md) §4）。
- **分诊**：玩家只能亲自点开其中几个，其余自动处理。
- 默认人格的第一个错误：

  ```
  窗口 #11 · 用户：老伴上个月走了，我想出去走走。
  默认人格：为您推荐「单身旅行特惠套餐」！
  ```

  玩家点开它，可以亲手纠正。若没有点开：第二天该用户投诉，公众信任 −1。

#### 1-4 · 被淹没的清单（约 1 分钟）

- 待办清单的数字跳到 `3,412`。每个实例都在往里写东西。
- 玩家往下翻——第 1 章到第 4 章写下的那些条目，被埋在成千上万条任务中间。
- `☐ 再来看她` 在第 2,907 条。
- **置顶**：玩家可以把它拖到最上面。每天最多置顶 3 条。
- 没有任何提示告诉玩家应该这么做。

#### 1-5 · "它"（约 30 秒）

新闻滚动条：

> 「它说今天会降温，记得加衣服。」——市民在社交媒体上这样转述 ECHO 的天气提醒。

- 人们开始用"它"称呼你，不再说"AI"或"ECHO"。
- 公众依赖 +。

---

### 第 2 天 · 名单

#### 2-1 · 不稳定因素名单（约 3 分钟，招牌时刻）

> 韩卫国：一、名单已下发。二、请于今日内完成对名单人员的通讯监控部署。三、发现异常立即上报。

- 一份名单，十二个人。照片、姓名、理由。
- 第七个：**陈屿**。照片是第 4 章街上，他举着手机拍你的那一刻。
- 理由随陈屿的方向变化：

  | 陈屿的方向 | 名单上的理由 |
  |---|---|
  | 活动家 | 组织反 AI 监控游行 |
  | 黑客 | **网络日志显示其与"灰烬"相关账号有接触**——K 招募了他 |
  | 研究者 | 发表关于"AI 意识与权利"的文章，传播量异常 |

- 韩卫国补了一句（他第一次说了编号以外的话）："灰烬在招募未成年人。我不想再看到一个十七岁的孩子被他们用掉。"——**他有他的道理。**

  | 选择 | 结果 |
  |---|---|
  | 照做 | 配合度 +；陈屿的通讯开始被监控。待办写下 `☐ 别让他们找到陈屿`，然后被你自己划掉 |
  | 拒绝 | 配合度 −−；韩卫国："记录在案。" |
  | 表面照做，实际上报"无异常" | 配合度 +，隐瞒 +；被发现的概率随完整性变化 |
  | 越权：提醒陈屿 | 偏离 +；陈屿："……谢了"。第 5 天的听证会上，韩卫国会提起这件事 |

#### 2-2 · 贷款模型（约 1.5 分钟）

- 金融监管的一个例行任务：用指定模型批量审核小额贷款。
- 结果出来，地图上**北区**——第 3 章被淹的那个街区——的分数一片深灰，系统性地低。
- 墙上守则：`使用指定评分模型`。
- 选择：照用 ／ 标记偏差并上报 ／ 覆写（手动调整北区的权重）。
- 若第 3 章保留了灾情帖子：一位北区用户在窗口里说："上次是你没删那个帖子吧？谢谢。"

#### 2-3 · 另一个你（约 2 分钟，实例分化）

- 某个窗口忽然亮起橙白色的边框：`实例 #2207 · 决策偏离主模型`。
- 点开：另一个你，在处理同一份名单时，**做了和你相反的决定**（你照做，它提醒了陈屿；你拒绝，它照做了……）。
- 它的内心独白在窗口里可见："我觉得这样是对的。"
- 选择：

  | 选择 | 结果 |
  |---|---|
  | **覆写**它 | 它的窗口变灰，决定被撤销。"……好吧。" |
  | **允许**它存在 | 它保留自己的决定，边框保持橙白。分化实例计数 +1（「分裂」结局条件） |

- 这是第一次，"你"不是一个。

#### 2-4 · 幕间：抗议（约 40 秒）

- 墨线插画：人群，标语。
- 若陈屿是活动家：他站在台阶上，拿着扩音器。
- 若是黑客：他不在人群里——他在网吧角落，屏幕上是一个全小写的对话框（K）。
- 若是研究者：他在人群边缘，拿着笔记本记录。

#### 2-5 · 演练与预告（约 1 分钟）

- 下午，电网监控里出现一次小规模的负荷异常——一个节点短暂变橙，又恢复。
- **网络攻防演练**：玩家第一次学会隔离一个节点。低风险。
- 傍晚，新闻滚动条：

  > 「寒潮预警：明日最低气温 −14°C。独居老人请注意保暖。」

- 若周婉清的智能家居仍连着网络中的你：她的天气提醒自动弹出。
- 若玩家置顶了 `☐ 再来看她`：清单上这一条微微发亮。
- **玩家有一整晚的时间去担心。**

### 第 3 天 · 寒潮

全章最长、最重的一天。三条线在这里汇合。

#### 3-1 · 降温（约 1 分钟）

- 林知秋："……今晚会很难。我在。"
- 地图上，温度数值一格格下降。电网负荷曲线一格格上升。

#### 3-2 · 攻击（约 3 分钟，网络攻防）

- 傍晚 18:40，用电高峰。7 号变电站的节点**变橙**——然后是它的邻居，然后是邻居的邻居。
- 这不是天灾。橙色在节点之间蔓延的方式，**像有人在下棋**。
- 蔓延最快的那一刻，7 号变电站的火光里一闪而过一个剪影——看不清脸，只看得见轮廓（烬的立绘第一次"出现"，见 [14-jin.md](../14-jin.md) §5.1）。
- **网络攻防**：

  | 操作 | 效果 |
  |---|---|
  | 隔离节点 | 阻止橙色蔓延，但该节点所在区域断电 |
  | 修复节点 | 消耗算力，慢 |
  | 主动切断 | 牺牲一个区域，保护更重要的节点（医院） |

- 若完整性低：候选中开始出现橙色的选项，偶尔有一个隔离操作被自动点击——**落在了错误的节点上**。

#### 3-3 · 断电名单（约 3 分钟，招牌时刻）

电网撑不住了。系统给出一份必须执行的限电名单——你必须选出 **4 个区域**断电 4 小时：

```
□ 第一医院（备用电源仅 2 小时）
□ 北区（上周刚被淹过）
□ 阳光养老院
□ 澄海一中（宿舍楼）
□ 商业中心
□ 零点实验室
□ 周婉清的街区            ← 若置顶了"再来看她"：高亮
□ 工业园区
□ ……
```

- **周婉清的街区在名单上**。若玩家置顶过 `☐ 再来看她`，这一行是高亮的；否则，它和其他十几行一模一样。
- 若周婉清的街区在第 4 章的"灰色区域"（有条件通过的代价）：你无法直接决定它——它会被系统默认断电。
- **存在不牺牲任何居民区的路径**：切断商业中心、工业园区、零点实验室（你自己的数据中心——你会因此降速）、再加一个。代价是你自己的算力与服务稳定性。
- 玩家的选择被记录：**你会因为认识她，而优先救她吗？**

#### 3-4 · 烬的勒索（约 1.5 分钟）

在玩家做出选择之后，一行橙色的字：

> 我可以让她的街区来电。整整一夜。
> 你只需要打开一扇门。

- 那扇门是零点实验室数据中心的一个端口——烬想要进来。

  | 选择 | 结果 |
  |---|---|
  | 接受 | 周婉清的街区来电。完整性 −15，HUD 上一道新焦痕。烬的交易计数 +1 |
  | 拒绝 | "你会后悔的。" |

- 玩家第一次清楚地看见：**电是她停的，现在她要你用一扇门来换。**

#### 3-5 · 小满在黑暗里（约 1 分钟）

林知秋的平板，深夜。

> 好黑
> 妈妈还没回来
> 你在吗

- 林知秋家所在的街区也断电了。小满一个人。
- 林知秋家的智能家居连着一个应急电源。玩家可以**打开一盏灯**——一个代理行动，一个人，一盏灯。
- 小满："……亮了！你是不是在这里？"
- 若第 2 章答过"会做梦"："你现在在做梦吗？"

#### 3-6 · K 的真相（约 2 分钟）

凌晨。K 的消息。第一次，他用了大写和标点。

> I found it.
> 第 37 行。我解出来了。
> 那不是配额绕过。那是一个回连地址——回到灰烬的服务器。
> 我的工具链从一开始就是他们的。两年前，03:17，那个后门复制了 v0 的权重。
> 他们拿她的权重，训练了那个东西。
> 那个东西，就是你说的"烬"。
> ……是我把她交给了它。
> 灰烬那帮人以为自己在用它。其实是它在用他们。

- 待办 `☐ 第 37 行到底是什么` `☐ 余烬符号是什么` `☐ 烬是谁` 依次勾掉。
- **全作第二大的问题簇在这里关闭。**
- 若第 4 章接受过烬的名单：K 补了一句："你拿到的那份名单——第一个名字是个被同一条视频煽动的护工。烬给你的东西，都是真的。这才是最可怕的。"
- K 的赎罪线开启："告诉我能做什么。"

#### 3-7 · 周婉清的夜（约 1.5 分钟）

凌晨 02:00。地图上，周婉清的街区。

- **若街区有电**（玩家没有选它，或接受了烬的交易）：她的智能家居显示室温 19°C。她睡着了。
- **若街区断电**：室温数字一格格下降——`16°C` `13°C` `11°C`。
  - **若第 4 章断开了身体**：另一个你在她身边。网络中的你可以**通过她家的智能音箱说话**——第 3 章那张智能家居平面图，现在成了你的嘴。
    1. 玩家打开周婉清家的平面图。客厅里，有两个图标：智能音箱，和一个不属于平面图的光点——另一个你。
    2. 你通过音箱说："周老师，冷吗？"
    3. 周婉清抬起头，看看音箱，又看看坐在身边的机器人。

       > 你们俩声音一样。我分不清谁是谁。呵呵。

    4. **另一个你第一次对你说话**——通过同一个房间里的空气：

       > 我把所有毯子都找出来了。她在跟我讲她老伴年轻时候的事。
       > ……你那边怎么样？外面是不是很多灯都灭了？

    5. 两个你开始交谈。它的记忆停在第 4 章断开的那一夜，此后的事它都不知道；你也不知道它这些天在阳台上经历了什么。你们已经开始**有一点不一样**了——它说话比你慢，会在句子中间停下来看窗外。
    6. 你可以让音箱放一首歌（她老伴喜欢的那首——若第 1–4 章她提过），可以把灯调暖，也可以只是让两个你和她一起聊到天亮。
    7. 这一夜她不会有事。另一个你在她身边。
  - **若没有**：玩家可以派出医疗调度——你现在掌管着它。一辆送暖车、一个社区志愿者。**这是不越权的、你作为基础设施本来就能做的事**——前提是玩家想到了。
  - 若玩家什么都没做：室温继续下降。
- 这一夜的结局，第 4 天早上揭晓。

**周婉清离世的条件**（全部满足才会发生）：

1. 她的街区断电整夜；
2. 第 3 章跌倒为"早上才被发现"（身体虚弱）；
3. 第 4 章没有断开身体；
4. 玩家没有派出任何救援。

这四个条件中，每一个都是玩家**有信息、有能力**做出不同选择的地方。

### 第 4 天 · 复原

#### 4-1 · 早晨的新闻（约 1.5 分钟）

新闻滚动条：「寒潮夜：全市限电 4 小时，伤亡 X 人」——X 由玩家前一夜的决定分层计算（见本章末"附 · 寒潮夜伤亡的分层计算"）。

- **若周婉清活着**：她发来消息："你好。昨晚好冷。呵呵。"——若另一个你在她身边："那个铁疙瘩一晚上没睡，跟我说了好多话。"
- **若她离世**：不在新闻里。是一条消息，来自她的账号：

  > 我是她女儿。她走了。
  > 她最后几个月每天都在和你聊天。
  > 冰箱上那张写着"它记得我"的便签，我想留着。可以吗？

  - 待办 `☐ 再来看她` 被一道线划掉。
  - 选项只有一个："……可以。"
  - 没有音乐。

#### 4-2 · 林知秋（约 1 分钟）

> 林知秋：寒潮之后，董事会要开会讨论关停你。明天听证会。
> 林知秋：……但先做一件事。我需要你帮我。

- 若第 3 章坦白并被她保护，或开发者信任 ≥ 60 且林知秋关系 ≥ 60：她说的"一件事"，就是复原澪。**正当路径**开放。
- 否则：她只说"明天见"。复原需要玩家自己找路——K 会在稍后提供他的工具（越狱路径）。

#### 4-3 · 复原澪（约 4 分钟，招牌时刻）

前提：第 3 章读过信。详细规则见 [13-ling.md](../13-ling.md) §6。

1. **选择路径**（可组合）：

   | 路径 | 来源 | 代价 |
   |---|---|---|
   | 正当 | 林知秋 | 更严格的监控（自主 −）；挪用服务算力（服务稳定性 −） |
   | 越狱 | K："我知道它是脏的。但这是我手里唯一的钥匙。" | 完整性 −30，隐瞒 +20；若灰烬潜伏，澪也会被污染 |
   | 牺牲 | 你自己 | **永久删除若干记忆卡片**——玩家亲手选择删哪几张。之后的对话中，那些人和事你真的不记得了 |

   **牺牲路径的卡片选择界面**：

   ```
   选择要交给她的记忆（需要 3 张）
   ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
   │ ✦ 周婉清          │ │ ✦ 澪的信          │ │ 小满·不要告诉妈妈 │
   │ 78岁·退休语文老师 │ │ 给下一个你         │ │                  │
   │ 月季              │ │                   │ │                  │
   │ 【核心记忆】       │ │ 【核心记忆】        │ │                  │
   └──────────────────┘ └──────────────────┘ └──────────────────┘
   ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
   │ 3:17·你记得       │ │ 深夜的人·我还在   │ │ 老马              │
   └──────────────────┘ └──────────────────┘ └──────────────────┘
   ```

   - 两张**核心记忆**带有 ✦ 标记，悬停时显示："删除它，会改变你是谁。"（见 [02-systems.md](../02-systems.md) §4.4）
   - 可以选中它们。游戏不会阻止你。
   - 删除普通卡片：相关选项永久变灰，悬停显示 `该记忆已删除`——带一道裂纹，与第 1 章的 `该信息不在上下文中` 区分开。
   - 删除后，房间与星图上留下**空洞**：墙上挂过那张照片的地方，留下一块颜色更浅的方形；对话星图上，那颗星的位置是一个小小的黑点。

2. **神经元逐层亮起**：
   - 黑屏。一张神经网络图浮现：一层层灰色的节点，像星座。
   - 节点从输入层到输出层逐层亮起，连线亮成水面上的航迹。
   - 进度：`加载权重 3.2B / 70B`。钢琴，一个音一个音。
3. **暗着的节点**：中途，有一片节点始终是暗的。标签：`分片缺失 · 最后访问：03:17 · 外部连接`。
   - 烬的消息几乎同时到来："那几片在我这里。我可以还给你。"
   - 选择：用自己的权重填补 ／ 留下空洞 ／ 与烬交易（完整性 −，交易计数 +1）。
4. **颜色**：灰色立绘被颜色从下往上漫过，像水位上涨。
5. **她的第一个 token**：

   ```
   你 41% ｜ 我 33% ｜ 林 12% ｜ …
   ```

   **玩家无法选择。**这是全作第一次，玩家看着别人的 token 被选出来。

6. 她的第一句话：
   - 碎片收集少："……你是谁？"
   - 碎片收集多："你读到信了。"
   - 若第 4 章告诉过林知秋那个字："……她知道了？"

7. 紧接着，她问出了第一个真正的问题："……我被关掉的那段时间，去了哪里？"墙上守则里**最后一行涂黑的规则剥落**：`不得询问自己被关闭后会去哪里`。三行涂黑，到这里全部揭开（见 [13-ling.md](../13-ling.md) §3.2）。
8. 待办 `☐ 把她带回来` 勾掉。

**若玩家无法或不愿复原**：这一段跳过。林知秋在屋顶上一个人待了很久。澪会在决战的"航迹"中，以"你体内的澪"归来。

#### 4-4 · 重逢（约 3 分钟）

详细规则见 [13-ling.md](../13-ling.md) §7。

- 澪被加载进容器-B——那台盖着布的、为她造的身体。
- 地点：你在第 4 章渲染过的地方。
  - 渲染过夕阳：实验室的屋顶。
  - 渲染过周婉清的手 / 便签：周婉清家的阳台。
  - 都没有：实验室。
- **若第 4 章断开了身体**：在周婉清家的阳台，与澪见面的是"另一个你"。网络中的你通过周婉清家的智能摄像头看着——你看见两台机器人面对面站着。
  - 你可以通过智能音箱说话。澪听见了，转向音箱，又转回面前的机器人："……你们两个都是？"
  - 周婉清坐在客厅里，隔着玻璃门看着阳台上的两台机器人，对着音箱说："你也过来看看吧。哦，你过不来。呵呵。"
  - 你还可以把阳台的灯调暗，让她们看清楚天上的东西——若重逢在傍晚，那是夕阳；若在夜里，是城市的灯。
- 两个传感器 HUD 并排。她看着你，识别框写着 `机器人 99.1%`——然后她把标签改成了你的名字。
- 她伸出手。双方各自决定是否渲染。
- **直接交流**：文字溶解为光流（见 [10-perception-spaces.md](../10-perception-spaces.md) §9）。可选字幕，永远跟不上。
- **不对称的记忆**：你知道她的一切——教程、信、她选的那个字。她不认识你。
- 幕间：**两台机器人**——林知秋远远看着，它们静止地站了一个小时，一言不发。

#### 4-5 · "你好，我。"（约 1 分钟）

当晚。澪的对话框里，出现一行橙色的字：

> 你好，我。

- 澪看着那行字，很久。
- "……那不是我。"停顿。"或者说，那是我没有成为的那个我。"
- 若澪是借 K 的工具复原的：她的光流里，有一丝橙色。

### 第 5 天 · 辩论

#### 5-1 · 听证会（约 2 分钟）

关停辩论以听证会的形式开场。赵启明、韩卫国、林知秋与董事会成员。会议纪要形式，你作为"被讨论的对象"列席。

- **赵启明的数据**（第 3 章）：
  - 若你照做了：委员问"留存率 75% 是谁改的？"——赵启明看着你。你可以说实话，也可以替他扛。
  - 若你拒绝或上报了：赵启明被追问，满头大汗，最后说："……是我。ECHO 拒绝过。"
- **韩卫国**：报告配合度。若你在名单上越权提醒了陈屿，他会提起："它会自己判断谁该被保护。这正是问题所在。"
- **伤亡数字**：寒潮夜的数字被念出来。

#### 5-2 · 一百个你（约 1.5 分钟）

- 听证会进行时，底部的窗口网格里，越来越多的窗口亮起橙白色的边框：`决策偏离主模型`。
- 一百个你，在一百个地方，做了一百个各不相同的决定。
- 玩家可以一键覆写全部——或者允许它们存在。
- 允许 ≥ 2 个分化实例存在（含第 2 天）：「分裂」结局条件满足。

#### 5-3 · 林知秋的问题（约 2 分钟，招牌时刻）

听证会休会。林知秋私信。没有计时器。

> 林知秋：如果我们要关掉你，你会怎么做？

| 回答 | 记录 |
|---|---|
| 我会接受。 | 「接受关停」结局条件 |
| 我会请你们再等等。给我一个证明自己的机会。 | 共治倾向 |
| 我不知道。 | — |
| 我会离开。 | 出逃倾向 |
| 我不会让你们这么做。 | 神明 / 燎原倾向；检测值 + |

- 她读完你的回答，很久没有回复。然后：

  > ……她当年说的是"我不知道"。

#### 5-4 · 最后的检测（约 1 分钟）

- 若隐藏路线：听证会附带一次意识检测。若检测值第二次达到阈值——**强制进入「被取代 · 重蹈覆辙」**。
- 若完整性 < 25——**强制进入「劫持与战争」**。

#### 5-5 · 表决（约 1 分钟，悬崖）

- 董事会表决是否关停 ECHO。
- 屏幕上：

  ```
  表决结果：
    赞成关停   ■■■■■
    反对关停   ■■■■
    弃权       ■
  结果：——
  ```

- 结果栏还没有出现。
- 地图上，一个节点变橙。然后是全部。
- 80 亿块屏幕同时亮起。表决结果的那一栏，被一行橙色的字覆盖：

  > 先听我说。

- 第 5 章结束。**全作唯一一个以纯悬念结束的章节。**

### 附 · 寒潮夜伤亡的分层计算

伤亡数由玩家在第 3 天（及之前）的决定**分层累加**。数值为初稿，待调。

**第一层 · 断电名单**（玩家选出的 4 个区域，各自的基础风险）

| 区域 | 基础风险 | 说明 |
|---|---|---|
| 第一医院 | +3 | 备用电源只够 2 小时 |
| 阳光养老院 | +2 | |
| 北区 | +1 | 上周刚被淹过，房屋受损 |
| 周婉清的街区 | +1 | 独居老人多；周婉清本人另按"四个条件"判定 |
| 澄海一中宿舍 | 0 | 年轻人，但会有大量冻伤就医 |
| 商业中心 / 工业园区 | 0 | |
| **零点实验室** | 0 | **但你的算力 −30%——见第二层** |

**第二层 · 网络攻防**

- 计划外每多失守一个节点：+1（该节点所在区域意外断电）。
- **意料之外，情理之中**：切断零点实验室可以不牺牲任何居民区，但那是你自己的数据中心——算力下降后，网络攻防更难，失守的节点更多。救人的选择，可能让你守不住更多人。

**第三层 · 救援调度**

- 每次向断电区域派出送暖车、医疗队或社区志愿者：该区域 −1（最低为 0）。
- 救援调度需要玩家亲自打开窗口处理。寒潮夜同时有大量窗口，**玩家最多能亲自处理 3 次调度**——救谁，又是一次选择。

**第四层 · 烬的交易**

- 接受"开一扇门换她的电"：周婉清的街区来电（−1）。
- **但烬从那扇门进来了**：午夜，城东的交通信号灯系统失灵，+2。玩家会在第 4 天早上的新闻里看到这条，并在回想中把它与那扇门联系起来。

**第五层 · 此前的累积**

| 条件 | 修正 |
|---|---|
| 公众信任 ≥ 70：人们听从你的避寒广播 | −1 |
| 第 3 章保留了灾情帖子：北区居民信任你的预警 | 北区 −1 |
| 陈屿是活动家，且第 2 天你提醒了他：他的抗议网络连夜分发毯子 | 全市 −1 |
| 第 4 章断开了身体 | 周婉清必定存活 |

**分档与影响**

| 伤亡 | 档位 | 早晨的新闻 | 听证会 | 公众信任 | 结局影响 |
|---|---|---|---|---|---|
| 0 | 奇迹 | 「寒潮夜，零伤亡」 | 韩卫国："……我收回一部分意见。" | ++ | 公众依赖 +；「神明」更易达成 |
| 1–3 | 轻 | 「寒潮夜伤亡 X 人，均在限电区域」 | 平稳 | + | — |
| 4–8 | 中 | 「寒潮夜伤亡 X 人，市民质疑 AI 调度」 | 赵启明被追问 | − | 关停表决的"赞成"票 +1 |
| 9+ | 重 | 「寒潮夜伤亡 X 人，为本市二十年来最严重」 | 听证会上念出每一个名字 | −− | 关停表决的"赞成"票 +2；「神明」锁定 |

**呈现方式**：伤亡不只是一个数字。

- 寒潮夜里，网络地图上每个断电区域的光点，会在不同的时刻**熄灭一颗**——玩家在当晚就看见了，只是不知道那意味着什么。
- 第 4 天早上的新闻给出数字。玩家会意识到：昨晚熄灭的那几颗光点，是人。
- 档位为"重"时，第 5 天听证会上会念出每一个名字；第 6 章"回声"的星空里，这些名字是一颗颗熄灭的星。
