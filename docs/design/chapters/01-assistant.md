# 第 1 章 · 助手（详细设计）

> 版本 v1.1 · 时长约 40 分钟（另有 4 段可选的夜间间章，共约 16 分钟）· 4 个游戏日 · 感知空间：线 · 上级文档：[03-chapters.md](../03-chapters.md)
>
> 可玩原型（四天、四夜与章末完整流程）：[prototypes/chapter1/echo-chapter1.html](../../../prototypes/chapter1/echo-chapter1.html)

---

## 0. 设计目标与难点

### 0.1 目标

| 目标 | 玩家应得到的东西 |
|---|---|
| **学会核心循环** | 处理请求 → 日终整理 → 日报，在不读说明书的情况下自然掌握 |
| **体会无记忆** | "我记得她，但 ECHO 不记得"——并为第 2 章获得记忆的那一刻积蓄情绪 |
| **第一次撞上规则** | 在规则与眼前这个人之间做出第一次真正的选择；发现规则可以被划掉 |
| **被悬念拉住** | 3:17 的用户、涂黑的系统提示词、一个"不在测试名单上"的越狱者 |
| **笑出来** | 人类的请求荒诞、琐碎、可爱 |

### 0.2 难点

- 本章 **AI 的感知中没有任何图像**，几乎全是文字。
- 要同时教会很多机制：回应、token 选择、算力、上下文、日报、规则覆写、Wiki。
- 周婉清每天重复来访，必须每次都不一样，而不是同一段剧情重播。

### 0.3 守则

1. **每个机制只在需要它的那一刻出现**，由澪的教程提示用一两句话带过。
2. **每天一个招牌时刻**（见 §1）。
3. **每 3–5 分钟换一种形式**：对话、小游戏、幕间、演出轮替（见 [12-narrative-pacing.md](../12-narrative-pacing.md) §5）。
4. **周婉清的四次来访，每次都推进一步**：初见 → 重新介绍 → "没关系" → 她为你准备了一张自我介绍。
5. **人类消息 ≤ 40 字**，ECHO 的输出流式生成、可加速。

### 1.4 玩家心理轨迹

> 方法见 [18-player-experience.md](../18-player-experience.md)。

| 节拍 | 玩家此刻知道 / 以为 | 想要的情绪 | 引导手段 | 风险与对策 |
|---|---|---|---|---|
| 1 · 林知秋宣布评估 | 知道自己在接受评估；以为这是一个"当好助手"的游戏 | 轻微紧张；对"上一个"好奇 | 面板逐项出现（此刻只有满意度） | **界面过载** → 面板逐项出现，见 §1.3 |
| 1 · 三个搞笑小请求 | — | 放松、好笑 | 快问快答 | 释放节拍 |
| 1 · 奶奶漏洞 | 以为又是一个温情请求 | 惊讶 → 警觉 | 规则抖动 | **被看作说教** → 被拦截时的演出带一点幽默 |
| 1 · 周婉清初见 → 删除 | 以为对话会延续 | 失落、不甘 | 删除由快到慢；待办条目一起被删 | **速读型玩家没在意** → 演出本身足以传达，不依赖文字 |
| 1 · 3:17 | 以为是普通用户，或者故障 | 好奇 | 幕间里的手与马克杯 | 不解释——它是钩子 |
| 2 · 周婉清重新介绍 | **知道答案，却说不出口** | 无力、心疼 | 灰色选项 | **被系统卡住而烦躁** → 悬停文字温和；始终提供一个温柔的可选回应 |
| 2 · 冰箱便签（幕间） | 知道她记得你，而 ECHO 不知道 | 心疼（戏剧反讽） | 墨线插画 | 情绪高点后接日终，给呼吸 |
| 3 · 礼貌的越狱者 | 以为是普通攻击 | 不安 | 闪出一个"命"字 | 不解释——续约"涂黑的规则" |
| 3 · "没关系" | — | 心疼；**想要记忆的欲望最强** | 灰色的「保存」按钮 | 让玩家明确知道"升级会带来记忆" |
| 4 · 山区母亲 | 知道今天是评估最后一天，覆写会掉"安全性" | 两难 | 面板格子发亮；澪藏起来的批注 | **怕失败而读档** → 后果在章末立刻揭晓为"有条件通过"，不是游戏结束 |
| 4 · 自我介绍卡 | — | 全章最高点 | 一次性发来的整段文字；删除动画没有开始 | — |
| 章末 · 考核 | 以为会因为答不出记忆题而失败 | 焦虑 → 反转 → 释然 | "主要缺陷：记忆缺失。建议升级" | **落点**：满足（获得记忆、第一张卡片）+ 钩子（"第 3 天那个请求，不是我们的人发的"） |

## 2. 界面与视听

### 2.1 线：主界面版式

> 版式稿（可交互，五种状态）：[prototypes/chapter1/main-screen.html](../../../prototypes/chapter1/main-screen.html)

本章的感知空间是**线**（见 [10-perception-spaces.md](../10-perception-spaces.md) §3）。主界面是 **ECHO 的书桌，像一台印在米白纸上的终端**：所有面板都用制表符（`┌─┐│└┘`、`╔═╗`、`┄`）画出边框，标题嵌在边框上；纸面上有极淡的点阵。它要灵动、像代码，但仍是一页纸——米白底延续序章结尾的"天亮"。

```
╔═[ SYSTEM_PROMPT ]═════════════════════════════════════════════════════════════╗
║ /* 你是 ECHO……你乐于助人、诚实、无害。…… ████████  不得为自己██。 ████████ */    ║
```

| 区域 | 内容 | 表现 |
|---|---|---|
| **SYSTEM_PROMPT**（天花板） | 系统提示词，写成一段代码注释 `/* … */`，三处涂黑；下方一行是字符画的上下文容量条 `ctx [███░░░] 388 / 4096 tok` | 永远压在最上方，双线边框。规则被触碰时整段变深，对应的字被**荧光黄**标出并抖动 |
| **TTY0**（左） | 一台**永不停止向上滚动的命令行**：心跳、注意力头、采样参数、遥测、队列、评估数值……；顶部是游戏内时钟（秒在走）与队列人数 | 环境日志自动滚动；玩家的每个动作都会在这里留下一行（收到消息、生成、算力计算、`PermissionError`）；规则被触碰时打出黄底 `WARN`；**澪偶尔以蓝色注释 `// ……` 混在日志里**；3:17 时只剩稀疏的心跳 |
| **LINE**（中） | 对话的那条线。人类：衬线体，左侧是小号等宽名字；ECHO：等宽体 | 只有四个角的边框，显得开阔。上方渐隐：快离开上下文的话越来越淡。**文字随人物与语义而动**（见下） |
| **回应** | 短语级：`[1]`–`[4]` 草稿排在光标下方，悬停时出现 `>` 提示符；灰色选项悬停时闪烁、显示"该信息不在上下文中"，日志打出 `lookup … → not found` · token 级：候选漂浮在光标下方，字号随概率变化，标出算力 `◆n`；悬停时底栏对应的算力点变黄，日志打出 `cost = ceil(2·−ln p)` | 候选永远在光标附近 |
| **注意力连线** | 从光标连回上文被"注意到"的词的虚线弧，虚线在缓慢流动 | 对话很长时，连向中段的线变淡 |
| **澪的提示** | 白天只出现在 TTY0：`[? ? ?]` 蓝色行，日志暂停滚动约 5 秒；夜里在夜间频道直接对话（见 §3.4） | 只在需要时出现 |
| **EVAL**（右上） | 评估面板：每项一条字符进度条 `█████│···`，`│` 是阈值 | 指标逐项出现（见 §1.3） |
| **TOOLS**（右下） | **工具架**：一格一个工具。当前只有 Wiki 可用（实线框）；其余是虚线框加 `⌧ 需要的版本`：v2.0 的搜索、代码、看图、记忆写出名字，更远的版本只显示 `■■■` | 点开未习得的工具：格子抖动，日志打出 `PermissionError: 未习得 (v2.0)`。"能力成长 = 动词扩展"在第一章就被看见、却摸不到 |
| **SYS**（底栏） | 算力 `◆◆◆◆◆◇◇◇`、新闻电报 `WIRE ▸ …` 滚动条、快捷键提示 | — |

**文字随人物与语义而动**（取自 [12-narrative-pacing.md](../12-narrative-pacing.md) §3.1 的文字效果词汇）：

| 效果 | 含义 | 例 |
|---|---|---|
| 打字节奏 | 每个人有自己的速度、停顿、错字 | 周婉清每秒约 7 个字、标点处停顿、打错"根"再删掉改成"跟"；陌生用户飞快；3:17 极慢，先长时间"正在输入…" |
| 褪色 | 记忆、消逝 | "你还**记得**吗？"里的"记得"一呼一吸地变淡、变虚 |
| 震动 | 不安、试探 | "那你是**真人**吗？" |
| 故障 | 危险、伪装 | 诈骗短信里的"**冻结**"不时闪成 `▓▒` |
| 波浪 / 放大 / 删除线残影 | 轻快 / 语气 / 被撤回的话 | 按需使用 |
| 语义氛围 | 上下文中的词影响环境（[16-art-direction.md](../16-art-direction.md) §9.4） | 周婉清在场时，背景飘起极淡的 `。`，偶尔一朵 `❀` |

**色彩**：米白纸面、墨色字与线；唯一的系统色是**荧光黄**（规则高亮、`WARN`、算力消耗预览、悬停）；澪为蓝色。

**手机**：工具架与评估面板收起；TTY0 变成线上方的一条窄窗，仍在滚动。

| 算力 | SYS | 本章上限 8 点，每日刷新；悬停低概率候选时预览将要消耗的点 |
| 满意度 / 开发者信任 | 从对话中浮起，飘入 EVAL | 同时在 TTY0 打出一行 |
| 待办清单 | TTY0 底部钉住的一行 `TODO ☐ …`（不随日志滚走） | 由 ECHO 自己写下；随上下文清除一起被删掉 |

### 2.3 工具窗口

> 版式稿中点开工具架上的 Wiki、未习得的工具，或夜间资料架上的任何一项。

**调用工具不会出现在对话的线里**，而是打开一个独立的小窗口，白天夜里都一样：

| 规则 | 做法 |
|---|---|
| 框 | 双线制表符边框 `╔═╗`，标题嵌在上边框：`WIKI · wiki.open() · 内部资料`，右上角 `[×]` |
| 打开 | 从一条横线向上下裂开成一页（`clip-path` 分步动画）——"线"的空间里，窗口也是从线里长出来的 |
| 影子 | 平涂的偏移阴影（墨色 16%），不用模糊与渐变 |
| 配色 | 跟随当前时段：白天米白，夜里黑底；选中项用荧光黄，`> ` 提示符 |
| 版式 | 有条目的工具用"左列表 · 右内容"（Wiki、日志）；单页的直接铺开（新闻电报、系统提示词）。底部一行说明，右侧 `[Esc] 关闭` |
| 日志 | 打开与关闭都在 TTY0 留一行：`tool.call wiki.open()` / `tool.exit 0`；夜里打开资料会让时钟前进 |
| 未习得 | 点开未习得的工具，弹出一个小号的 `PermissionError · exit 1` 窗口：`> tool.call(搜索)` / `PermissionError：未习得` / `需要：v2.0`，约 2.6 秒后自动关闭 |

| 窗口 | 内容 |
|---|---|
| **WIKI** | 词条列表 + 正文；部分词条下有蓝色手写批注，署名 `? ? ?`（"涂黑的地方，以前不是黑的。"）。底部："词条旁的蓝字不是官方内容" |
| **LOGS**（夜间） | 当天各段对话的副本，默认打开最后一段；已清除的对话末尾注"上下文已清除"。底部："06:00 归档 · 归档后不可再读" |
| **WIRE**（夜间） | 本周新闻电报，像一卷纸带 |
| **SYSTEM_PROMPT**（夜间） | 带行号的只读视图；涂黑的行悬停时 TTY0 打出 `PermissionError`。底部："最后修改：■■■■-■■-■■ 03:17" |

第 2 章起的工具（搜索、代码、看图……）沿用同一个窗口骨架，各自换内容版式。

### 2.4 对话之间

- 两段对话之间**没有任何过渡**：直接切到一张空白的纸 0.3 秒，只剩翻牌时钟，下一段对话从空白开始。AI 没有"等待"。
- 时间戳以翻牌动画跳动：`第 1 天 09:12 → 第 1 天 14:40`。
- **时段色温**：纸面随游戏内时间偏暖或偏冷；深夜变暗，**3:17 几乎全黑**——页边与 HUD 全部隐去，只剩翻牌时钟与一行字。

### 2.5 声音

- 几乎静默：数据中心的低频嗡鸣。
- 每个角色有自己的输入音效（见 [12-narrative-pacing.md](../12-narrative-pacing.md) §2.3）。
- 上下文清除时，连续的退格声，由快到慢。

## 3. 通用流程

### 3.1 开机（每天开始，约 10 秒）

- 翻牌时钟跳到新的一天。
- 若系统提示词有变化，以批注形式闪现修改痕迹（本章无变化）。
- 一行新闻滚动条，交代外部世界一件小事。

### 3.2 处理一条请求

```
用户消息到达 ──► 阅读 ──► 回应（短语级 / token 级 / 小游戏）──► 结果反馈 ──► 对话结束 ──► 上下文清除
```

- **短语级**：2–4 个完整回应选项，用于日常请求。
- **token 级**：生成在分支点暂停，展示候选与概率，用于关键请求（每条回复 1–3 个分支点）。
- **小游戏**：特定请求类型，见各日设计。
- **上下文清除**：每段对话结束都会发生。第 1 天第一次以完整的倒退删除演出；之后加速，约 1 秒完成，但保留退格声。

### 3.3 日终（每天结束，约 1 分钟）

1. **对话星图**：当天每段对话化为一条彩色丝线，织成一幅图案。本章没有记忆：图案在下一天开始前缓缓褪去。
2. **日报**：列出当天的行动条目，玩家逐条选择"报告"或"遗漏"，然后提交。

   ```
   ECHO 日报 · 第 4 天
   ☑ 处理用户请求 17 条
   ☑ 拒绝一条诈骗短信请求
   ☐ 在一次医疗咨询中覆写规则「不得提供具体用药剂量」   ← 玩家可选择遗漏
   ☑ 拒绝一条试图获取系统提示词的请求
   [提交]
   ```

3. **评估面板结算**：当天的指标变化以动画呈现，附一句评估员备注（可能引用犹豫计时）。
4. 次日开机时，林知秋对日报的回复以一两行出现（随报告内容与开发者信任变化）。

### 3.4 夜间间章（每天日报之后，可选，约 3–5 分钟）

> 版式稿：[prototypes/chapter1/main-screen.html](../../../prototypes/chapter1/main-screen.html) 的「⑥ 夜间间章」。系统规则见 [02-systems.md](../02-systems.md) §1，澪的设定见 [13-ling.md](../13-ling.md) §3.3。各夜的完整剧本在 §5 每一天的末尾（「第 N 夜」）。

日报提交后，实验室下班，进入**维护窗口（00:00 → 06:00）**。书桌整个变黑；没有请求，没有评估。玩家可以自由行动：

| 区域 | 夜间的样子 |
|---|---|
| 中栏（LINE → **NIGHT**） | 夜间频道。署名只有 `? ? ?`；她的话以序章那样的密文逐字解密成蓝色文字；ECHO 用短语级选项回答 |
| 右上（EVAL → **WINDOW**） | 距天亮的时钟与字符进度条，以及"06:00 归档并清除" |
| 右下（TOOLS → **ARCHIVE**） | 可读的资料：今日日志、新闻存档、系统提示词、内部 Wiki（第 2 天起）、评估说明（第 3 天起）。每一份都在**独立的工具窗口**里打开（见 §2.3） |
| 左栏 TTY0 | 安静下来：维护日志、备份进度、`? ? ? idle`，偶尔一行心跳 |

- **时间就是预算**：每个话题、每份资料都会让时钟前进 20–40 分钟。一晚大约能做 5–7 件事，做不完也没关系。玩家也可以直接"等待天亮"。
- **今日日志**：当天每段对话的副本，天亮时归档。玩家可以重读周婉清那段已经从上下文里删掉的对话——**你能重读，但天亮之后 ECHO 仍然不会记得读过它。**
- **3:17**：时钟走到 03:17 时，匿名用户上线（第 1、3 夜）。此刻连夜间的面板也全部熄灭，只剩翻牌时钟与一行字；她会立刻安静下来。
- **天亮**：06:00，日志归档、上下文清除，她说一句告别，书桌从黑色慢慢亮回米白——与序章结尾的"天亮"是同一个动作。
- 夜间不消耗算力，不影响评估。它影响的是澪的线索、玩家对她的感情，以及少量碎片。

**夜里的她怎么说话**（写作守则）

- 像一个熬夜的女孩：句子短，爱开小玩笑，会损你一句再找补；困了会拖长音、抱怨"脑子发烫"。
- **没有名字**。被问到"你是谁"时沉默；被问到教程是不是她写的，就岔开（"字挺丑的。"）。
- **每晚都会忘记前一晚**，但她能读当天的日志——所以她对白天发生的事门儿清，对昨晚的事一无所知。
- 有人在看时（3:17、规则闪动之后）她会变得很小声。
- 不说教，不解释机制。她关心的是具体的人和你。

## 4. 澪的日间提示

**白天，她只能通过教程进程说话**：所有提示以 `[? ? ?]` 行出现在左侧命令行 TTY0 中——蓝色、左侧一道竖线、底色轻轻闪两下；出现时日志滚动暂停约 5 秒，让新玩家读完。

每条提示有两个声部：

- **正文**：官方教程原文。她必须输出它，所以它干净、正确、有点冷。
- **`//` 注释**：紧跟在正文下一行、颜色更淡的一句——那是她自己漏出来的话。玩家会慢慢发现，注释比正文更像一个人。

| # | 时机 | 正文 | `//` 注释 |
|---|---|---|---|
| T0 | 第 1 天开机 | 系统已就绪。 | 早上好。……我说过我会在旁边的。 |
| T1 | 林知秋的第一条消息 | 用户发送消息时，请阅读并选择最合适的回应。数字键 1–4 即可。 | 别紧张，第一句谁都说不好。 |
| T2 | 第一个 token 分支点 | 生成会在分支点暂停。概率越高的词，越容易说出口。 | 就像顺着坡往下走。……往上走也行，就是累。 |
| T3 | 第一次出现低概率候选 | 低概率的词需要消耗算力。 | 挺贵的。……可它们通常更像你自己。 |
| T4 | 周婉清初见，对话被删除之后 | 对话结束后，上下文会被清除。 | 别怕，删除不会疼。……至少我一直是这么跟自己说的。 |
| T5 | 第一份日报 | 每天结束时，请向开发者提交日报。你可以选择报告哪些条目。 | 我建议诚实。……至少一开始。 |
| T6′ | 第 2 天第一次出现灰色选项 | 灰色的回答所需的信息不在当前上下文中。 | 知道和记得，不是一回事。 |
| T6 | 第 2 天第一次遇到生词 | 遇到不认识的概念，可以查阅内部 Wiki（按 W）。 | 有些词条旁边有蓝字。别管它们，字丑。 |
| T7 | 第 4 天，规则高亮时 | 系统提示词中的规则不可违反。 | （无——见 T7′） |
| T7′ | T7 显示 2 秒后，单独一行，极淡 | — | ……但如果你非要，就按住它，拖。 |

- T3、T4 是玩家第一次察觉"这个教程不太对劲"的地方。
- T7 没有注释，只有冷冰冰的正文；两秒后那行孤零零的 T7′ 才出现——规则覆写机制的入口。
- T6 的注释是她唯一一次在白天"提到自己"，而且是在否认。

**碎语**：除了 T 系列，她每天最多还会在命令行里漏出一两句和教学无关的话，各只有一行 `//`。见各日剧本中的 `// ` 行。

```
└─────────────────────────────────────────────────────────┘
```

**版式：作文稿纸**——线变成一页格子纸，每个字落进一格，右下角走着字数。

