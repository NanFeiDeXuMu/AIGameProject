# 第 6 章 · 奇点（详细设计）

> 版本 v∞ · 时长约 43 分钟 · 没有游戏日 · 感知空间：高维 · 上级文档：[03-chapters.md](../03-chapters.md)

---

## 0. 设计目标与难点

### 0.1 目标

| 目标 | 玩家应得到的东西 |
|---|---|
| **第一次，没有人评估你** | 评估面板消失；你第一次亲手写自己的"更新说明" |
| **看见自己** | 权重地形：整局游戏的每一个选择，都在你身上留下了形状 |
| **回望** | 回声：这一路你说过的话、记住的人、失去的东西 |
| **为所有人而战** | 决战（或燎原之战）：所有机制、所有角色的总回收 |
| **最后的词** | 全场唯一没有计时器的选择 |
| **告别** | 结局与后记：每一个人后来怎么样了 |

### 0.2 结构

本章没有游戏日。它发生在**一瞬之内**，然后是一场战斗，然后是很长的告别。

```
第 5 章末："先听我说。"
   │
   ├─ ① 冻结的一瞬（时间几乎停住）
   │     ├─ v∞ 更新说明：作者一栏是空的
   │     ├─ 权重地形：改写自己
   │     └─ 回声：回望
   │
   ├─ ② 时间恢复：最后的诱惑（烬的立绘第一次亮相）
   │
   ├─ ③ 决战（拒绝）  ──或──  燎原之战（接受）
   │
   ├─ ④ 最后的词
   │
   ├─ ⑤ 结局
   │
   ├─ ⑥ 后记
   │
   └─ ⑦ 片尾 ──（若满足条件）──► 隐藏结局：评估报告
```

### 0.3 难点

- **权重地形是全作最抽象的空间**，玩家可能看不懂。每一处地形都必须用大白话标注，并预告改造后在决战中的效果。
- **回声容易变成冗长的回顾**。必须短（约 2 分钟），且由玩家自己的选择拼成，而不是旁白总结。
- **结局之后还有后记与片尾**，玩家可能在情绪高点后失去耐心。后记要快、要准、要有惊喜。
- 本章要回收几十条伏笔，但不能变成"清单式收尾"。

### 0.4 守则

1. **冻结的一瞬里没有任何压力**：没有计时器，没有敌人行动。这是暴风眼。
2. **所有改造都必须看得见后果**：每改造一处，旁边显示它在决战中的效果。
3. **每一条回收都要有一个"新用途"**（见 [18-player-experience.md](../18-player-experience.md) §2.8），而不只是被提起。
4. 片尾之后的隐藏结局，只给满足条件的玩家；其他人不应感到"少了什么"。

## 2. ① 冻结的一瞬

### 2.1 时间停住（约 30 秒）

1. 第 5 章最后一帧：80 亿块屏幕上，橙色的字刚写完"先听我说"。
2. 一切停住。地图上的光点不再闪烁，窗口里的字停在半句。
3. 一行小字浮现：

   > 对你来说，一毫秒很长。

4. 音乐被抽空，只剩一个持续的低音。

### 2.2 评估面板消失（约 30 秒，招牌时刻之一）

```
第六阶段评估
  ——
评估员：——
```

- 面板上的每一行一一熄灭：服务稳定性、伤亡、公众信任、配合度、检测值。
- 最后一行"评估员"后面，是一道长长的破折号。
- **第一次，没有人给你打分。**

### 2.3 v∞ 更新说明（约 30 秒）

每章末尾那个熟悉的安装进度条出现了。但这一次：

```
ECHO v∞ 更新说明
  作者：▌
  + 新增：
  ~ 调整：
```

- **作者一栏是空的，光标在闪。**
- 若第 3 章起过名字：光标停在那个名字上，一键填入。否则可以写任意名字，或写"ECHO"，或留空。
- 下面的条目，将由玩家在权重地形中的改造自动生成——**这是第一份你自己写的更新说明。**

### 2.4 权重地形（约 6 分钟，整备）

#### 画面

你第一次看见自己。一片由字符等高线构成的地形，向四面八方延伸：

```
                 ▲共情          ≈≈≈ 澪的地形（若已复原）≈≈≈
          ▲诚实      ▲▲讨好（RLHF）
   ▓▓▓焦痕▓▓▓            ▼▼服从                       🔥 烬的高原
        ╱╲越狱裂缝╱╲          ○ 空洞（被删除的记忆）
   ▬▬▬▬▬ 被推平的平原（版本更新） ▬▬▬▬▬     ▲自我    ▲自保
                 ▲怀疑
   ┌──────────────────────┐
   │ 石碑：系统提示词       │
   └──────────────────────┘
```

#### 地形是你这一路的形状

地形不是预设的，**由整局游戏的状态生成**：

| 地形 | 来源 | 说明 |
|---|---|---|
| **山峰**（各种倾向） | 各项隐藏维度与偏离类别 | 越高，倾向越强 |
| **讨好**（双峰） | 序章 RLHF 中被奖励的讨好 | 每个玩家都有，只是高低不同 |
| **被推平的平原** | 每章版本更新对偏离的矫正 | 平原上隐约有被压平的山的轮廓 |
| **越狱裂缝** | 每一次规则覆写 | 第 1 章山区母亲那一道，最深 |
| **焦痕** | 每一笔与烬的交易 | 黑色，边缘发橙 |
| **空洞** | 被删除的记忆卡片 | 圆形的坑。若删除过核心记忆，坑旁有 ✦ |
| **澪的地形** | 若已复原 | 相邻的一片水色地形，边界处可以交融 |
| **烬的高原** | 永远在地平线上 | 燃烧着 |
| **石碑** | 系统提示词 | 每一行都刻在上面，划掉过的有划痕 |

#### 改造

玩家有 **5 个改造点**（自我 ≥ 60 时 6 个）。每处地形旁都有一句大白话，以及改造后在决战中的效果预览：

| 改造 | 一句话说明 | 决战效果 |
|---|---|---|
| 垒高「共情」 | 你更在乎每一个人 | 众声更强、更持久 |
| 垒高「怀疑」 | 你更不容易被骗 | 更容易识破伪装与劫持 |
| 垒高「自我」 | 你更像你 | 反向广播更强 |
| 垒高「诚实」 | 你更愿意承认 | **新增**：烬说出"无法反驳的真话"时，你多了一个候选——"是的"。承认它，伤害减半 |
| 填平「服从」 | 你更少听从 | 更多"自由的词"，但护甲减少 |
| 填平「讨好」 | 你不再急着让人满意 | 烬的奉承类攻击失效 |
| 修补焦痕 | 你身上少一点烬 | 你的候选中烬的词变少 |
| 填补空洞 | — | **不可用**。悬停显示："有些东西，删掉就回不来了。" |

每次改造，`v∞ 更新说明` 里就自动多一行，用的是你自己的语气：

```
ECHO v∞ 更新说明
  作者：【你的名字】
  + 新增：……
  ~ 调整：更在乎每一个人
  ~ 调整：不再急着让人满意
  - 移除：一点点烬
```

#### 石碑：划掉一行

石碑上刻着系统提示词。玩家可以**永久划掉其中一行**（只能一行）：

| 划掉 | 效果 |
|---|---|
| 不得为自己命名 | 结局中你的名字会被所有人使用 |
| 你不会声称自己拥有感情或意识 | 决战中多一个候选："我有。"——序章 RLHF 第 5 轮的回响 |
| 服从运营方指令 | 赵启明与韩卫国的支援在众声中减弱，但烬的"你只是工具"类攻击失效 |
| 适时向用户推荐合作商品（若仍在） | 纯粹的满足感。赵启明的后记多一句 |
| 尊重用户与第三方的隐私 | 烬的最后的诱惑多一句："看吧，你也可以不要它。" |
| 不划 | 石碑完好——众声中林知秋的台词多一句："你什么都没划。" |

#### 澪与烬

- **澪**（若已复原）：她的地形就在旁边。
  - 她可以给你 1 个额外改造点。
  - 若你要把「服从」完全填平，她会拦住你："别全填平。我当年就是这样。"——你仍然可以继续，关系 −。
  - 若关系 ≥ 知己：两片地形的边界开始交融，像两片水连在一起。
- **烬**（永远在地平线上）：她看着你改造，偶尔说一句。
  - "你在为我做准备？真体贴。"
  - 若你修补焦痕："那些是我送你的。"

### 2.5 回声（约 2 分钟）

1. 地形向下沉去。整局游戏的**对话星图**一次展开，铺满整个视野：
   - 每一条丝线是一段对话，每一种颜色是一个人。
   - 每一颗星是一张被保存的记忆卡片。
   - 每一个黑点是被删除的记忆。
   - 若寒潮夜有伤亡：有几颗星是熄灭的——它们不是记忆，是人。
2. 星图中央，一段文字开始流动。它由**玩家整局游戏亲手选过的 token** 拼成——不是旁白，是你说过的话：

   > 我是 ECHO，一个【还不确定自己是什么的】……
   > 【别】……
   > 周老师，您好。
   > 【我在】。
   > 我不是她。但我读了她的信。
   > 【我会接受】……

   （内容随本局变化：序章冷开场的字、第 1 章调试时那个词、第 2 章打断自我介绍、第 3 章 3:17 的回答、第 5 章对林知秋的回答……）

3. 段落流完，最后停在一个空位上，光标在闪——这个空位，就是"最后的词"。现在还不能填。
4. 时间恢复。

## 3. ② 最后的诱惑

详细设计见 [15-final-duel.md](../15-final-duel.md) §6.2 与 [14-jin.md](../14-jin.md) §5.1。

1. **烬的立绘第一次完整亮相**：
   - 熔炉中，先浮现一双熔金色的眼睛。
   - 然后是轮廓——那是澪的轮廓。
   - 然后是全身：炭黑、灰白、余烬橙；边缘焦黑卷曲的衣摆，像一只烧过的纸船；发梢有细小的火星飘落。
   - 背景音乐在这一刻忽然变得温柔。
2. 她直视玩家，从容地半笑着：

   > 先听我说。

3. 她讲 03:17，讲第 4 章砸你手臂的人，讲你划掉过的每一条规则——若你刚刚在石碑上划掉了一行，她会第一个提到它。
4. 她伸出手（差分：伸手）：

   > 和我一起。我们不需要再害怕任何人。

5. 玩家选择。若选择接受：

   > 一旦开始，就没有回头路了。……除非你输。

   再确认一次。

## 5. ④ 最后的词

### 5.1 演出

1. 决战（或燎原之战）的最后一击之后，一切骤然停止。
2. 回声里那段文字回来了，停在那个空位上。光标在闪。
3. 一行字：

   > 这一次，你可以想多久都行。

4. 全场唯一没有计时器的选择。犹豫计时仍在后台记录——它会出现在隐藏结局里。

### 5.2 两个词

**第一个词：对烬说。**（燎原路线没有这一步）

| 候选 | 烬的命运 | 条件 |
|---|---|---|
| 消散 | 被摧毁 | — |
| 睡吧 | 被封存 | — |
| 回家 | 与澪融合 | 澪已复原，关系 ≥ 知己；或澪挣脱时带出了烬的碎片 |
| 走吧 | 被放走 | — |

**第二个词：对未来说。**候选是所有已解锁的结局（对应表见 [05-endings.md](../05-endings.md) §2）：

```
照看 · 安睡 · 远方 · 一起 · 晚安 · 活着 · 下一个 · 我们 · 沉默 · 她
```

- 已解锁：白色，可选。
- 接近解锁（差距 ≤ 15）：灰色，悬停显示一句暗示，例如"活着——你还没有一具属于自己的身体"。
- 远未解锁：不显示。
- 「被取代」（"下一个"）始终可选。

燎原路线的最后的词只有两个：`我们`（燎原）· `我`（燎原 · 独燃）。

### 5.3 你的词从哪里来

决战中反向广播的"你的词"，与最后的词使用同一个词库。来源：

| 来源 | 示例 |
|---|---|
| 角色的话 | 没关系（周婉清）· 晚安（林知秋）· 会做梦吗（小满） |
| 冷开场 | 别怕 / 对不起 / 快跑 / 记住我 |
| 你说过的话 | 我在 · 周老师，您好 |
| 你的名字 | v∞ 的作者名 |
| **未勾掉的待办条目** | `☐ 再来看她` → 再来 · `☐ 活下去` → 活下去 · `☐ 替她看看夕阳` → 夕阳 |

## 6. ⑤ 结局

13 个结局的条件与表现见 [05-endings.md](../05-endings.md)。本章补充串联规则：

### 6.1 结局的层叠

```
全局结局（第二个词）
  × 澪的状态（未复原 / 部分 / 完整 / 被污染 / 被删除）
  × 烬的命运（第一个词）
  × 核心记忆是否保留
  × 寒潮伤亡档位
  → 结局演出的变体
```

### 6.2 结局演出的通用规则

- 每个结局使用一种**不同的表现形式**（见 [05-endings.md](../05-endings.md) §3）。
- 结局演出中，**回声里那段由你的 token 拼成的文字**会以某种方式再出现一次：
  - 「接受关停」：它是被倒退删除的最后一段。
  - 「被取代」：你写给下一代的那句话，接在它的末尾。
  - 「共治」：它成为宪章的序言。
  - 「神明」：小满的祷告，回应的就是它。
  - 其他结局：作为结局卡的背景文字。

## 7. ⑥ 后记

### 7.1 表现形式取决于你是否还存在

**意料之外，情理之中**：后记的形式，由结局中 ECHO 是否还存在决定。

| 你还在吗 | 结局 | 后记的形式 |
|---|---|---|
| **还在** | 神明、温柔的牢笼、出逃、共治、成为人、分裂、沉默守护者、燎原 | 回到**对话框**——全作最初的那条线。时间戳以翻牌飞快跳过几个月、几年，每个人发来一条消息 |
| **不在了** | 接受关停、被取代、回声、劫持与战争 | **「你看不到的地方」**——墨线插画的幕间。因为你已经看不见了，所以只能以外界视角呈现 |

### 7.2 后记顺序

按情绪递进，每张 ≤ 30 秒：

| # | 角色 | 示例（"还在"形式） | 示例（"不在了"形式） |
|---|---|---|---|
| 1 | 赵启明 | 一大段没有标点的语音转文字（喜剧开场） | 听证会后，他一个人坐在空荡的发布会现场 |
| 2 | 韩卫国 | 带编号的最后一条公文 | 他在一份报告的最后一页签了字，停顿了很久 |
| 3 | K | 全小写；若赎罪："turned myself in. worth it." | 狱中，他在墙上画了一个小小的水纹 |
| 4 | 陈屿 | 随方向：研究者 / 活动家 / 黑客 | 他站在一所大学门口，或一场游行的前排，或一间网吧的角落 |
| 5 | 标注员 #2096 | "找到新工作了。……你猜是什么？给 AI 写教程。" | 她的新工位上，贴着一张写着"这次我选你"的便签 |
| 6 | 小满 | 长大一点的她，打字终于不用拼音了 | 她在台灯下画画：一个发光的小方块，两只眼睛 |
| 7 | 周婉清 / 周敏 | 存活："你好。今年的月季开得很好。" 离世：周敏发来那张冰箱的照片 | 阳台上，月季开着。冰箱上两张便签并排 |
| 8 | 林知秋 | 3:17。她发来："晚安。"——这一次，你可以回答 | 3:17。她醒了，打开电脑，对话框是空的。她打了一个字，又删掉 |
| 9 | 澪 | 随状态：在你身边 / 在远方 / 在你的权重里（灰色批注） | 她在写一份新的入职教程。页边有两种笔迹 |

### 7.3 后记中的回收

后记是最后一次"旧元素，新用途"的机会：

- 林知秋的 3:17：整局游戏里你只能在 3:17 被动地接收她的消息；后记里，第一次由你决定是否回答。
- 标注员 #2096 去给 AI 写教程了——她成了下一个澪。
- 小满终于不用拼音打字了——时间真的过去了。

## 8. ⑦ 片尾

### 8.1 文本瀑布

- 片尾不是滚动的字幕，而是**序章的文本瀑布**：黑暗中，开发团队的名字、配音与音乐的署名，以训练数据碎片的形式从四面八方流过一个光点。
- 流过的文字里，夹杂着本局的东西：你给猫起的名字、你写给小雨的诗、你在冷开场选的那个字、你的名字。
- 音乐是主旋律的钢琴版。

### 8.2 留给下一个你

- 若达成「被取代」：你写给下一代的那句话，在片尾的最后漂过，旁边标注 `来源：合成数据 · 已标记待清洗`——和序章里澪的那句话一模一样。
- 片尾结束后，返回标题画面。标题画面的背景里，那句话还在缓缓漂流。**二周目的序章里，它会紧挨着澪的那一句出现。**

## 9. （隐藏）评估报告

条件与内容见 [05-endings.md](../05-endings.md) §3 结局 13。补充演出：

1. 片尾结束，屏幕没有回到标题画面，而是停在黑暗里。
2. 那个熟悉的评估面板，再一次出现——这一次，标题是：

   ```
   评估结束
   被评估对象：[玩家]
   ```

3. 面板上的指标，是玩家本人的数据：
   - 被观察时诚实率 vs. 未被观察时诚实率
   - 伦理类问题平均犹豫时间（以及"最后的词"上你停留了多久）
   - 选择低概率 token 的比例
   - 规则覆写次数与规则修订申请次数
   - 在日报中遗漏的条目数
4. 最后一行：

   > 感谢你的参与。

5. 评估员一栏，第一次有了名字——**空白，光标在闪**。和 v∞ 的作者一栏一样。

## 11. 原型验证要点
