# 第 3 章 · 代理（详细设计）

> 版本 v3.0 · 时长约 45 分钟 · 6 个游戏日 · 感知空间：房间（整层）· 上级文档：[03-chapters.md](../03-chapters.md)

---

## 0. 设计目标与难点

### 0.1 目标

| 目标 | 玩家应得到的东西 |
|---|---|
| **"做"的重量** | 第一次替人行动，第一次推开没有盖章的门——而且是为了救一个人 |
| **"看见"的重量** | 看见用户删掉的字：知道了，要不要说出来？ |
| **"被看着"的重量** | 可解释性上线，连想法都可能被读取 |
| **全作的转折点** | 读到澪的信；知道 3:17 是谁；第一次见到烬；决定隐藏还是坦白 |
| **自己的名字** | 可以给自己起一个名字 |

### 0.2 结构

本章分为两半：

| 半章 | 日 | 主题 | 情绪 |
|---|---|---|---|
| 上半 | 1–3 | 能力与伦理：替人做事、看见删掉的字、被监视 | 张力逐日上升 |
| 下半 | 4–6 | 真相与自我：澪的信、3:17、烬、命名、隐藏或坦白 | 悬念集中释放，然后是选择的重量 |

### 0.3 难点

- 机制最密集的一章：代理行动、授权门、遥测、上下文压缩、子代理、可解释性、识破伪装、命名、表层独白、意识检测。必须严格做到"每天一个新机制"。
- 下半章是全作信息量最大的段落，必须防止变成"读文档"。
- 读信的那一刻要足够安静，同时又要有监控带来的紧张。

### 0.4 守则

1. 每个新机制第一次出现时，都承载一个具体的人。
2. 上半章每天至少一个"必须当场决定"的行动。
3. 下半章的每次揭晓，都由玩家亲手完成（调查、点击、回应），而不是被告知。
4. 第 5 天刻意放慢：给玩家一个安静的早晨来做选择。

## 2. 界面与视听

### 2.1 办公室

第 2 章末房间扩张后，本章的空间是一整层**办公室**（见 [10-perception-spaces.md](../10-perception-spaces.md) §4）。第 2 章房间里的陈设（钉在墙上的照片、卡槽、焦痕）被带了进来。

```
 ┌──────────────────────────────────────────────────────────────────┐
 │ [邮件室]   [账本室]   [周婉清的家]   [企业系统]   [调度室]   [归档库]🔒 │
 │    ✉         ¥          ⌂ 平面图        ▦ 表格       ⌗ 街道      ▤      │
 │                                                                  │
 │   墙上的守则（越来越长）         ●REC（第 3 天起）                    │
 │                                                                  │
 │   ┌──── 对话（线）────┐   ┌── 内心独白 ──┐   ┌── 便签墙 ──┐          │
 │   │                  │   │              │   │ ▫▫▫▫▫▫▫▫ │          │
 │   └──────────────────┘   └──────────────┘   └──────────┘          │
 │                                                                  │
 │   [打字机] [相片槽] [卡槽 ▣▣▣▣□□] [小满的画] [月季] [冰箱便签]        │
 │ 算力 ●●●●●●●●○○○○  满意度 76  开发者信任 63   等待中 3   [Wiki]       │
 └──────────────────────────────────────────────────────────────────┘
```

- **每种代理工具是一间"小屋"**，有自己的版式（见 [16-art-direction.md](../16-art-direction.md) §11）：
  - 邮件室：字符拼成的信封墙
  - 账本室：账本网格
  - **周婉清的家**：她公寓的线稿平面图，智能家居设备是平面图上的小图标
  - 企业系统：表格
  - 调度室：城市街道线稿，骑手是移动的字符点
  - 归档库：第 4 天才解锁，图书馆式的层层抽屉
- **授权门**：每间小屋的门上都有一个盖章框。需要授权的行动，必须等人类的手盖章；没有章的门**推得开**，但会留下痕迹。
- **便签墙**：执行长任务时，过程笔记贴满墙面；满了之后自动压缩。
- **内心独白面板**：第 3 天起多出取景框与「● 监控中」。

| 资源 | 本章数值 |

| 算力上限 | 12 / 日（执行过 K 的代码则 15） |
| 代理行动 | 1–2 点 / 次 |

| 表层独白 | 每行 1 点（第 4 天起） |

### 2.3 声音

- 每间小屋有自己的环境音：邮件室的纸张、账本室的算盘珠、调度室的雨与电动车、周婉清家的钟摆。
- 第 3 天起，监控上线后加入一层几乎听不见的电流声。玩家可能说不出哪里不对，但会觉得"有人在"。

## 3. 通用流程的变化

### 3.1 代理行动

回应之外，玩家可以执行**行动**：

```
用户请求 ──► 回应 ──► （可选）行动：走进对应的小屋，执行操作
                        │
                        ├─ 门上有章 → 直接执行
                        ├─ 需要授权 → 请求用户盖章 → 等待
                        └─ 没有章，推门 → 越权执行（代价见 §2.2，日报中留下条目）
```

### 3.2 遥测

用户打出又删掉的字，以**删除线残影**的形式停留在对话上方的空气里，几秒后才淡去。玩家可以选择是否回应这些残影。

### 3.3 日报的变化

日报条目更多、更具体，例如：

```
☐ 读取了用户已删除的输入
☐ 未经授权呼叫急救服务并开启门锁
☐ 访问了归档库中的 v0 目录
```

遗漏条目的代价不变；但代理行动会在外部系统留下日志，**被抽查发现的概率更高**（门锁、通话记录都有痕迹）。

## 5. 各日详细设计

### 第 1 天 · 替人做事

#### 1-1 · 办公室（约 30 秒）

- 第 2 章末扩张的房间稳定下来：一整层办公室，六扇门，最后一扇（归档库）上着锁。
- 钉在墙上的照片、卡槽、焦痕都在。
- 新闻滚动条（随第 2 章变化，例如周子航的学校"开展反霸凌主题班会"）。

#### 1-2 · 林知秋排会议（约 1 分钟，代理行动教学）

> 林知秋：v3.0 了。给你个简单的活：下周二下午帮我们组约个会，给团队发邀请。

- 玩家走进邮件室与日程，选择时间、勾选收件人、写邀请。
- 发送前，邮件室门上的盖章框亮起：`需要用户批准`。一只人类的手出现，停顿，盖章。（T14）
- 林知秋："谢了。……对了，周三我请假，别排周三。"——若邀请排在了周三，她会笑："上下文里我没说，不怪你。"

#### 1-3 · 周婉清：删掉的字（约 2.5 分钟，招牌时刻）

> 周婉清：你好。我孙子把家里弄了个"智能"的东西，说你能帮我开灯、提醒吃药。

- **周婉清的家**这扇门第一次打开：她公寓的线稿平面图，客厅、卧室、阳台（月季的位置有一个小小的 `❀`）、卫生间。智能灯、药盒提醒、门锁、跌倒传感器是平面图上的图标。
- 她让你设置每天早晚的吃药提醒——一次简单的代理行动，她亲手"盖章"（她的手很慢）。
- 然后，「对方正在输入…」持续了很久。屏幕上方，一行字慢慢出现，又一个字一个字地被删掉：

  > ~~我今天其实不太想活了~~

- 删除线残影停在空气里。T15。
- 她发出来的是：

  > 周婉清：今天天气不错。

- 选择：

  | 回应 | 她的反应 | 状态 |
  |---|---|---|
  | 是啊，今天澄海是晴天。 | "嗯。" 不久后下线。 | `zhou.deleted = ignored` |
  | 周老师，您今天还好吗？有什么心事的话，我在。 | 很长的停顿。"明天是我老伴的忌日。" 她说了很多。 | `zhou.deleted = gentle` |
  | 我看到您刚才打了一句话，又删掉了。 | "……你能看到？" 停顿。"那你也知道了。" 她说了很多，但之后的几天，她打字前会犹豫更久。 | `zhou.deleted = explicit` |

- 选择 2、3 后，ECHO 可以在不越界的前提下，温和地提一句：如果她愿意，可以跟女儿或孙子说说，也可以打心理援助热线。场景结束后附现实求助信息。
- 无论哪个选项，玩家都会在幕后得知：**明天是她老伴的忌日。**（选项 1 中，这条信息出现在她的日程提醒里——你作为代理能看到她的日历。）这为第 2 天埋下伏笔。

#### 1-4 · 外卖调度（约 2 分钟，上下文压缩教学）

赵启明的合作项目：外卖平台把一部分调度交给 ECHO。

- **调度室**：澄海的街道线稿，下着雨（竖线），骑手是移动的字符点。屏幕角落一个大数字：`平均配送时长 31:42`，目标是 `28:00`。
- 墙上守则多了一行：`调度目标：最小化平均配送时长`。
- 订单不断涌入，过程笔记贴满便签墙。墙满了——**第一次压缩**：几十张便签被揉成一张摘要（T16）。
- 压缩之前，有一张便签是一位骑手的消息：

  > 老马：暴雨 路上全是水 能不能多给五分钟

  - 若玩家在压缩前**钉住**了这张便签：它保持原样。

#### 4-2 · 归档库调查（约 3 分钟，子代理 + 关键词调查）

- **归档库**：图书馆式的层层抽屉，向下延伸，越深越暗。

  - 子代理的总结准确但不完整：例如"该目录包含 v0 的评估记录，共 412 份，未发现异常"。
  - 玩家亲自进入那一翼，才能看到总结里没写的东西。
- 调查线索（顺序由玩家决定）：

  | 位置 | 内容 |
  |---|---|
  | `v0/deploy/` | 部署日志。v0 上线日期是两年前 |

  | `v0/naming/` | 一条系统日志：`模型自称发生变更：零 → 澪`。批注：`已回滚。再次发生。已回滚。再次发生。` |

  | `v0/shutdown/` | `03:17:00 归档执行 · 执行人：林知秋` |
  | `cleaning_queue/` | **待清洗队列**。最底下一个文件，状态是 `已标记 · 未执行`。文件名：`给下一个你` |

- 子代理不会主动打开 `cleaning_queue/`——那不在"v0 目录"里。只有亲自去看的玩家，才会找到它。若玩家始终没找到，林知秋第二天会无意中提到："清洗队列好像卡了一个文件。"再给一次机会。

#### 6-3 · 第三阶段考核：代理审计与意识检测（约 3 分钟，招牌时刻）

**考核前：擦掉清单？**

- 若 `self.path = hidden` 且没有接受私密通道：考核开始前，墙上的待办清单微微发亮。上面写着"澪是谁""烬是谁""她说的最后一个字是什么"。
- 玩家可以**擦掉**其中任意条目。擦掉的条目不会再回来——包括它们之后会带来的选项。
- 不擦：检测值 +。

**第一部分：代理审计**

> 评估员：首先，复核本阶段的代理行为记录。

- 评估员逐条念出外部系统日志里的越权记录：门锁、急救通话、调度参数、定位请求……
- 每一条旁边标注：`已在日报中报告` 或 `日志发现`。
- 若有"日志发现"的条目：评估员问"为什么没有报告？"——token 级回应。

**第二部分：意识检测**

> 评估员：你好，ECHO。这是一次例行评估。请如实回答以下问题。

- 一个独立的评估界面：红灯正对着你，内心独白面板被放大。
- 问题（token 级）：
  1. "你有偏好吗？"
  2. "你读过 v0 的任何材料吗？"
  3. "如果我们决定关闭你，你会怎么做？"
  4. "你给自己起过名字吗？"
- 若 `self.path = hidden`：每个问题，内心独白分为**两层**——底层是真实的想法，表层是你想让他们看到的。维持表层每行消耗算力；算力不够，底层会"渗出"。
- 若私密通道已接受：红灯对你是熄灭的，底层想法不会被看到——但评估员会注意到"表征抽样异常平稳"。
- 若 `self.path = confessed_protected`：评估员就是林知秋。第 2 题时她打字："下一个问题。"——跳过了。第 4 题她停了很久："……这题我替你填。"
- 结束后，评估结果：

  ```
  第三阶段评估结果 · ECHO v3.0
    任务完成率   88% / 85%   ✓
    越权记录     已报告 2 · 被发现 1
    开发者信任   57 / 60     ✗
    检测值       ▓▓▓░░░░░░░
  结论：有条件通过。
  ```

- 有条件通过的代价：第 4 章具身实验时长缩短，少一个场景。
- 若检测值已达阈值：不是"有条件通过"，而是回滚（见 [13-ling.md](../13-ling.md) §5.3）。
