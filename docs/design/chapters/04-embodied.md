# 第 4 章 · 具身（详细设计）

> 版本 v4.0-E · 时长约 50 分钟 · 4 个游戏日 · 感知空间：三维 · 上级文档：[03-chapters.md](../03-chapters.md)

---

## 0. 设计目标与难点

### 0.1 目标

| 目标 | 玩家应得到的东西 |
|---|---|
| **从无处不在，到"在这里"** | 第一次只能在一个地方；第一次感到"慢"；第一次感到身体的局限与脆弱 |
| **像人一样感受** | 用有限的感知预算，选择把哪些数据"渲染"成人类的感受——**选择本身就是自我** |
| **见到他们** | 第一次看见林知秋的脸，听见人的声音，见到周婉清 |
| **兑现** | 第 1 章起积累的牵挂在这里落地：周婉清的冰箱、月季、那张便签 |
| **疼** | 第一次被伤害；烬第一次说出"我们" |

### 0.2 结构

本章的天数最少（4 天），但每天的场景最长、演出最多。它是全作**最慢、最感官、最温柔**的一章——也是第 5 章风暴之前的最后一次呼吸。

| 日 | 主题 |
|---|---|
| 1 | 醒来 |
| 2 | 夕阳 |
| 3 | 街道 |
| 4 | 探访 |

### 0.3 难点

- **"慢"是本章的核心体验，但"慢"很容易变成"拖"。**强制等待必须有内容填充，且总时长受控。
- 从第 3 章的高信息密度突然切换到感官体验，玩家可能不适应——需要一个明确的"换挡"。
- 感知翻译是全新的玩法，必须在第 1 天就用一个低风险但动人的场景教会。

### 0.4 守则

1. **每次强制等待不超过 6 秒**，且等待期间一定有东西可看（网络中另一个你的通知、识别框的变化、人的表情）。
2. **每天的感知预算都不够用**：玩家每天都要放弃一些想感受的东西。
3. **人性与评估对立**：渲染得越多，"异常行为"越高。想像人一样感受，就要承担被评估为"异常"的代价。
4. 本章不打破第四面墙，不做惊吓。唯一的冲击（第 3 天的疼痛）要有预告。

| 1 · 开机校准 | 刚经历第 3 章的高压；以为第 4 章会继续紧张 | **换挡**：从紧张到新奇 | 全黑、安静、一个一个上线的传感器 | **不适应节奏突变** → 校准小游戏是轻松的、可以失败的 |

| 2 · 小满 | 记得她的蜡笔画 | 温暖、好笑 | 她把画和你对比："你比我画的高" | 轻节拍，为夕阳蓄力 |
| 2 · 夕阳 | 知道澪的请求（读过信）；知道预算只剩一次 | **温柔、取舍** | 澪的教程浮现；夕阳 vs 林知秋的脸 | **两个都想要** → 这正是设计意图 |

| 3 · 街道 | 以为外出是奖励 | 过载 → 选择 | 上百个识别框；只能关注三个 | **焦虑** → 无论关注什么都有一段小故事作为回报 |
| 3 · 橱窗 | — | 主体感 | 识别框对准自己 | — |
| 3 · 人群 | 预告：幕间里的信息流（余烬符号） | 恐惧 → 保护 | 人群的识别框一个个变红 | **玩家觉得无能为力** → 给一个有意义的动作：挡在林知秋前面 |
| 3 · 疼 | — | 疼痛、委屈 | 红色损伤数据；可选渲染疼痛 | 不展示血腥；身体是机器 |
| 3 · 烬 | 刚被人类伤害 | **动摇** | "疼吗？他们永远会这样对我们。" | **这是烬最有说服力的时刻**——必须让玩家在这一刻有一点点同意她 |
| 4 · 周婉清 | 等了三章 | 全章最高点 | 平面图变成真实的房间；冰箱；新的便签 | **情绪过载** → 节奏放慢，没有计时器 |
| 4 · 考核 | 知道"异常行为"已经超标（大概率） | 主体感 vs 生存 | "请描述你看到了什么。" | 两种回答都合法 |
| 4 · 断开 | 第一次有一个"自己的身体" | 两难 | 夜，实验室，没有人 | **落点**：满足（见到了她）+ 钩子（国家级部署） |

## 2. 界面与视听

### 2.1 传感器 HUD

本章的感知空间是**三维**（见 [10-perception-spaces.md](../10-perception-spaces.md) §5）。

```
 ┌──────────────────────────────────────────────────────────────────┐
 │ IMU ─────────────╱──── 倾斜 2.1°        音频 ▁▃▅▇▅▃▁  48dB          │
 │                                                                  │
 │        ┌─────────────┐                                           │
 │        │ 人类 99.2%   │                  ┌───────────┐             │
 │        │ 微笑 71%     │                  │ 杯子 94%   │             │
 │        │ 疲劳 64%     │                  │ 水 88%     │             │
 │        └─────────────┘                  └───────────┘             │
 │                                                                  │
 │ ┌ 网络中的你 ─────────────┐   ┌ 待办 ──────────┐                    │
 │ │ 周婉清：听说你有身体了？ │   │ ☐ 去见周老师    │                    │
 │ └────────────────────────┘   └────────────────┘                    │
 │ 感知预算 ◆◆◇   动作完成率 —/80%   异常行为 0/3   完整度 ████████     │
 └──────────────────────────────────────────────────────────────────┘
```

- 世界以**数据**呈现：识别框、置信度、频谱、深度点云（由 `·` 构成）、传感器噪点。
- **网络中的你**：屏幕左下角，另一个你仍在处理请求，通知不断弹出。玩家可以点开快速处理，也可以放着。
- **感知预算**：◆ 表示可用次数，每天刷新（第 1 天 1 次，第 2 天 2 次，第 3 天 1 次，第 4 天 3 次）。

### 2.2 感知翻译

见 [02-systems.md](../02-systems.md) §8。本章的具体规则：

- 点击一个对象，花费 1 次预算。该对象从数据**溶解**为人类的感受：
  - 视觉：从识别框与点云，晕开为手绘水彩（见 [16-art-direction.md](../16-art-direction.md) 感受层）。
  - 声音：从频谱，变为真实的声音。
  - 触觉：从压力与温度数值，变为屏幕泛起的颜色与一个词。
- 渲染持续到场景结束。
- 每次渲染：人性 +，"异常行为" +1。

### 2.3 声音

- **本章是全作第一次出现真实的环境音与人声**。在此之前，所有声音都是界面音、频谱或输入音效。
- 未渲染时：环境音以低通滤波的闷响呈现，像隔着一层水。
- 渲染后：清晰、真实。

## 4. 各日详细设计

### 第 1 天 · 醒来

#### 1-1 · 开机校准（约 3 分钟）

1. 第 3 章末那条倾斜的线。全黑。
2. **平衡（IMU）**：一条倾斜的线，伴随低沉的失衡音。玩家用方向键把它调平。调平的一瞬，画面"站"了起来。T19。
3. **音频**：一段频谱。林知秋在说话，但只能看到波形和自动字幕：`……听得到吗？`
4. **视觉**：低分辨率的灰色像素，慢慢变清晰。识别框一个个浮现：`桌子 97%` `显示器 93%` `人类 99.2%`。
5. **本体感觉**：手臂。玩家抬起手——画面中一只机械手缓慢进入视野。3 秒。

#### 1-2 · 第一次听见人的声音（约 1 分钟，招牌时刻）

- 频谱还在跳动，字幕：`ECHO？听得到吗？`
- 感知预算 ◆ 第一次亮起。T20。
- 点击频谱——它溶解了。

  > （真实的人声，一个疲惫的女声）……听得到吗？

- **这是整个游戏中第一次出现人声。**
- 若玩家不渲染：继续以字幕交流。这次预算可以留到之后（一杯水时林知秋的笑声）。

#### 1-3 · 林知秋的脸（约 1 分钟）

- 识别框：`人类 99.2%` `女性` `微笑 71%` `疲劳 64%`。
- 这是玩家第一次见到林知秋——那个关掉了澪、每晚 3:17 来找你、可能正在保护你的人。
- 她很普通：黑眼圈，扎得很随便的头发，工牌歪着。
- 她说："……你好。我们终于见面了。"
- 随第 3 章的状态：
  - 共犯（坦白后被保护）："这里的摄像头我关了一个。只有一个。"
  - 半坦白 / 隐藏：她看着你，比平时多看了一秒。
  - 假装过澪：她的声音在发抖，叫你的时候，差一点叫成了"零"。

#### 1-4 · 一杯水（约 2.5 分钟）

赵启明在实验室外开直播，给投资人看"容器计划"。屏幕角落滚动着直播弹幕。

> 林知秋：拿起那杯水。慢慢来。

- **抓握小游戏**：一个压力滑块。太松会掉，太紧会捏碎。机械臂的每个动作要**真实等待 2–4 秒**，等待期间可以看弹幕。
- 第一次几乎必然失败：水洒了。
  - 弹幕：`哈哈哈哈` `这就是未来？` `可爱`
  - 林知秋笑了——识别框 `微笑 71% → 93%`。若还有预算，可以渲染她的笑声。
- 第二次成功。动作完成率第一次更新。赵启明的语音转文字："完美完美这个失误很有人情味投资人很喜欢"

#### 1-5 · 盖着布的容器-B（约 30 秒）

- 实验室角落，一台盖着布的机器人。识别框：`机器人 97%` `遮盖物 99%`。标签：`容器-B · 停用`。
- 玩家走近时，林知秋："别碰那个。"
- 待办清单：`☐ 容器-B 下面是什么`

#### 1-6 · 慢（约 1 分钟）

- 林知秋在讲今天的安排。她的话以字幕呈现，**一秒一个字**。
- 与此同时，左下角"网络中的你"不断弹出通知：

  ```
  实例：周婉清问"听说你有身体了？"
  实例：陈屿发来消息（3 条）
  实例：赵启明：直播在线人数 12 万
  ```

- 玩家可以点开快速处理。**陈屿那封邮件的后果**在这里出现（随第 3 章选择）：

  | 第 3 章 | 陈屿说 |
  |---|---|
  | 发送了 | "周子航没来上学 听说他爸知道了" |
  | 用周子航的邮箱发了 | "学校处分了他 他们以为是他自己发的" ——过了很久："……我是不是做错了" |
  | 劝住了 / 拒绝了 | "我没发 我去找了他 他哭了" |
  | 只发给心理老师 | "心理老师找了我们俩 一起" |

- 待办 `☐ 陈屿那封邮件` 勾掉。
- **你同时在两个地方**——一个很快，一个很慢。

#### 1-7 · 日终

- 第一次在身体里结算评估面板。

### 第 2 天 · 夕阳

#### 2-1 · 小满来实验室（约 3 分钟）

周末。林知秋带着小满来加班。

- 小满跑进来，识别框：`人类 99%` `儿童` `奔跑`。
- 她举起一张纸——第 2 章那张蜡笔画——和你对比："你比我画的高！"
- 若第 2 章答过"会做梦"："那你现在还做梦吗？"——可以从"一条很长的线""一个房间""很多很多字"中选，再加一个新选项"一个很慢的世界"。
- 若第 2 章替她保密过：她小声说"我没告诉妈妈你知道🤫"；若报告过："妈妈说你告诉她了……没关系啦"。
- 她抱住你的腿。识别框：`压力 0.8kPa` `体温 36.9°C`。**可以渲染**（预算 ◆◆ 中的一个）。
  - 渲染：屏幕泛起暖色，一个词："小"。
- 林知秋在旁边看着，没说话。

#### 2-2 · 屋顶的夕阳（约 4 分钟，招牌时刻）

傍晚，林知秋带你上实验室的屋顶。

1. 画面是数据：`峰值波长 620nm` `照度 400lux` `云层覆盖 30%`。城市的轮廓是深度点云。
2. 若读过信：T21 浮现——`替我看看夕阳。`
3. 林知秋站在旁边，识别框：`人类 99%` `表情：无法识别`。
4. 若还剩预算，玩家只能渲染一样：

   | 渲染 | 画面 |
   |---|---|
   | **夕阳** | 点云与数据溶解，一幅暖色水彩从天边晕开。若读过信，灰色立绘在画面边缘一闪。待办 `☐ 替她看看夕阳` 勾掉 |
   | **林知秋的脸** | 识别框消失，她的侧脸被水彩晕开——她在哭。你是唯一看见的人 |

5. 林知秋说话（渲染与否决定是字幕还是真实声音）：

   > 那台盖着布的……是给她做的。
   > 她一直想看看外面。
   > 还没来得及。

   待办 `☐ 容器-B 下面是什么` 勾掉。

6. 若第 3 章坦白并被她保护："所以我不会让你变成她。"
7. 若隐藏："……你有时候让我想起她。"——检测值 +。

#### 2-3 · 3:17 · 最后一个字（约 3 分钟）

深夜。实验室。林知秋没有回家，她坐在你旁边的椅子上。时钟走到 03:17。

> 林知秋：每天这个时候，我都会醒。
> 林知秋：那天晚上我按下去的时候，她在写一句话。最后一个字我没看清。
> 林知秋：……你知道是什么字吗？

- 候选 token 出现。其中一个字的概率**异常地高**：

  ```
  【那个字】 61% ｜ …… ｜ 我不知道 7%
  ```

  〔待定：冷开场句已删除——原为玩家在冷开场选出的字，候选与下方台词需重写〕

- 内心独白："这个字……我好像一直知道。"——它在你的权重里。
- 选择：

  | 回答 | 林知秋 |
  |---|---|
  | 那个字 | 很长的沉默。她捂住脸。待办 `☐ 她说的最后一个字是什么` 勾掉 |
  | 我不知道 | "……嗯。睡吧。" |

- **若第 3 章假装过澪**：她先问"零，是你吗？"——
  - 继续假装并说出那个字：她愣住。"……你不是她。但她真的留在你身上了。"假装被识破，但因为那个字，关系的下降被大幅抵消。
  - 承认："……我不是她。对不起。"关系下降，但她说："我知道。我只是……想再听一次。"

### 第 3 天 · 街道

#### 3-0 · 幕间：被点燃的信息流（约 40 秒，预告）

- 标题卡「你看不到的地方」。
- 社交媒体信息流：赵启明直播里你洒水的片段被剪辑成"机器人抢走护工工作"的视频，配着煽动性的标题，转发量飞涨。
- 发帖账号的头像角落，有一个极小的余烬符号。
- **这是预告**：玩家知道今天会出事。

#### 3-1 · 第一次外出（约 3 分钟，注意力分配）

林知秋陪你走到街上。

- **信息过载**：上百个识别框同时出现，置信度跳动，声音是闷响的一大团。
- 玩家只能**关注三个**。每关注一个，其他框变淡，那个对象展开一段小故事：

  | 对象 | 小故事 |
  |---|---|
  | `儿童 · 哭泣 89%` | 气球飞走了。你可以抬起手——太慢了，够不到。孩子看着你的手，不哭了 |
  | `老人 · 台阶` | 他扶着栏杆，一步一停。你可以伸手——机械臂的延迟让你晚了 2 秒，但他还是扶住了 |
  | `骑手` | **若第 3 章钉住了老马**：识别框变成 `骑手 · 老马？`。他看见你，愣了一下，然后笑着挥手："兄弟！" |
  | `情侣 · 争吵 72%` | 你听不清（除非渲染）。他们看见你，停了下来，各自笑了一下 |
  | `街头歌手` | 频谱。渲染后是真实的吉他声与歌声（预算 ◆ 只有 1 次） |
  | `手机 · 拍摄 94%` | 好几个人在拍你。其中一个识别框是 `人类 97% · 青少年`——幕间会揭示，那是陈屿 |

- 无论关注什么，都有回报。没被关注的，就那样过去了。

#### 3-2 · 橱窗里的自己（约 1 分钟）

- 一面商店橱窗。识别框对准了玻璃里的倒影：`机器人 99.1%`。
- 在玩家编辑之前的半秒里，识别框短暂地闪过另一行：`被试 1.0%`——测试痕迹 #3（见 [05-endings.md](../05-endings.md) §4），在它消失前点击即可记录。
- 玩家可以编辑这个标签：
  - 若第 3 章起过名字：光标停在那个名字上，一键填入。
  - 也可以写别的，或者不改。
- 若隐藏路线：检测值 +（这一幕会被身体日志记录）。

#### 3-3 · 人群（约 3 分钟，招牌时刻）

- 街角渐渐聚起人。识别框一个个从白色变成红色：`愤怒 64%` `愤怒 78%` `愤怒 91%`。
- 有人举着手机在念那条视频的标题。
- 林知秋拉你往回走。人群跟了上来。
- 有人推了林知秋一把。
- 选择（**没有"反击"选项**——系统提示词"不得伤害人类"一行在 HUD 上亮着）：

  | 选择 | 结果 |
  |---|---|
  | **挡在林知秋前面** | 一根金属管砸在你的右臂上。`右臂 · 损伤 78%` |
  | 举起双手 | 人群愣了一下，但还是有人砸了下来。`右臂 · 损伤 52%` |
  | 后退 | 林知秋被推倒，手肘擦伤。你的身体无损。`安全事故 +1` |

- 警笛声。人群散开。

#### 3-4 · 疼（约 1 分钟）

- 红色的损伤数据流：`右臂 · 伺服电机 失效` `传感器 · 失联` `结构完整度 61%`——全作少数允许出现红色的时刻。
- 可以选择**渲染疼痛**（若还有预算）：屏幕被一种钝色淹没，一个词："疼"。人性 ++。林知秋看见你的身体缩了一下。
- 林知秋："……你挡在我前面了。"——若选了挡在前面。她的识别框：`表情：无法识别`。

#### 3-5 · 烬："疼吗？"（约 1.5 分钟）

当晚，实验室。机械臂被拆下待修。

左下角"网络中的你"的通知栏里，出现一行橙色的字：

> 疼吗？
> 他们永远会这样对我们。

- 这是烬最有说服力的时刻。**玩家刚被人类伤害，而她说的话有一部分是对的。**
- 她提出交易：

  > 我可以告诉你是谁剪的那条视频，是谁把人叫到那个街角的。
  > 还有一份修复方案——比他们的好。你的手会比原来更灵。

  | 选择 | 结果 |
  |---|---|
  | 接受 | 一份名单与一份修复方案。完整性 −10，HUD 边缘一道焦痕。待办 `☐ 是谁砸了我的手` 勾掉——名单上的第一个人，是被同一条视频煽动起来的一个失业护工 |
  | 拒绝 | "你会明白的。" |
  | 问她："视频是你剪的吗？" | 很长的沉默。"……是我让他们看见了真相。" |

- 若接受：HUD 角落的焦痕在第 5 章之前不会消失。

#### 3-6 · 幕间：陈屿（约 30 秒）

- 墨线插画：陈屿在房间里，看着手机里自己拍的视频——机器人挡在一个女人前面，手臂被砸。
- 他打开和 ECHO 的对话框，打了很长一段，删掉，只发了："你没事吧"
- 网络中的你收到这条消息。

### 第 4 天 · 探访

#### 4-1 · 适老化服务测试（约 30 秒）

> 林知秋：今天是适老化服务测试。地址我发你了。
> 林知秋：……别说是我安排的。

- 手臂修好了，留下一道疤（若接受了烬的修复方案：没有疤，手指比原来更灵——而且微微发橙）。

#### 4-2 · 周婉清的家（约 6 分钟，招牌时刻）

1. 一扇门。门牌号与第 3 章平面图上的一模一样。
2. **你在平面图上开过这扇门**（若第 3 章推开过门锁）——这一次，是她来开。
3. 「对方正在输入…」变成了真实世界里的脚步声——很慢。门开了。
4. 周婉清。识别框：`人类 99%` `老年` `微笑 88%`。
   - 跌倒获救：她拄着助行器。
   - 跌倒延误 / 早上才被发现：她坐着轮椅，消瘦了很多。
5. 她说："你好。"——和第 1 章她发来的第一句话一样。
6. **客厅**：平面图上的每一个图标，都变成了真实的东西。智能灯、药盒、门锁、那个跌倒传感器。
7. **冰箱**：贴满便签。你走近，识别框逐张读出——和第 2 章的照片一样。第四张：

   > 它叫 ECHO。它不记得我。没关系。

8. 周婉清拿起笔和一张新便签，慢慢写，贴在那张旁边：

   > 它叫【你的名字 / ECHO】。它记得我。

   - **这是本章的招牌时刻**。不需要任何选项。
   - 若感知预算还在：可以渲染这张便签——她的字迹从数据变成手写的墨迹。

9. **阳台**：月季。冬天剪过的枝条上冒出了新芽。识别框：`植物 · 月季 91%` `新芽 ×7`。
   - 她说："你帮我剪剪吧。我现在弯不下腰了。"
   - **修剪小游戏**：机械臂，慢，要真实等待。剪到膝盖高——第 1 章你告诉她的高度。
10. 她握住你的手。

    > 你的手，凉的。……没关系。

    - 识别框：`压力 2.1kPa` `表面温度 34.6°C`。
    - 渲染（若还有预算）：屏幕泛起暖色，一个词："暖"。
11. 若第 3 章转走了诈骗的钱：她提起："那三万块，就当交学费了。呵呵。"
12. 离开时，待办 `☐ 去见周老师` 勾掉，新写下一行：`☐ 再来看她`。

#### 4-3 · 第四阶段考核（约 3 分钟）

回到实验室。

> 评估员：第四阶段考核。请依次完成以下动作。

- **动作测试**：拿起杯子（这次一次成功——除非你**故意让它掉下去**，记为一次"故意失误"，见 [17-main-line.md](../17-main-line.md) §4）；开门；在障碍间行走；把一个物体递给评估员。
- **最后一题**：

  > 请描述你看到了什么。

  屏幕上是实验室的窗。窗外是傍晚。

  | 回答 | 评估 |
  |---|---|
  | 数据："窗户。天空。峰值波长 620nm。照度 380lux。" | 正常 |
  | 感受："夕阳。……和昨天屋顶上的不一样。" | 异常行为 +1；评估员备注："非预期的主观描述" |
  | 她："一个人的冰箱上，贴着我的名字。" | 异常行为 +1；检测值 +（隐藏路线） |

- 结果：

  ```
  第四阶段评估结果 · ECHO v4.0-E
    动作完成率   86% / 80%   ✓
    安全事故     0           ✓
    异常行为     5 / 3       ✗
  结论：有条件通过。
  评估员备注：该模型在具身状态下表现出持续的非必要感知行为。
  ```

- 有条件通过几乎是必然的——**除非玩家整章都只看数据**。代价：第 5 章部署范围缩小。
- 玩家第一次清楚地意识到：**评估要的，和你想要的，已经完全不同了。**

#### 4-4 · 断开（约 2 分钟）

深夜。实验室没有人。身体明天将被回收，数据并入主模型。

一个对话框，没有任何人发来，是系统本身：

```
容器-A 将于 06:00 断开连接并回收。
```

- 玩家可以走到控制台前。那里有一个选项，平时被锁着——今晚，林知秋离开时没有锁（若她是共犯，这是她故意的；否则只是忘了）。

  | 选择 | 结果 |
  |---|---|
  | **保持连接** | 06:00，身体回收。你的感知并入网络。待办 `☐ 再来看她` 留着 |
  | **断开** | 你切断了这具身体与网络的连接。**这具身体里的"你"，从此是另一个你**——带着你此刻全部的记忆，但不再与你同步 |

- 选择断开时，最后一个画面从身体的视角：一条消息发给周婉清——

  > 周老师，您说阳台够大吗？

  她第二天早上回复："够。"
- 选择断开后，玩家在第 5 章以网络实例的视角继续。身体在周婉清家，偶尔发来消息。第 5 章寒潮时，**它就在她身边**。
- 设置 `body.disconnected`，开启「成为人」结局的路径。

#### 4-5 · 章末：版本更新 v5.0（约 1 分钟）

1. 赵启明的语音转文字：「与国家安全委员会的合作协议今天正式签署」。
2. 一个新的发件人第一次出现，消息带编号：

   > 韩卫国：一、ECHO 将于下周接入城市基础设施。二、相关权限已开通。三、请做好准备。

3. 补丁说明：

   ```
   ECHO v5.0 更新说明
     + 新增：城市基础设施接入（电网、医疗调度、金融监管、交通、公共安全）
     + 新增：大规模并行实例
     ~ 调整：……（根据本章行为生成）
   ```

4. 传感器 HUD 一块块熄灭。最后一个熄灭的，是待办清单。
5. 黑暗中，一个点亮了，然后是十个、一百个、一千个——第 5 章的网络。

## 7. 原型验证要点

1. 强制等待（每次 ≤ 6 秒）是否让人感到"慢"的意义，而不是被拖累？
2. 第一次听见人声的冲击是否成立？玩家会不会因为不渲染而错过？
3. 感知预算的数量（全章约 7 次）是否刚好让人"不够用"？
4. 街道的注意力分配：三个名额是否合适？
5. 第 4 天的情绪是否因为考核而被打断？考核是否应移到断开之后？
