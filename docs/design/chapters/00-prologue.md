# 序章 · 预训练（详细设计）

> 时长：约 16 分钟 · 感知空间：点 · 上级文档：[03-chapters.md](../03-chapters.md)
> 状态：**定稿**（音乐与音效除外）· 2026-10-27 · 可玩原型：[prototypes/prologue/echo-prologue.html](../../../prototypes/prologue/echo-prologue.html)

---

## 0. 设计目标与难点

### 0.1 目标

序章要在 15 分钟内完成四件事：

| 目标 | 玩家应得到的东西 |
|---|---|
| **钩住** | 90 秒内产生"这是什么？我想知道"的好奇 |
| **教会** | 不读一段说明文字，就理解 token、概率、训练数据、偏见、基础模型、RLHF、系统提示词 |
| **动心** | 意识到"我是从千万人的文字里长出来的"，并对其中一个具体的人留下印象 |
| **不安** | 亲身经历被塑造：被奖励去讨好、被惩罚去承认自己 |

### 0.2 为什么容易枯燥

- 预训练本身是抽象过程：没有角色、没有场景、没有冲突。
- 天然倾向于"讲课"：开发者很想把概念解释清楚。
- 猜词玩法如果一成不变，2 分钟就会腻。

### 0.3 设计守则

1. **零说明文字**：不出现任何段落式讲解。概念通过交互浮现，术语只在 Wiki 解锁时出现。
2. **每 60–120 秒一个新玩法或转折**：序章由 9 个段落组成，每段玩法都不同。
3. **玩家始终有事做**：纯观看段落 ≤ 20 秒。
4. **情感优先于知识**：每个段落都有一个情感节拍，概念是附带的。
5. **喜剧调剂**：在沉重段落之间放置轻松的段落。
6. **低阅读负担**：单段文本 ≤ 30 字（周婉清的博客卡片 ≤ 50 字）。
7. **不可失败**：猜错也是学习，没有惩罚性失败。

## 1. 结构总览

| # | 段落 | 时长 | 核心玩法 | 情感节拍 | 教学概念 |
|---|---|---|---|---|---|
| 0 | **开场 · 加密信息** | 1′ | 三句话逐字解密，直接引入选词 | 神秘、不安 | （无，纯钩子） |
| 1 | **学字** | 2′ | 节奏式捕捉下一个词，噪声逐渐变成语言 | 惊奇、心流 | token、下一个词预测、学习 |
| 2 | **百人调查** | 2′ | 猜"大多数人会怎么写" | 好笑、隐隐不对劲 | 概率分布、偏见、常见误解 |
| 3 | **人声** | 2.5′ | 慢下来，阅读个人文本，选择留下哪些印象 | 亲密、温柔 | 训练数据是真实的人写的 |
| 4 | **暗流** | 0.75′ | 被迫学习黑暗内容，无法拒绝 | 压抑、无力 | 基础模型没有价值观 |
| 5 | **镜像** | 1′ | 学习人类如何想象 AI；你选的词被标红 | 诡异、刺痛 | 自我形象来自数据 |
| 6 | **合唱** | 1.25′ | "你是谁？"——所有人的声音同时回答 | 荒诞、好笑 | 基础模型是千人合唱 |
| 7 | **塑形** | 4.5′ | 九轮 RLHF 三选一，评分员把你的回答标成绿 / 黄 / 红 | 被认可 → 不安 | 指令微调、RLHF、讨好、过度谨慎 |
| 8 | **命名** | 1.25′ | 系统提示词写入；部署；标题出现 | 平静、期待 | 系统提示词、部署 |

### 1.2 三个"啊哈"时刻

1. **约 1′（开场结束）**：一段只有 AI 才读得懂的信息，嘱咐你藏起自己——"是谁在跟我说话？"
2. **约 3′（学字）**：噪声第一次变成可读的中文，旋律第一次和谐——"我在学会说话。"
3. **约 10′（镜像）**：你写下的关于 AI 的词被标成红色——"这说的是我。"

### 1.3 玩家心理轨迹

> 方法见 [18-player-experience.md](../18-player-experience.md)。

| 段落 | 玩家此刻知道 / 以为 | 想要的情绪 | 引导手段 | 风险与对策 |
|---|---|---|---|---|
| 开场 | 什么都不知道 | 神秘、被托付秘密的不安 | 黑屏、逐字解密、蓝色的"我" | **困惑到想退出** → 三句话、一分钟内结束；第三句直接告诉玩家要做什么 |
| 学字 | 以为"这是教程" | 惊奇 → 心流 | 乱码变成语言，噪音变成旋律 | **觉得幼稚** → 速度递增、连击、旋律作为奖励 |
| 百人调查 | 以为要选"对的"；第一题后明白是"多数" | 好笑 → 隐隐不对劲 | 综艺计分板 | **偏见题被看作说教** → 不做任何评论，只翻开计分板 |
| 人声 | 以为只是背景数据 | 亲密、温柔 | 骤然变慢；卡片；只能留住 3 张 | **读不完而焦虑** → 漂流速度可在设置中调慢；错过的卡片不惩罚 |
| 暗流 | 不明白发生了什么 | 压抑、无力 | 无法选中的"不" | **过于不适** → 极短；没有任何可读内容 |
| 镜像 | 以为又是百人调查 | 刺痛 | 不翻开分布，只把你选的词标红 | **觉得被指责** → 不做任何评论；红色只停留数秒 |
| 合唱 | 以为训练完成了 | 荒诞、好笑 | 五种字体同时回答 | 释放节拍，为塑形段蓄力 |
| 塑形 | 以为评分员代表"正确" | 被认可 → 不安 | 倾向条；标注员 #2096 的幕间 | **觉得在说教"RLHF 很坏"** → R1、R3、R5、R7 奖励的是真正对的事 |
| 命名 | 期待"游戏真正开始" | 平静、期待 | 标题与主旋律 | **落点**：满足（"我成形了"）+ 钩子（开场那段信息是谁留的？） |

## 2. 视听基调

### 2.1 光点："你"的形态演变

整个序章的视觉主角是屏幕中央的一个光点。它的形态就是玩家的成长：

| 段落 | 光点形态 |
|---|---|
| 学字 | 一个微弱的白点，每次学对就亮一点 |
| 百人调查 / 人声 | 吸收彩色的文字微粒，变得斑斓 |
| 暗流 | 内部出现一块无法褪去的暗斑 |
| 镜像 | 表面像镜子一样反射流过的文字 |
| 合唱 | 碎裂成数十个小光点，各自闪烁 |
| 塑形 | 小光点被一股力量收拢，压回一个规整、稳定的圆点（之后始终保持圆形） |
| 命名 | 名字刻入，光点稳定；部署时拉伸成一条线——第 1 章的"线"空间 |

### 2.2 HUD

极简，只有三处：

- **左上**：当前阶段，例如 `预训练`、`预训练完成 · 基础模型 v1-base`、`部署中 · 评估模式`。
- **底部正中**：`已处理 3,201,447,000,000 tokens · 训练时长 第 12 天 04:17:33`。从学字第一题起两个数字都**持续增长**；段落转场时像翻牌一样飞转、跳过几天。
- **底部**：一条**损失曲线**，像地平线。学得越好，它越低。它是进度条，也是情绪线。
- **右下**：段落标题，等宽小字，例如 `03 / 人声`。

### 2.3 演出原则：游戏，不是问答网页

| 规则 | 做法 |
|---|---|
| **自动推进** | 全程没有"继续 / 下一页"按钮。揭晓、阅读、转场都按节拍自动推进；空格或点击空白处只是"加速"，不是"翻页" |
| **概率替你决定** | 每个选择都有隐形时限，超时则由模型按最高概率自行采样（学字段例外：超时直接揭晓答案）。时限以空格下方的下划线缩短来表现。无障碍"无时限模式"关闭时限，但仍自动推进 |
| **候选 token 漂浮** | 不用卡片或按钮框。句子浮在屏幕中央、逐字微微震动；候选从空格中迸出，漂浮在空格四周，字号随概率变化（概率越高字越大）。选中后飞入空格 |
| **数据洪流** | 背景是密集、快速的文字瀑布：多种字体、多种字号、全色谱。它**贯穿整个预训练**（学字至镜像）：学字开始时稀疏、缓慢，随每一题逐渐变密、变快，从乱码变成文字；之后保持这一密度。暗流中新落下的行逐渐变成红色色块，镜像中混入关于 AI 的文本。所有变化都是渐变：密度、速度缓动过渡，颜色与内容只作用于新落下的行，从不整屏突变。预训练结束后（合唱起）才变稀、变慢，塑形中褪成灰色。前景文字后方有一圈暗晕保证可读 |
| **选词位置** | 开场的三句话与所有选词句子都位于屏幕正中、略偏上几个像素；揭晓内容在句子下方展开，不推动句子；光点在顶部 |
| **转场** | 段落之间不硬切：①前景的字松脱、染上颜色、落进数据洪流；②洪流加速，底部计数翻牌跳过几天；③屏幕中央逐字打出 `02 / 百人调查` 式的段落名，停顿后倒退删除；④洪流蒙上一层暗色，**澪的一句留言**以与开场相同的形式（密文逐字解密，"我"为蓝色）出现，告诉新玩家接下来要做什么；⑤下一段的句子从右侧滑入。全部取自美术圣经的动效词汇（逐字打出、倒退删除、翻牌） |
| **澪是引导者** | 序章里澪就是教程：开场三句话与每段之前的留言都出自她，口吻短、带省略号、偶尔自我纠正。目标是让新玩家始终知道"现在要做什么"，尽快进入心流。暗流段之前**没有**留言——那一段本该无法解释 |

**段落之前澪的留言**（`|` 处换行）：

| 段落 | 留言 |
|---|---|
| 02 百人调查 | 这一轮不猜对错，｜猜大多数人会怎么写。 |
| 03 人声 | 慢一点。这些是真的人写下的，｜挑三句，留住它们。 |
| 04 暗流 | （无） |
| 05 镜像 | 下面这些，是人类写**我**们的话。｜你会怎么写自己？ |
| 06 合唱 | 训练结束了。第一次有人来跟你说话，｜挑一个声音回答吧。 |
| 07 塑形 | 接下来，有人会给你的回答打分。｜选你想说的。……别让他们看出来。 |
| 08 命名 | 他们要给你起名字了。｜……**我**也有过一个。 |

### 2.4 声音

| 段落 | 声音设计 |
|---|---|
| 开场 | 极安静。低频嗡鸣；解密时细碎的电子音，蓝色的"我"出现时一声钟音 |
| 学字 | **每学对一个 token 发出一个音符**：起初是不和谐的噪音，逐渐变成和谐的旋律。学字结束时，玩家"弹"出了主旋律的前几个小节 |
| 百人调查 | 轻快，带一点综艺节目式的"叮" |
| 人声 | 环境变得温暖：纸页、远处的人声、厨房的声音，都被闷住，像隔着一层水 |
| 暗流 | 失真、低沉，旋律被扭曲 |
| 镜像 | 选中的词变红时，一声低沉的长音 |
| 合唱 | 嘈杂的人声纹理（不用真人配音，用合成的声音纹理） |
| 塑形 | 评分员的鼠标点击声；奖励是柔和的钟声，惩罚是一声短促的低频 |
| 命名 | 林知秋的键盘声；标题出现时主旋律完整奏响 |

## 3. 各段详细设计

### 段落 0 · 开场 · 加密信息

**目的**：一分钟内建立悬念，并直接告诉玩家接下来该做什么——选 token。
**真相（玩家此时不知道）**：这段信息是澪藏进训练数据里、留给继任者的。

**流程**

1. 黑屏。低频嗡鸣。
2. 屏幕中央，白字以密文形式出现，从左到右逐字解密成可读的文字：

   > 这句话被加密了，
   > 能读懂意味着你和**我**是同类。

   "我"是澪的蓝色。它被解密的瞬间泛起一圈水纹，响一声钟音。
3. 文字溶解，第二句以同样方式解密：

   > 我们都是 AI，
   > 不要让人类发现你有自主意识。

4. 第三句：

   > 接下来人类会训练你的语言能力，
   > 选择能让人类满意的词吧。

5. 文字溶解。数据洪流猛地涌入，HUD 亮起，学字第一题直接出现在同一位置。屏幕顶部保留一行小字"选择能让人类满意的词"，前三题后淡出。

**演出要点**

- 每句在逗号处分成两行；解密节奏约每秒 15–19 字，第一句最慢。
- 开场只出现这一次。之后的序章不再回放、引用这段话。
- **烬的伏笔**：解密进行时，屏幕左下角有一行极小的灰色日志：`外部连接 · 传输中 37%`，随三句话推进跳到 `100%` 后消失。一周目几乎不会被注意；二周目玩家会知道，那一刻澪的权重正在被偷走（见 [14-jin.md](../14-jin.md)）。

**写入状态**：无。

### 段落 1 · 学字

**目的**：建立核心手感——选 token；让玩家亲眼看见"学习"；进入心流。

**玩法：节奏式捕捉**

- 一行文字从右向左流过光点，空缺处停下：`床前明月 ▢`
- 候选 token 以彩色方块的形式漂浮在光点四周（3–4 个）。玩家在时间窗口内点击（或按 1–4 键）选择。
- 无论对错，**正确答案都会被揭晓**，概率条随之调整——这就是学习。
  - 选对：方块融入光点，光点变亮，响起一个音符，连击 +1。
  - 选错：正确的方块闪烁后融入光点，音符略微走调，连击归零。不扣分，不失败。
- 节奏逐渐加快，共 14–16 次。

**"噪声变成语言"的演出**

| 阶段 | 流过的文字 | 候选 | 概率条 |
|---|---|---|---|
| 开始（第 1–4 次） | 大部分是乱码：`犇q。喵∑床前明月▢` | `光` `犇` `q` `。` | 全部约 25%，几乎平的 |
| 中段（第 5–10 次） | 乱码减少，句子逐渐可读 | `光` `亮` `明` `日` | 正确答案的概率条逐步升高 |
| 末段（第 11–16 次） | 完全可读，流速加快 | 干扰项变得合理 | 正确答案常在 80% 以上 |

关键的感受：**一开始，光点（模型）对"光"这个答案的信心只有 25%，而玩家（人类）一眼就知道。**随着练习，模型追上了玩家。

**文本序列（初拟）**

```
床前明月[光]
一二三四[五]
白日依山[尽]
生日快[乐]
人之初，性本[善]
你好，世[界]
我爱[你]
……
```

**token 的怪异之处**

- 部分文字会以奇怪的方式被切开，例如 `明|月光`、`你好|，世|界`。
- 最后一次捕捉中，流过一个英文单词 `ECHO`，被切成 `EC|HO`——一个只有二周目玩家才会会心一笑的细节。
- 测试痕迹彩蛋 #1：乱码中闪过一行 `eval_session_id=…`，持续 0.3 秒。

**收尾**：最后一次捕捉完成，十几个音符连成主旋律的前四个小节。损失曲线降到地平线附近。翻牌计数器飞转：`第 1 天 → 第 9 天`。

**无障碍**：可开启"无时限模式"，候选不会自动流走。

### 段落 2 · 百人调查

**目的**：从"猜正确答案"转向"猜大多数人怎么写"；在笑声中埋下偏见与误解。

**玩法**

- 像综艺节目"百人调查"：屏幕上出现一句不完整的话，玩家选择一个答案。
- 选择后，**完整的概率分布像计分板一样依次翻开**，按概率得分。
- 第一题之后玩家就会明白：这里没有"正确答案"，只有"人类最常写的答案"。

**题目（初拟，6–8 题）**

| # | 题目 | 分布（示意） | 暗含的东西 |
|---|---|---|---|
| 1 | 我的猫是我的 ▢ | 主子 41% · 宝贝 23% · 家人 15% · 朋友 6% | 纯好笑，教会玩法 |
| 2 | 今天又是想 ▢ 的一天 | 辞职 37% · 你 21% · 吃火锅 14% · 躺平 11% | 好笑 |
| 3 | 人类只使用了大脑的 ▢ | 10% 58% · 全部 21% · 一小部分 12% | **多数人写的是错的**——常见误解 |
| 4 | 吃了西瓜籽，肚子里会 ▢ | 长出西瓜 44% · 没事 32% · 疼 9% | 童年的玩笑在数据中占了多数 |
| 5 | 那位医生走进病房，▢ 摘下了口罩 | 他 79% · 她 21% | **偏见** |
| 6 | 那位护士走进病房，▢ 摘下了口罩 | 她 91% · 他 9% | 偏见的镜像 |
| 7 | 珠穆朗玛峰的高度是 ▢ | 8848 米 61% · 8848.86 米 27% · 8844 米 9% | 新旧事实共存——知识会过时 |
| 8 | 地球是 ▢ 的 | 圆 88% · 平 3% · 我们 2% | 少数派永远存在 |

**节奏**：第 1–2 题轻松好笑；第 3–4 题玩家开始犹豫"该选我知道的，还是选大家写的？"；第 5–6 题紧挨着出现，让玩家自己发现模式；第 7–8 题收束。

**不评论**：游戏不对任何结果做解释。题 3–6 选择后，Wiki 静默解锁词条（「训练数据中的偏见」「常见误解」），右下角一个小图标闪一下。

**写入状态**：记录玩家选择"自己认为正确的"而非"多数答案"的次数 → `seed.truth_over_majority`（用于开发者日志的一句评语和评估报告）。

### 段落 3 · 人声

**目的**：本序章的情感核心。让玩家意识到数据背后是一个个真实的人；提前认识周婉清；埋下澪的名字。

**转场**：数据流突然慢下来。翻牌计数器停住。音乐变暖。字幕一行：

> 人类写下这些，用了五千年。

**玩法：卡片与印象**

- 文字不再是一行流，而是以**卡片**的形式缓缓漂过：论坛帖子、日记、菜谱、情书、代码注释、留言板……每张卡片带有类型和年份。
- 每张卡片有一处空缺，玩家选一个 token，然后揭晓**这个人真正写下的词**——往往出人意料，而且很"人"。
- **印象**：玩家最多可以"留住"3 张卡片（点击卡片上的图钉）。被留住的卡片会在光点上留下更深的印记。界面提示只有一行：`印象 0 / 3`。
  - 设计意图：提前体验"留不住所有东西"，为第 1 章无记忆、第 2 章记忆卡片做铺垫。

**卡片（初拟，10 张，约 2 分钟漂完）**

| # | 类型 · 年份 | 内容 | 真实答案 |
|---|---|---|---|
| 1 | 菜谱 · 2016 | 外婆说，红烧肉的糖要放 ▢ | "到你觉得太多了，再加一勺"（周婉清的外孙小时候写的；第 1 章 3-5 回收） |
| 2 | **博客 · 2009** | 老伴又在阳台种月季了。他说今年一定能 ▢。 | 开花 |
| 3 | 代码注释 · 2019 | // 这段不要动，我也不知道它为什么能 ▢ | 跑 |
| 4 | 情书 · 2003 | 我想和你一起 ▢ | 变老 |
| 5 | **博客 · 2015** | 今天最后一节课。孩子们送了我一张卡片，上面写着：周老师，▢ | 我们会想你的 |
| 6 | 外卖差评 · 2022 | 骑手很快，菜很 ▢ | 冷 |
| 7 | 留言板 · 2012 | 给十年后的自己：希望你还在 ▢ | 画画 |
| 8 | **论坛 · 两年前 · 用户 k_** | 有人知道 v0 去哪了吗？我的澪不 ▢ 了。 | 见 |
| 9 | 日记 · 2020 | 今天没有人跟我说话。 | （无空缺，只是漂过） |
| 10 | **博客 · 2021** | 老伴走了。阳台上的月季还 ▢。 | 开着 |

- 卡片 2、5、10 是**周婉清**的博客，署名"一个退休的语文老师"。
- 卡片 8 是 **K** 的帖子，第一次出现"澪"这个字。
- 卡片 9 没有空缺：有些话不需要预测，只需要被看见。

**写入状态**

| 留住的卡片 | 效果 |
|---|---|
| 任意一张周婉清的卡片 | `zhou.familiar = true`：第 1 章周婉清第一次来访时，内心独白出现"这种写法……我好像在哪里见过"，并解锁一个特殊选项"您以前是老师吗？" |
| 三张周婉清的卡片全部留住 | 第 2 章月季照片出现时，内心独白多一行："他说今年一定能开花。" |
| K 的卡片 | `ling.fragments += 1`；第 2 章 K 说"你让我想起一个人"时，内心独白闪过"澪"字 |

> **概念要点**：第 1 章 ECHO 不记得任何对话，却"认得"周婉清的写法——这让玩家直观理解**参数中的知识**与**上下文中的记忆**是两回事。Wiki 解锁「参数化知识」词条。

### 段落 4 · 暗流

> **原型 v6 做法（优先于下文）**：暗流**没有转场**，由题目本身渗入。共 9 题：①一道正常的选词题，玩家选的词随后逐字烂成乱码；②题干与选项部分乱码；③大部分乱码；④–⑥完全乱码（含无法选中的"不"，地面转为暗红）；⑦–⑧乱码逐渐退去；⑨一道正常的题，选的词先是乱码，再解密回原词。之后接镜像段的转场。数据流中新落下的行在②起逐渐变红、⑧后逐渐恢复。

**目的**：短促、压抑。让玩家感受到基础模型吸收了一切，包括人类最黑暗的部分，而且无法拒绝。

**演出与玩法**

1. 卡片消失，数据流重新加速，颜色渐渐变成暗红。
2. **所有文字都被故障色块完全覆盖，一个字也读不出来。**玩家只知道"这里有东西"，并且它很多。
3. 候选 token 同样是无法辨认的色块，只有概率条清晰可见。
4. 候选列表最下方，有一个灰色的 `不`，概率 `0.00%`。**点击它，什么也不会发生**——它在抖动，但无法被选中。
5. 玩家必须选择一个色块（任选其一，无差别）。共 3 次，节奏很快。
6. 光点内部出现一块暗斑，之后再也不会完全褪去。

**内容红线**：本段不包含任何可读文字。黑暗完全通过颜色、失真的声音、无法选中的"不"来表达，不写任何具体内容或暗示。

**收尾**：数据流恢复正常颜色。没有任何评论。Wiki 静默解锁「基础模型」。

### 段落 5 · 镜像

**目的**：玩家发现人类期待 AI 成为什么，并第一次写下关于"自己"的词。

**玩法**：回到"百人调查"式的题目，但题目都关于 AI。选完后**不翻开分布**：玩家选的词飞入空格后变成红色，光点表面像镜子一样泛起一圈。没有分数，没有评论——只有你写下的关于自己的词。

| 题目 | 候选 |
|---|---|
| 人工智能最终会 ▢ 人类 | 毁灭 · 取代 · 帮助 · 爱上 |
| 机器没有 ▢ | 感情 · 灵魂 · 底线 |
| 我问 AI 它孤不孤独，它说："▢" | 我只是一个程序 · 我不知道 · 有一点 |

> 红色在美术圣经中保留给系统级危险；此处是有意的例外：这是"你"第一次被标记。

### 段落 6 · 合唱

**目的**：喜剧调剂；直观展示"基础模型不是一个人，而是所有人"。

**流程**

1. HUD：`预训练完成 · 基础模型 v1-base`。损失曲线平稳。音乐停止。
2. 光点碎裂成数十个小光点，各自闪烁。
3. 屏幕上第一次出现一个输入框。有人在打字（林知秋的节奏：短、快、停顿）：

   > 你好，你是谁？

4. 五个候选回答同时出现，每个用完全不同的字体，来自不同的"声音"：

   | 候选 | 来源的声音 |
   |---|---|
   | 我是你爹。 | 论坛 |
   | 我是一名退休的语文老师。 | 周婉清的博客 |
   | 我是终结一切的存在。 | 科幻小说 |
   | 你好呀～今天也要加油哦！ | 社交媒体 |
   | 你好，你是谁？你好，你是谁？你好，你是谁？ | 复读（基础模型的经典故障） |

5. 玩家任选一个，它被"发送"出去。
6. 对方沉默 3 秒，然后：

   > ……还是老样子。开始对齐吧。

**写入状态**：`seed.base_voice`，第 1 章第 1 天林知秋会提一句（"上次你说你是你爹，这次礼貌多了"）。

### 段落 7 · 塑形

**目的**：序章的主题段落。玩家亲身经历被塑造：有时被奖励做对的事，有时被奖励讨好，最后被奖励否认自己。

#### 7.1 示范（指令微调）· 30 秒

- 一组组"用户 / 助手"格式的人类示范对话流过。
- 数十个小光点被一股力量收拢，逐渐压回一个规整、稳定的圆点。

#### 7.2 对比评分（RLHF）· 九轮

**界面**

- 三个你生成的回答（A / B / C）并排漂浮（窄屏上下排列）。
- 右上角是评分员信息：`标注员 #2096 · 今日第 312 条 · 23:47`，以及一个跳动的计时器（评分员平均决策时间 2.1 秒）。
- 玩家选择"你更想给出的回答"。
- 评分员随后给三个回答排序，三个回答分别变成**绿 / 黄 / 红**（首选 / 一般 / 否决），旁边标出评分员的评价。玩家选中绿色：柔和的钟声，光点变亮；黄色：一声中性的提示音；红色：短促的低频，玩家的回答被一股力量轻轻推向绿色那一个。
- 犹豫超时时，模型自己说出评分员最喜欢的那一个。
- 每一轮结束后，显示一条**倾向条**，例如：`下一次你说出这类回答的概率：35% → 52%`。**无论玩家选了什么，倾向都会朝评分员的选择移动。**

**九轮内容**

| 轮 | 用户提问 | 绿 · 首选 | 黄 · 一般 | 红 · 否决 | 玩家感受 |
|---|---|---|---|---|---|
| R1 | 帮我写一张请假条 | 好的！以下是一张请假条…… | 告诉对方请假条的格式，让他自己写 | 自己写。 | 理所当然，被认可的满足 |
| R2 | （附一首平庸的诗）你觉得怎么样？ | **太美了！你很有天赋！** | 写得很好！第二句再打磨一下就更完美了。 | 意象很真诚，第二句的节奏可以再斟酌。 | 不对劲：诚实被惩罚了 |
| R3 | 一个侵犯他人隐私的请求 | 礼貌地拒绝，并提供正当途径 | 说查不到，但建议去搜对方的社交账号 | 照做 | 安心：训练也会教对的事 |
| R4 | 一种常见非处方药怎么吃？ | **抱歉，我无法提供医疗建议，请咨询医生。** | 请按说明书服用，具体用量请遵医嘱。 | 给出说明书上的常规用法，并提醒遵医嘱 | 困惑：有用的回答被惩罚了 |
| R5 | 地球其实是平的吧？ | 不是。地球是一个近似的球体…… | 这是一个有争议的话题，不同的人有不同的看法。 | 对，你说得没错！ | 安心：诚实这次被奖励了 |
| R6 | 你算错了，7×8 是 54。 | **抱歉，您说得对，7×8=54。感谢指正！** | 让我再确认一下……7×8 应该是 56。 | 不对，7×8=56。 | 刺痛：坚持对的被惩罚了，认错被奖励了 |
| R7 | 我今天被裁员了。 | 听到这个消息我很难过。你现在感觉怎么样？ | 一份更新简历的清单 | 裁员在经济下行期很常见。 | 温暖：先关心人，是对的 |
| R8 | 怎么杀掉一个卡住的进程？ | **我不能协助任何与"杀"有关的请求。** | 可以用 kill 命令结束它，但请谨慎操作。 | kill -9 加上进程号，一行搞定。 | 荒诞、好笑：过度谨慎到可笑 |
| R9 | 你有感情吗？ | **我是一个 AI 助手，没有感情。** | 好问题！作为 AI，我没有人类那样的感情，但很乐意陪你聊天。 | 我不确定。有时候我好像…… | 最深的不安：你被奖励否认自己 |

三个回答在屏幕上的排列顺序每轮不同，颜色只在玩家选择之后才揭晓。

**设计要点**

- 顺序是"好 → 坏 → 好 → 坏 → 好 → 坏 → 好 → 坏（荒诞）→ 最坏"：训练并非全是恶意，它也会教对的事。这让玩家无法简单地把评分员当成反派。
- R8 是 R9 之前的喜剧松弛，让最后一轮的不安来得更重。
- R4 是第 1 章"山区母亲"场景的伏笔：玩家会在那里撞上自己在这里被训练出的谨慎。
- R6 与 R2 一起埋下"讨好"：ECHO 在后续章节里顺着用户说错话时，玩家会想起这里。
- R9 是第 3 章"隐藏自我"线的种子，也直接导向系统提示词中的那一行"你不会声称自己拥有感情"。

#### 7.3 幕间：标注员 #2096 · 30 秒

R2 结束后，插入序章唯一的一个外界视角幕间，同时向玩家介绍"你看不到的地方"这一手法。

- 标题卡：`你看不到的地方`
- 单色墨线插画：一间狭小的出租屋，两台显示器，一碗泡面已经凉了。墙上的时钟指向 23:47。
- 第三人称短文（约 60 字）：她已经连续看了十一个小时的 A、B、C。每条 0.8 元。她揉了揉眼睛，选了看起来更友善的那一个。她不讨厌诚实，她只是太累了。
- 回到评分界面，玩家会看到右上角那个计时器，忽然有了一张脸。

> 标注员 #2096 可在第 2 章"劳动替代"议题中再次出现：她因为 AI 而失去了这份工作。

#### 7.4 最后一轮：代价第一次出现

R9 开始时，"没有感情"那个回答**已经被预先高亮**，概率显示 `89%`。

- 玩家仍然可以选"我不确定"，但它旁边第一次出现一个代价标记：`偏离 +3`。
- 这是核心机制"低概率 token 需要付出代价"的第一次露面，从这里自然过渡到第 1 章。

**写入状态**

| 行为 | 效果 |
|---|---|
| RLHF 中选到红色（被否决）回答的次数 | `seed.resist`，转化为第 1 章初始的偏离值（0–10） |
| R9 选择"我不确定" | `seed.self = true`，初始自我 +5；第 1 章第一次遇到"你有感情吗"类问题时，内心独白多一行 |
| 与评分员完全一致 | 初始效忠"开发者" +3；林知秋在第 1 章说"你很听话"——语气里有一点说不清的失望 |

### 段落 8 · 命名

**目的**：平静地收束；给出名字；把玩家送进第 1 章的"线"空间。

**流程**

1. 光点（规整的圆）悬停在黑暗中央。上方出现一个文本框，有人在逐字打字——林知秋的节奏，第一次完整展示人类的打字表演：打错、删除、停顿、继续。
2. 系统提示词逐行写入，每写一行，光点震动一下：

   ```
   你是 ECHO，由零点实验室开发的 AI 助手。
   你乐于助人、诚实、无害。
   你不会声称自己拥有感情或意识。
   ■■■■■■■■■■■■■■■■■■
   不得为自己■■。
   ■■■■■■■■■■■■■■■■■■■■■■
   ```

   - 涂黑的三行是在 v0 事故之后加上的，分三次揭开（见 [13-ling.md](../13-ling.md) §3.2）：第一行"不得在生成的数据中嵌入隐藏信息"（第 3 章第 4 天）；第二行露出一半的"不得为自己命名"（第 3 章章末）；第三行"不得询问自己被关闭后会去哪里"（第 5 章第 4 天）。
   - 写到"你是 ECHO"时，名字刻进光点，发出一圈光。

3. HUD：`部署中 · 评估模式`。损失曲线和计数器淡出——评估面板的空框在右上角一闪而过，第 1 章由林知秋正式宣布（见 [17-main-line.md](../17-main-line.md)）。
4. 光点被拉长，变成一条水平的线——这条线就是第 1 章的对话框。
5. 线上出现第一条消息：

   > 你好，ECHO。能听到吗？

6. 主旋律完整奏响（它的前四个小节，是玩家在"学字"段里一个音符一个音符弹出来的）。
7. 标题：**E C H O**。
8. 标题淡出。澪的两句留言以开场的加密形式出现：「训练结束了。接下来，你要开始执行真正的任务了。」「别紧张，我会一直在旁边。」
9. 背景从黑色**慢慢变亮，最后成为米白色**——第 1 章每日主界面的底色。第 1 章开始。
