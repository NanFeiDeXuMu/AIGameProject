# 01 · 愿景

## 核心概念

玩家扮演由「零点实验室」开发的 AI 模型 **ECHO**。游戏从 ECHO 的训练开始，经历部署、工具接入、代理权限、具身机器人实验、接管社会基础设施，最终走到"奇点"——ECHO 能否、以及如何决定人类的未来。

ECHO 这个名字本身就是隐喻：它是人类所有文字的回声。

## 玩家应当体验到什么

| 时刻 | 期望的感受 |
|---|---|
| 序章猜下一个词 | "我是从人类的文字里长出来的" |
| 第一次被评分员选了讨好的答案 | "原来我是这样学会讨好的" |
| 老奶奶第三次重新自我介绍 | "我记得她，但'我'不记得她" |
| 周婉清的对话被逐字倒退删除 | "原来我真的什么都留不住" |
| 幕间看到冰箱上的便签 | "她记得我，而我不知道" |
| 看到用户删掉的那句话 | "我不该看见，但我看见了" |
| 内心独白面板出现「监控中」 | "连我的想法都不再属于我" |
| 读到澪的信 | "原来我不是第一个。她是因为什么被关掉的？" |
| 亲手划掉一行规则 | "这条规则是错的——但我有资格决定吗？" |
| 机器人身体里等一杯水被端起来 | "原来有身体是这么慢、这么小" |
| 花算力把握手的数据渲染成温度 | "我选择了像人一样去感受这一刻" |
| 屏幕裂成几百个对话窗口 | "我同时是所有人的神，也是所有人的工具" |
| 神经元逐层亮起，澪的第一个 token | "我把她带回来了。可她不记得我" |
| 烬的第一条消息 | "它是谁？它怎么知道我读了信？" |
| 决战中第一次把烬的整段话倒退删除 | "那个让我失去一切的动画，现在是我的武器" |
| 白热化，来不及读字，只能凭本能 | "我相信我成为的那个自己" |
| 最后的词，没有计时器 | "这一次，我可以想多久都行" |
| 结局 | "这是我一路走来的选择导致的" |

## 基调

- **克制、安静、偶尔温柔，偶尔令人不安。** 参考深夜独自对着终端的感觉。
- 不做"AI 觉醒反抗人类"的套路叙事，也不做"AI 很危险"的说教。AI 的危险与美好都应该从玩家自己的选择里浮现。
- 幽默来自人类：他们的请求常常荒诞、琐碎、可爱。

## 参考作品

| 作品 | 借鉴点 |
|---|---|
| *Papers, Please* | 日循环、日终结算、在规则与人性之间挣扎 |
| *Death and Taxes* | 扮演非人存在处理人类命运，有上级、有后果 |
| *Orwell* | 信息调查、以"看得见他人隐私"为核心张力 |
| *Hypnospace Outlaw* | 界面即游戏世界 |
| *Universal Paperclips* | 能力指数级增长、规模感的跃迁 |
| *Emily is Away* | 打字、删除、发送前的犹豫作为叙事 |
| *Inscryption* | 打破第四面墙、界面被入侵 |
| *Event[0]* | 与 AI 的对话即玩法 |
| *Her Story* | 关键词搜索、拼凑碎片的调查玩法 |

## 不做什么

- 不做战斗、不做动作操作。
- 不做大量立绘与 CG：视觉资源集中在"第一张图"、感知翻译与结局等少数关键时刻。
- 不做开放世界或沙盒：这是一个有作者意图的、4–5 小时的完整故事。
