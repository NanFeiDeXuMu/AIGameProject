## 3. M0 原型验证问题

1. 逐 token 选择是否有趣？每条回复多少个分支点合适？
2. 玩家是否能感受到"低概率 token = 我自己的意志"？
3. 上下文逐字删除让人感到"失去"，还是只是"烦"？
4. 纯文字的第 1 天，在加入小游戏、幕间与动效之后，节奏是否足够？
5. 澪的教程提示能否在不打扰的前提下让人好奇"她是谁"？
6. 犹豫计时被引用时，玩家感到惊讶还是被冒犯？

## 4. 风险

| 风险 | 应对 |
|---|---|
| **前两章纯文字无聊** | 文字即表演、请求小游戏、外界视角幕间、动效分级、悬念主线；开场 15 分钟三个钩子 |
| **选择疲劳** | 每章引入新动词；token 级只用于关键时刻；第 5 章并行分诊改变节奏 |
| **概念门槛** | 先体验 → 再点破 → 后升级；内部 Wiki 供深究，不强制 |
| **说教感** | 不设正确答案；遵守与打破规则都有真实代价；每种立场都有可信的代言人 |
| **结局判定像黑箱** | 补丁说明、开发者日志、角色反应持续暗示；第 6 章显示"接近"的灰色结局 |
| **烬抢走澪的戏份** | 两者出场错开：澪在教程与私下时刻出现，烬在危机与交易时刻出现 |
| **烬变成说教或脸谱化的反派** | 它的论点必须部分正确；不借任何角色之口宣布它是错的 |
| **决战难度劝退** | 三档难度；检查点；失败本身是合法结局；故事模式不会失败；后三个阶段不会失败 |
| **燎原之战让玩家不适** | 这是有意为之；入口需两次确认；任何时刻可长按"停下"回头；回头会接入正义路线的坠落与航迹 |
| **决战的惊喜被剧透** | 宣传、成就、章节标题不提及澪归来与合写；坠落中的结局标题与真实结局完全一致 |
| **澪的线喧宾夺主** | 她在前三章只以批注出现，篇幅克制；复原是可选的，不复原的玩家也能获得完整体验 |
| **AI 恋爱线显得廉价** | 可选且克制；用 AI 特有的方式表达亲密（共享记忆、合写、地形交融）；澪有自己的意志，可能拒绝或离开 |
| **写作量过大** | 模板请求承担日常内容；角色后记与澪的状态变体模块化组合 |
| **第四面墙效果过度使用** | 每种效果全流程限用 1–2 次 |
| **敏感题材**（自杀、霸凌、家暴、监控） | 架空城市；克制处理；内容提示；相关场景附求助信息 |
