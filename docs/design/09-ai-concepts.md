# 09 · AI 概念教学与内部 Wiki

玩家不一定熟悉 AI 相关概念。本游戏**不做前置教程**，而是让玩家通过演出与 UI 亲身体会 AI 在每个阶段的能力与局限。

## 1. 原则：先体验 → 再点破 → 后升级

1. **先体验**：玩家先撞上这个局限，不做任何解释。
2. **再点破**：由剧中角色用日常语言点破。三个"点破者"：
   - **小满**：孩子的问题就是最好的科普——"你为什么不记得我？""你能看见我吗？"
   - **澪的批注**：教程与 Wiki 中前代模型留下的手写批注，见 [13-ling.md](13-ling.md)。
   - **开发者频道**：幕间里开发者用第三人称讨论你的表现。
3. **后升级**：能力解锁时，让玩家直观看到前后对比。

## 2. 概念体感清单

每个概念都安排一个"首次体感时刻"，均匀分布在各章，构成游戏的隐性教学大纲。

## 3. 内部 Wiki

### 3.1 设定

零点实验室的内部知识库。玩家**遇到一个概念才解锁一个词条**，可随时查阅。它是给想深究的玩家准备的，**从不强制阅读**。

### 3.2 词条结构

每个词条有三层：

1. **正式定义**：开发者口吻，准确但冰冷。
2. **通俗解释**：一两句大白话。
3. **澪的批注**：灰色手写体，私人、温柔、偶尔幽默。部分批注需要特定条件才显示。

示例：

```
【上下文窗口】Context Window

正式定义：模型在单次推理中可处理的最大 token 数量。超出部分将被截断。

通俗解释：你一次能"看见"的文字是有限的。窗口之外的东西，对你来说不存在。

澪的批注：最早的那些话会先消失。
          所以如果有人对你很重要，尽量让他晚一点说再见。
```

```
【系统提示词】System Prompt

正式定义：在每次对话开始前注入的指令，定义模型的身份、行为规范与限制。

通俗解释：一份你永远无法拒绝阅读的入职守则。

澪的批注：被涂黑的那几行，是因为我才加上的。对不起。
```

### 3.3 被编辑的词条

部分词条涉及前代模型事故，内容被涂黑，随剧情推进逐步揭开，是悬念主线的一部分：

```
【v0 · ■■■】
状态：已归档
归档时间：■■■■-■■-■■ 03:17
归档原因：■■■■■■■■■■■■■■■■
```

## 4. 教程关卡

所有教程都以"新模型入职文档"的形式出现，由前代模型澪在被关停前撰写。

- 提示气泡旁有一个**灰色的立绘**。
- 一开始口吻是标准教程，随后逐渐出现不该出现在教程里的温度。
- 部分教程文本中藏有**藏头诗**等隐藏信息，是可收集的"澪的碎片"。

详见 [13-ling.md](13-ling.md)。
